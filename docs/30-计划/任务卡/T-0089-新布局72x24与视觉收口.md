## 1. 背景

`DES-014` 的 P1 已落地，但 Player、Browse 树、键位和状态栏仍未达到最终设计。本卡按 2026-11-13 冻结的设计稿一次性收口到 72×24 默认布局，并删除补全与多余键位。

---

## 2. 目标

- 新窗口默认 72×24；`layout_areas` 只返回 `top / player / controller`，状态栏嵌外框下边线。
- Player 无左右边框，内容宽 = 外框内宽 − 2；6 行视觉 + overlay + 整宽进度条；右下 `Mode ↻`。
- Browse 树顺序为 `歌单 / 子项 / 媒体库 / 搜索 / 队列 / 设置`；初始选中歌单；歌单 >5 折叠，≤5 展开；`Shift+Enter` 切换。
- 只保留确认键位；补全整体删除，无死代码。
- 内置主题只留 MilkGreen，自定义主题和 token 兜底保留。
- 圆角、焦点边框、计数弱化、状态栏分色按冻结方案落地。

## 3. 非目标

- 不改队列表、歌单表、设置表的列内容（H 决定）。
- 不改命令语法、错误码、`np-core` 命令契约。
- 不删除自定义主题机制；不删除 `ThemeTokens::default` 兜底。
- 不新增 Rust 依赖；不做鼠标交互；不做动画。
