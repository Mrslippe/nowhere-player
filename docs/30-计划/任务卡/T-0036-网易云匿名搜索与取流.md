## 1. 背景

B 站这条竖线已经跑通（真机下载 8.2MB m4a）。现在做第二个源：网易云匿名。

## 2. 目标

1. `NeteaseSource::search` + `resolve`。
2. **先探测免加密接口**；只在确实被拒时才上 `weapi` 加密。
3. 把**源相关的请求头**从 `HttpDownloader` 移进 `ResolvedStream.headers`（清 T-0035 遗留）。
4. 加**单曲时长上限**（≥ 30 分钟不下载，报 `E_SRC_UNAVAILABLE` 并说明原因）。

## 3. 非目标

- 不做登录、不存 cookie。
- 不做歌单/专辑/艺人页。
- 不做歌词。
- 不做 yt-dlp（T-0037）。

## 4. 必读 / 必须先探测

1. `docs/20-架构/adr/ADR-0004-在线音源适配层.md`（§4 网络策略、§11 实现备注）
2. `crates/np-sources/src/bilibili/**`（照它的分层写）
3. **先探测这几个端点在无加密、无 cookie 下是否可用**（开发调试，不是测试）：
   - `https://music.163.com/api/search/get?s=<kw>&type=1&limit=20`
   - `https://music.163.com/api/song/enhance/player/url?ids=[<id>]&br=320000`
   - 若 403/-460，再评估 `weapi`（`/weapi/cloudsearch/get/web`、`/weapi/song/enhance/player/url/v1`）

> **探测结论决定实现路线**，请把它写进回报的第一段。不要一上来就写 AES/RSA。

## 6. 实施要求

### 6.1 搜索

- 映射到 `SourceTrack`：`source_id` 用歌曲 id 字符串；`artist` 多艺人用 `,` 连接；`duration_ms` 用 `dt`/`duration`。
- `cover_url` 从 `al.picUrl` 或 `album.picUrl` 取，**把 `http://` 改成 `https://`**（老接口返回 http，WebView 与 CSP 都会拦）。

### 6.2 取流

- 优先 `br=320000`；拿不到就依次降级 `192000` / `128000`。
- `url` 为 `null` 或 `code != 200` → `Unavailable`，**并带上"需要会员/版权受限"这类可读原因**。
- `expires_at` 从 `expi`（毫秒还是秒要实测确认）换算。

### 6.3 请求头移进 `ResolvedStream`

```rust
pub struct ResolvedStream {
    pub url: String,
    pub mime: String,
    pub expires_at: Option<SystemTime>,
    pub headers: Vec<(String, String)>,   // ← 新增
}
```

- `HttpDownloader` 不再硬编码 `Referer`/`Origin`，只发 `stream.headers` + 固定 UA。
- B 站那边把自己需要的 header 填进 `ResolvedStream`。
- **这是契约变更**：`SourceTrack` 不变，`ResolvedStream` 加字段，属于本卡授权范围（ADR-0004 §3 需同步）。

### 6.4 时长上限

- 搜索结果与 `resolve` 都检查：`duration_ms > 30 分钟` → 该条目在搜索里**不返回**（过滤），`resolve` 遇到则报 `Unavailable`。
- 常量放模块顶部，不要散落魔法数。

## 11. 风险

- **`/api/search/get` 可能已失效**：网易云近年收紧，返回空或 -460。若实测不可用，如实说明并上 weapi，不要用"能跑就行"的方式硬凑。
- `weapi` 的 AES-CBC 两轮加密 + RSA 是**公开算法**（`cipher.c`/`weapi` 的魔改 base64 表），实现不难但容易错一位就全错。用固定向量自测。
- 取流返回的 URL 有时是 `http://m7.music.126.net/...`，**必须 https 化**。
- 版权受限的曲目占相当比例，`url: null` 是常态不是异常——错误文案要说人话（"该曲目在网易云不可播放"），不是 `E_SRC_UNAVAILABLE`。
- `ResolvedStream` 加字段会影响 T-0035 的下载器与夹具，**改完必须跑全量 `cargo test --workspace`**。
