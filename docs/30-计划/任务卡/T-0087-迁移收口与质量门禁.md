## 1. 目标

1. 让 README / 当前状态 / 结构规范 / 数据模型 / 命令表与代码一致。
2. 给 schema v3 补 ADR-0007，并标 ADR-0005 的取代关系。
3. 完成 T-0079 的删除闭环：covers 入口、死字段、库层 `eprintln!`、回归测试。
4. 补 LICENSE、版本 0.1.0、CHANGELOG。
5. 拆分 `np-app/command.rs`，移除 crate 级 `allow(dead_code)`。
6. 把文档/契约/文件预算做成可执行门禁，接入 `check.ps1` / `check.sh` / CI。
7. 补 SPEC-004/005/006、OPS-001 四份短规范。

---

## 2. 非目标

- 不实现 macOS/Linux 的托盘/自启/单实例；只收窄宣传口径。
- 不新增 Rust 依赖。
- 不重写历史任务卡；只索引与修硬伤。
- 不做发布签名/安装器。

## 5. 关键改动

- 新增 ADR-0007；ADR-0002 标 superseded；ADR-0004 从 proposed 改 accepted。
- `np-app/command.rs` 拆为 `model/settings/executor/helpers/library/online` + `tests.rs`；最大生产文件 1,780 行。
- 删除 `CoverStore` / `covers_dir` / `cover_store` / covers 缓存目标；`cache clear covers` 现在解析即拒绝。
- 新增 `check-docs.py` / `check-contracts.py` / `check-hygiene.py`；`check.sh` 与 `check.ps1` 对齐。
- CI 增加 docs/契约/卫生/release build/macOS，使用 `--locked`。
- 文档索引覆盖 31 篇规范类；85 张任务卡有独立索引。

## 6. 残留风险

1. `np-app/command/tests.rs` 仍有 5,525 行；测试可按功能再拆，暂由 6,000 行测试上限兜底。
2. `智能体工作管线` 491 行、`数据模型` 252 行、`任务卡模板` 242 行在 allowlist 到 2026-12-31，需拆分或压缩。
3. 32 条 docs warning 中多数是 `verified: —` 与历史路径引用；语义正确性仍需人工抽查。
4. 跨平台仍 Windows-first；macOS/Linux 只做了编译/测试，未做真机系统集成。
5. 性能指标（40ms / 20MB）仍是历史测量，没有 CI benchmark。
