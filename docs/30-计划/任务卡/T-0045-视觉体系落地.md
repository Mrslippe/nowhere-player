## 1. 背景

产品选定方向 B：**D3（Modern）的结构与方法 + 保留琥珀作为信号色**。
设计依据：`docs/10-设计/preview2/d3-modern.html`（**照它做，但要按 §6.1 把蓝色换成琥珀**）。

## 2. 核心原则（这一卡所有决定的依据）

> **琥珀只做信号，不做文字。**
> 琥珀出现在：进度填充、播放头、命令提示符、需要强调的数字。
> 正文一律暖中性灰。**这是解决"太单调"的关键**——不是加颜色，是把颜色的使用收窄。

## 3. 目标与阶段

### 阶段 1：token 与终端外壳（1.5 天）

1. **字阶**（替换现有字面的两档）：
   | 角色 | 字号 | 行高 | 字重 |
   |---|---|---|---|
   | 标题/命令回显 | 15px | 1.3 | 600 |
   | 结果正文 | 13px | 1.4 | 400 |
   | 元信息/表头 | 11px | 1.5 | 400 |
   | 极小标注 | 10px | 1.4 | 400 |

2. **字体分工**：界面用无衬线（`Segoe UI` → `Microsoft YaHei` → system-ui），数字/时间/ID 用等宽（`Cascadia Code` → `Consolas`）+ `font-variant-numeric: tabular-nums`。

3. **三级材质**：底 `#0d0f12` / 卡片 `#14171c` / 浮层 `#1a1e24`，每级只差 4–5 个明度点；**层级靠明度 + 1px 内高光**（`inset 0 1px 0 rgba(255,255,255,.06)`），不靠粗描边。

4. **间距阶**：8px（8/16/24/32）；行高 28px；表格行间只有 4% 行间线；表头下 **2px** 强调线。

5. **列宽**：序号 48 / 来源 72 / 标题 `1fr` / 艺人 120 / 时长 72（**全是 8 的倍数**）；数字列右对齐。

6. **顶栏**：保留现有品牌 + 本地库状态 + 窗口控制；背景加 `backdrop-filter: blur(18px)`（内容从下面滚过）。

### 阶段 2：播放器（1.5 天）

1. 卡片：`radius 14`、底 `#14171c`、1px 内高光、`shadow` 只用浮层（不要多层柔影）。
2. 封面 56×56、`radius 9`；**不做取色光晕**（需要 canvas 采样，成本高于收益，留 M7）。
3. 标题**单行**、15px/600、超出省略；第 26 个字符处截断是可接受的。
4. 副标题 11px/50% 灰；空艺人时**不占位**（进度条上移），不留空洞。
5. 进度：**连续轨道 3px（`radius 999`，20% 线色）+ 9px 圆形播放头**，透明描边 2px。**废弃 28 段碎块**。
6. 底部一行：时间 / 控制键 / 时间，30px 高；控制键不随标题移动。
7. 琥珀只出现在：播放头、进度填充。

### 阶段 3：错误块可操作（1 天）

1. 错误块改为卡片：左 `#ff8b7d` 4px 竖线 + 标题行 + 一行说明 + **操作按钮**。
2. 按钮是**可点击的**：点击等价于执行按钮上写的命令。
3. 需要给 Block 增加可选字段（见 §6.2），**属于契约扩展，先报告再改**。

## 6. 实施要求

### 6.1 颜色映射（D3 的蓝 → 我们的琥珀）

| 用途 | D3 的值 | 本项目 |
|---|---|---|
| 底 / 卡 / 浮层 | `#0d0f12` / `#14171c` / `#1a1e24` | **同** |
| 正文 | `#e8e6e1`（冷） | `#e9e4da`（暖中性） |
| 次/弱 | 70% / 50% | 同 |
| **信号色** | `#8ea6ff` | **`#ffb454`** |
| 危险 | `#ff8b7d` | 同 |
| 内高光 | `rgba(255,255,255,.06)` | 同 |

对比度校验：`#e9e4da` on `#0d0f12` ≥ 12:1；50% 灰 ≥ 4.5:1；琥珀仅做图形，不做正文（若用于文字，对比度需 ≥ 4.5）。

### 6.2 块操作（契约扩展）

```ts
type BlockAction = { label: string; input: string };   // input = 点击后要执行的命令
```

- `Block`（wire）新增可选 `actions?: BlockAction[]`，**旧数据无此字段仍然合法**。
- 前端渲染为按钮；点击 → 走与输入框相同的 `cmd.exec` 路径（复用现有逻辑）。
- 后端先在错误块上产出：`[{ label: "重试", input: "<原命令>" }, { label: "只用本地搜索", input: "search <关键词> --local" }]`。
- **schemaVersion 不变**（新增可选字段向后兼容），但 `终端输出模型.md` 要补一节。

### 6.3 不能破坏的东西

- 公开样式契约的 12 个选择器（`.np-player-card__*`、`.np-blocks-item` 等）**不改名**。
- `data-status` / `data-tone` 的取值不变。
- `prefers-reduced-motion` 全部生效。
- `plain` 与 `phosphor` 两个 skin 都要能跑（**新视觉属于 `plain` 的重做，phosphor 保留其结构，仅套用新字阶与材质**）。

## 11. 风险

- **这是最大的一次视觉改动**，会让所有截图失效——每阶段结束都要留一组「阶段前/阶段后」对比。
- 无衬线界面 + 等宽数字的**混排**容易基线不齐：表格里数字列必须 `tabular-nums` 且 `text-align: right`，否则跳动。
- 三级材质只有 4–5 个明度点差，**在低质量显示器上可能看不出差异**——如果实测分不清，宁可拉大差距，也不要靠加描边补救。
- 块操作是新交互，**键盘用户可能不知道能点**：按钮要能被 Tab 聚焦，且要能用 `Enter` 触发。
