## 1. 背景

两笔 M0 留下的欠账：

1. `IconButton` 只有 32×32 一种尺寸，播放器为了塞进 64px 封面在 `player.css` 里覆写成 20×20——**业务代码绕过设计系统**。
2. 主题选择不持久化，刷新就回 graphite。

顺手一起清掉，范围小、验收明确，适合作为"低思考强度"的对照实验。

## 2. 目标

1. `IconButton` 增加 `size?: "sm" | "md"`（`sm` = 20×20 / 图标 14px，`md` = 32×32 / 图标 16px，`md` 为默认）。
2. 删除 `apps/web/src/features/player/player.css` 里对 `IconButton` 的尺寸覆写，改用 `<IconButton size="sm" />`。
3. 主题持久化：`data-theme` 变化时写入 `localStorage["np.theme"]`，启动时读回；非法值回落 `graphite`。

## 3. 非目标

- 不做主题跟随系统（`prefers-color-scheme`）。
- 不做主题切换动画。
- 不动 DES-001 的颜色值。

## 4. 输入

1. `docs/10-设计/设计语言.md` §4（组件 API）
2. `apps/web/src/design/components/IconButton.tsx`
3. `apps/web/src/features/player/player.css`（覆写处）
4. `apps/web/src/features/terminal/TerminalLab.tsx`（主题切换入口，只需看，不必改）

## 5. 授权路径

**可写**：

```
apps/web/src/design/components/**
apps/web/src/design/index.ts
apps/web/src/features/player/**
apps/web/src/shared/theme.ts        ← 新建：读写 localStorage
apps/web/src/shared/theme.test.ts
```

**禁改**：`features/terminal/**`、`app/**`、`crates/**`、`docs/**`、`vite.config.ts`、`package.json`、`pnpm-lock.yaml`

## 6. 实施要求

- `IconButton` 的 `size` 用 `data-size` 属性 + CSS 变量控制，**不要**用内联样式。
- 删除覆写后，播放器小窗的控制键视觉必须与之前一致（20×20、图标 16px 可接受——若视觉变化，在回报里说明并附截图）。
- `theme.ts` 导出 `loadTheme(): ThemeName` 与 `saveTheme(name)`；`ThemeName = "graphite" | "amber" | "ice"`。
- 读取时用 `try/catch` 包住 `localStorage`（隐私模式下会抛错），失败回落默认值。
- 不改 `TerminalLab` 的主题切换逻辑——它已经改了 `data-theme`，持久化由 `theme.ts` 在 `ThemeProvider` 或 App 层挂载时接管；若必须改 `TerminalLab`，先在回报里说明。

## 7. 验收标准

- [ ] `pnpm -C apps/web typecheck` 通过
- [ ] `pnpm -C apps/web test -- src/design src/shared src/features/player` 通过
- [ ] `IconButton` 两个尺寸各 1 个测试（断言 `data-size` 与 box 尺寸）
- [ ] `theme.ts` 3 个测试：默认值、读写往返、非法值回落
- [ ] `grep -r "icon-button" apps/web/src/features/player/player.css` 无尺寸覆写残留
- [ ] 播放器小窗 340×120 下视觉无回归（附截图）
- [ ] 不跑 `scripts/check.ps1`（并行期）

## 11. 风险

- 删掉覆写后如果播放器布局塌了，说明覆写里还有别的样式（不只是尺寸）——这种情况**不要扩大范围**，把原覆写拆成"尺寸（删）"和"布局（保留并改注释）"两部分。
