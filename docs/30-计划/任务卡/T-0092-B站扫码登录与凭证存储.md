## 0. 目标

```text
/login bili
→ QR generate/poll
→ 手机扫码
→ DPAPI 加密保存 cookie
→ 直播 API 带 cookie
→ 争取 qn10000
→ /logout bili 清除
```

登录态只用于 B站直播 API / 取流，不用于音乐源。

## 1. 协议

```text
GET https://passport.bilibili.com/x/passport-login/web/qrcode/generate
GET https://passport.bilibili.com/x/passport-login/web/qrcode/poll?qrcode_key=...
```

poll code：

```text
86101 未扫码
86090 已扫码待确认
86038 过期
0     成功，Set-Cookie 含 SESSDATA
```

保存：

```text
SESSDATA
bili_jct
DedeUserID
DedeUserID__ckMd5
sid
buvid3（如响应有）
refresh_token（如响应有）
```

## 2. 后端 T-0092a

### 2.1 Transport

`np-sources` 增加窄响应：

```rust
pub struct HttpResponse {
    pub status: u16,
    pub headers: Vec<(String, String)>,
    pub body: Vec<u8>,
}

trait Transport {
    fn get_with_headers(&self, url: &str, headers: &[(&str, &str)]) -> Result<HttpResponse>;
}
```

默认实现回退 `get`，headers 为空；生产 `ReqwestTransport` 返回 status/headers/body。
不改 `get`/`get_to`/`open_stream` 的既有语义。

### 2.2 Auth 模块

```text
np-live/src/auth.rs
  BiliAuth { cookies, refresh_token, uid }
  QrLogin { qr_url, qrcode_key, status }
  generate_qr(transport)
  poll_qr(transport, key)
  parse_set_cookie(headers)
  cookie_header()
```

- 不打印 cookie / QR URL；
- poll 2s 间隔；
- 过期/取消有明确状态。

### 2.3 DPAPI

Windows：

```text
%APPDATA%\com.nowhere.player\bili-auth.bin
CryptProtectData / CryptUnprotectData
```

- `windows-sys` 0.61，features `Win32_Security_Cryptography`, `Win32_Foundation`, `Win32_System_Memory`；
- 加密后写文件；原子替换；
- `load/save/clear`；
- 非 Windows 第一版只做内存登录，不落盘；
- 不把 cookie 写日志、临时文件、panic 信息。

### 2.4 测试

- FakeTransport：generate/poll 四种 code、Set-Cookie 解析、cookie header；
- DPAPI roundtrip（Windows）；
- 空 cookie / 损坏文件 / 非 Windows fallback；
- 不访问真实 B站。

## 3. QR 渲染 T-0092b

只改 `np-tui`，新增：

```text
crates/np-tui/src/qr.rs
```

- 终端 QR，Unicode 半块；
- 33x33 → 33 列 x 17 行（72x24 可容纳）；
- 输入 URL，输出 `Vec<String>`；
- 不生成图片、不打开浏览器；
- 使用 **vendored qrcodegen（MIT，Project Nayuki）** 或纯 Rust 等价实现；不新增 crates.io 依赖（当前 registry 不可达）；
- 保留 MIT 许可头；
- 测试已知 URL 的模块尺寸/边框/白边。
