## 0. 事实基线

- 控制条/标题栏目前使用硬编码深灰 + 蓝色 accent，和 TUI 默认 MilkGreen / 用户主题不一致。
- TUI `Palette` 已有 `bg/fg/muted/faint/accent/line/danger`，但尚未包含 `bgElev/bgHover/accentFg`。
- 视频窗口是独立进程，主题必须由 TUI 通过握手/控制行传入，不能自己读主题 JSON。
- 用户确认：底部悬浮、尽量无缝；本卡只做视觉与主题联动，不改布局/交互语义。

## 1. 目标

### 1.1 视觉

- 控制条和标题栏都使用当前 TUI 主题：
  - surface = `bgElev`
  - hover = `bgHover`
  - text = `fg`
  - muted = `fgMuted`
  - faint = `fgFaint`
  - accent = `accent`
  - line = `line`
  - danger = `danger`
  - 关闭按钮 glyph = `accentFg`
- 控制条：顶部 1px line，去掉上下双边框；背景 surface；
- 播放中暂停图标 accent；暂停中播放图标 fg；
- 音量滑杆填充/圆点 accent；轨道 line；
- 清晰度 muted + `▾`；hover 变 fg；
- cache faint；
- 按钮 hover 用 bgHover；不新增动画、圆角、阴影；
- 标题栏使用同一主题，避免控制条亮/标题栏暗。

### 1.2 主题传递

- `Palette` 增加 `bg_elev`、`bg_hover`、`accent_fg`，从 `ThemeTokens` 读取。
- `Palette::terminal()` / 默认值回退到 `Palette::default_dark()` 的具体 RGB。
- TUI 新增 `VideoTheme`（RGB 八元组），`Palette → VideoTheme`；非 RGB 终端色回退默认暗色。
- 初始握手新增：

  ```text
  theme #accent #surface #hover #text #muted #faint #line #danger #accentFg
  ```

  共 9 个 `#rrggbb`，顺序固定。
- 视频打开期间切主题，TUI 每 tick 比较当前 `Palette`，变化时向宿主 stdin 发同样 `theme ...` 行；宿主重绘标题栏/控制条，不重启 mpv。
- 主题行只含颜色，不含 URL/Cookie。

## 2. 非目标

- 不改视频比例/控制条几何/2s 隐藏。
- 不改清晰度切换/追帧/音频启动。
- 不主题化 mpv 视频画面或系统原生菜单（菜单仍是 OS 风格）。
- 不新增第三方依赖。

## 4. 实现要点

- `Palette` 新字段后所有构造点（`from_tokens`/`terminal`/`default_dark`）同步更新。
- `VideoTheme::from_palette` 对 `Color::Rgb` 直接取值；`Color::Reset`/命名色回退 `Palette::default_dark()`。
- TUI `VideoAudioOptions` 增加 `theme`，初始 `host_request` 写 `theme ...`。
- `VideoController` 存 `theme`；`sync_theme` 发送 `theme ...`；`TuiAudio::toggle_video_with_theme` 由 controller 传入 `app.palette`，保留无参 `toggle_video()` 给测试/关闭路径。
- `event_loop` 每 tick 调 `player.sync_video_theme(&app.palette)`；变化即发。
- np-video `Request`/`Control` 增加 theme；`Host` 保存 theme；paint 全部读取 `host.theme`，不再用硬编码 ACCENT/BACKGROUND。
- 控制条 hover 状态：`Host.hovered_control: Option<ControlHit>`；`WM_MOUSEMOVE/WM_MOUSELEAVE` 更新并重绘。
- 清晰度文字加 `▾`；标题栏/控制条按主题重绘。
- `theme ...` 行解析校验九个 `#rrggbb`；非法整行拒绝/回退旧主题，不 panic。

## 6. 结果

**状态：完成（代码 + 单元测试 + 全量门禁）；T3 真机项未验证（当前环境无法交互操作 Win32 窗口 / GDI 绘制）。**

### 变更

- `crates/np-tui/src/theme.rs`：
  - `Palette` 新增 `bg_elev` / `bg_hover` / `accent_fg`，从 `ThemeTokens` 读取；`default_dark()` 为 graphite 具体 RGB，`terminal()` 的新槽位保持非 RGB。
  - 新增 `VideoTheme`（9 个具体 RGB）：`from_palette` 逐槽取 `Color::Rgb`，非 RGB 回退 `Palette::default_dark()`；`protocol_line()` 固定输出 `theme #accent #surface #hover #text #muted #faint #line #danger #accentFg`。
- `crates/np-tui/src/video.rs`：
  - `VideoAudioOptions` 带 `theme`；初始 `host_request` 在 `buffer_ms` 后写主题行。
  - `VideoController` 保存最近主题；新增 `sync_theme`：变化时 `HostChild::set_theme` 写 `theme ...`，只重绘 np-video 标题栏 / 控制条，不重启 mpv；`TuiAudio::sync_video_theme(&Palette)` 转发。
  - 新增 `toggle_video_with_theme(&Palette)`；保留无参 `toggle_video()` 给测试 / 关闭路径。
- `crates/np-tui/src/controller.rs`：`Action::ToggleVideo` 使用 `app.palette`。
- `crates/np-tui/src/event_loop.rs`：每 tick 调 `player.sync_video_theme(&app.palette)`。
- `crates/np-video/src/protocol.rs`：新增 `Theme`（9 个 RGB）与 `theme` 行解析 / 序列化；`Request.theme: Option<Theme>`；非法初始主题行整行忽略并保留上一份（没有则默认 graphite），不 panic。
- `crates/np-video/src/main.rs`：stdin 新增运行期 `theme ...`；非法行只记 warn、不发 `Control`，宿主保持旧主题。
- `crates/np-video/src/host/mod.rs`：
  - `Control::Theme(Theme)`；`Host` 保存 `theme`，变化时只置标题栏 / 控制条重绘标志。
  - `Host.hovered_control: Option<ControlHit>`；`WM_MOUSEMOVE` 更新并 `TrackMouseEvent(TME_LEAVE)`，`WM_MOUSELEAVE` 清空；控制条收起时同步清空。
- `crates/np-video/src/host/paint.rs`：删除硬编码深灰 / 蓝色 accent，标题栏与控制条全部读 `Host.theme`。
  - 标题栏：surface 背景、text 标题、line 底边；普通按钮 hover `bgHover`，关闭按钮 hover `danger`、hover 字形 `accentFg`。

- `crates/np-video/src/layout.rs` 未改：40px 高度 / 12px 边距 / 2s 隐藏 / 按钮尺寸与命中保持不变。
- 未触碰 `crates/np-tui/src/render.rs`（用户 WIP）。
- 不主题化 mpv 视频画面与原生清晰度 popup 菜单；菜单仍由 OS 绘制（本卡非目标）。

### 未验证 / 风险

- **T3 全部未验证**：真实窗口下的浅色 / 暗色观感、按钮 hover、切主题即时重绘、高 DPI（125% / 150%）与 960×540 / 1440×810 截图；当前为无 GUI 的自动化环境，只验证了颜色映射、协议行与状态机。
- 控制条 hover 依赖 `WM_MOUSEMOVE` 与 `TrackMouseEvent(TME_LEAVE)`；控制条刚显示时若鼠标不动，hover 要等下一次移动才出现。
- 标题栏关闭按钮的 `accentFg` 仅在 hover（danger 底）时使用；静止态用正文色，避免 MilkGreen 浅底上 `#eef1ea` 不可辨。
- 原生清晰度 popup 菜单仍是 OS 主题；mpv 视频画面不参与换肤，系统为浅色模式时菜单与窗口主题可能不一致（符合本卡非目标）。
- 主题行按 1 行 9 色传输，不包含透明度；`rgba(...)` 主题 token 已在 TUI 侧按 `bg` 混合成 RGB，视频窗口收到的始终是不透明色。
