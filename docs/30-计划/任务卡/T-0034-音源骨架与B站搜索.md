## 1. 背景

M5 要把在线音源接进来。这一卡**只做一条竖线**：`np-sources` 的 trait 骨架 + B 站搜索能跑通。不接播放、不改命令层。

**为什么先做 B 站**：只需要 HTTP + `wbi` 签名（md5），不涉及加密登录，是三个源里风险最低的。用它验证适配层形状，再决定网易云和 yt-dlp 怎么接。

## 2. 目标

1. `crates/np-sources` 落地：`AudioSource` trait、`SourceTrack`、`ResolvedStream`、错误类型。
2. **可注入的 `Transport`**（`get(url) -> Result<Bytes>`），生产实现用 `reqwest::blocking`，测试用夹具。
3. `BilibiliSource::search`：调搜索接口 → 解析 → 返回 `Vec<SourceTrack>`。
4. `BilibiliSource::resolve`：**先只返回占位错误**（`E_SRC_NOT_IMPLEMENTED`），取流地址放 T-0035。
5. 错误类型覆盖 ADR-0004 §6 的降级语义。

## 3. 非目标

- 不接命令层（`search` 命令仍然是本地库）。
- 不下载、不播放。
- 不做网易云 / yt-dlp。
- 不做异步。

## 6. 实施要求

### 6.1 依赖（已批准，仅这些）

```toml
reqwest = { version = "0.12", default-features = false, features = ["rustls-tls", "json", "blocking"] }
md5 = "0.7"
thiserror = "2"
serde = { workspace = true }
serde_json = "1"
```

### 6.2 trait 形状

按 ADR-0004 §3。注意：

- `search` 返回的 `SourceTrack` 必须带 `source`、`source_id`、`title`、`artist`、`duration_ms`；`album`/`cover_url` 可为 `None`。
- `resolve` 返回 `ResolvedStream { url, mime, expires_at: Option<SystemTime> }`。
- 所有网络错误要能区分：`Network` / `Http(status)` / `Parse` / `Unavailable`。

### 6.3 B 站搜索

- 搜索接口：`https://api.bilibili.com/x/web-interface/wbi/search/type?search_type=video&keyword=...`
- `wbi` 签名：从 `nav` 接口取 `wbi_img.img_url/sub_url` → 拼 mixin key → 参数排序 + 拼 `w_rid`。**签名逻辑单独成纯函数**（`wbi::sign(params, key) -> String`），用固定向量测试。
- 结果只保留**音频可提取**的条目（时长、id 合法）。

### 6.4 夹具与测试

- `fixtures/bilibili/search_ok.json`、`search_empty.json`、`search_denied.json`（-412 风控）。
- **允许开发时手工请求一次真实接口确认字段**（这是调试，不是测试），但**测试代码里不得有网络调用**。
- 若无法联网：用合成 JSON，并在回报里**明确标注哪些字段未经真实校验**。
- 测试用固定 `Transport` 返回夹具；`wbi::sign` 用固定 key + 参数断言已知签名。

## 7. 验收标准

- [ ] `cargo test -p np-sources` 通过，≥ 12 用例：
  - `wbi::sign` 固定向量（≥ 3 组）
  - 解析 `search_ok` → 条数、字段映射正确

## 11. 风险

- **`wbi` 签名是最容易错的地方**：mixin key 的取法、参数排序、`w_rid` 的计算顺序，任一错都会得到 -403。先用固定向量自测。
- B 站可能对无 cookie 的请求返回 -412（风控）。**如实报告**，不要伪造 UA 或加 cookie——那会让这个源在别人机器上更不稳定。
- `reqwest::blocking` 在测试里不会用到（注入 Transport），但如果误在测试构造了它，会拉起运行时——避免。
- 搜索结果是视频条目，**音频要另外取**（T-0035）。本卡只保证"能搜到、字段对"。
