## 1. 目标

### 1.1 常驻播放器面板（右栏 28 列）

```
┌ 播放 ─────────────┐
│                   │
│   [封面 Sixel]    │   ← ~26 列 × 12 行
│                   │
│ The Less I Know   │
│ Tame Impala       │
│                   │
│ ▮▮▮▮▮▮▯▯▯▯        │   ← 频谱（10 行）
│ ▮▮▮▯▯▯▯▯▯▯        │
│                   │
│ 02:41 / 03:36     │
│  ⏮  ⏯  ⏭          │   ← 用字符画，不是 emoji
└───────────────────┘
```

- **`Ctrl+B`** 显示/隐藏面板（默认显示）。
- 面板与左侧命令区**独立**：滚动左侧不影响封面。

### 1.2 沉浸模式

- **`Ctrl+F`** 进入：整屏大封面（占 ~60% 宽）+ 大标题 + 全宽频谱 + 精简状态。
- `Esc` 返回。
- 进入/退出用一帧即切（TUI 里做过渡动画意义不大，且会闪）。

### 1.3 频谱（可视化）

- 数据来源：**需要给 `np-audio` 加一个样本 tap**（见 §4 授权）。
- 实现：`Arc<Mutex<RingBuffer<f32>>>`，Player 每渲染一帧 PCM 写一次；UI 侧每帧取最近 2048 样本。
- **FFT 自己实现**（radix-2，约 80 行），**不引入 `rustfft`**——红线要求新依赖走 ADR，而 2048 点 FFT 手写成本很低。
- 分 16 个频段（对数分布），每段取峰值 → 映射成 0–10 的字符高度（`▁▂▃▄▅▆▇█`）。
- **限帧 20fps**，且**暂停时不刷新**（省 CPU）。

## 2. 非目标

- 不做歌词（无歌词源）。
- 不做鼠标点击控制键。
- 不做主题切换（T-0062）。
- 不做托盘/热键（T-0063）。

## 3. 界面细节约定

| 项 | 约定 |
|---|---|
| 封面尺寸 | 面板宽度 - 2 列，行数按图片纵横比算；`Resize::Fit` |
| 无封面时 | 画一个字符占位框（`░` 填充 + `♪`），不请求网络 |
| 标题溢出 | 省略号截断，**按字符宽度算**（中文 2 列） |
| 进度条 | `Gauge`，已完成用 `▮`，未完成 `▯`；带时间文本 |
| 控制键 | `⏮` 换成 `◀◀`、`▶` `❚❚`（字符而非 emoji） |
| 频谱字符 | `▁▂▃▄▅▆▇█`（八级） |
| 面板边框 | 1px `┌─┐│└┘`，标题嵌在顶线 |

## 4. 授权路径

```
crates/np-tui/**
crates/np-audio/src/**          ← 仅新增样本 tap（见下）
Cargo.toml（若需 workspace 成员）
```

**禁止**：`np-app` / `np-core` / `np-library` / `np-sources` / `apps/**` / `docs/**`

### 4.1 `np-audio` 的唯一改动

```rust
pub struct SampleTap { ... }          // 环形容器
impl Player {
    pub fn sample_tap(&self) -> SampleTapHandle;  // 只读句柄
}
```

- **只加读取接口，不改播放路径**。
- 写入点在音频回调里，**不允许分配内存**（用预分配环形缓冲）。
- 现有 23 个音频测试必须继续通过。

## 6. 测试要求

- FFT：单测（正弦输入 → 峰值落在正确频段）。
- 环形缓冲：覆写/读取边界的单测。
- 面板布局：`TestBackend` 断言行列分配（不含 Sixel 部分）。

## 7. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | **Sixel 在面板内滚动时会花** | 面板固定不滚动；`ratatui-image` 会跳过图像区域 |
| 2 | 音频回调里加锁会影响播放 | 用无锁环形缓冲（单生产者单消费者）或 `try_lock` 失败即跳过 |
| 3 | 20fps 刷新在低配机器上抖 | 实测 CPU；超过 15% 就降到 12fps |
| 4 | 中文标题在面板里对不齐 | 用 `unicode-width` 算宽度，`TestBackend` + 真机各验一次 |
| 5 | 沉浸模式恢复时 Sixel 重绘慢 | 两种模式共用同一个 `Protocol`，不重新编码 |
