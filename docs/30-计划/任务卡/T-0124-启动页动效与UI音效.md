## 0. 事实基线

- 启动页 `splash.rs` 目前只在事件到达或 resize 时重绘，`event::poll(200ms)`。
- `logo.rs` 输出 6 行、66 列的 NOWHERE 字形；72×24 下内区 70 列。
- Windows Terminal 的 BEL 默认不可靠；不采用终端 bell。
- 项目禁止新增第三方依赖。

## 1. 目标

### 动效

- 新增 `ui/motion.rs` 或等价模块，提供时间相位、sine pulse、RGB 插值。
- 启动页局部 30fps 重绘：上下浮动 ±1 行、宽屏左右 ±1 列、accent/fg 呼吸、450ms 亮度渐入。
- 保留静态 `draw_splash`（phase=0）供 golden 使用；新增 `draw_splash_at(phase)` 供运行期。
- 新增 `ui.motion` 设置，默认开；`NP_TUI_NO_ANIM=1` 强制静态。
- 终端高度不足或宽度不允许时自动降级，不 panic。

### 音效

- 新增 `sound.rs`：Windows `PlaySoundW` + 内存合成 WAV，零 crate、零资源文件。
- 4 个音色：移动、切焦点、确认、返回；低振幅、短促。
- 只在状态实际变化时播放：列表下标变化、焦点变化、确认成功、Esc 返回。
- 35ms 去抖；打字、搜索、弹幕输入不响。
- 新增 `ui.sound` 设置，默认开；非 Windows no-op。

## 2. 非目标

- 不引入 `tachyonfx` / `tui-shimmer` / `rodio`。
- 不做全屏 60fps 动画。
- 不做独立音量滑杆；使用系统音量。
- 不播放背景音乐或长音效。

## 5. 结果

2026-11-21：

- 动效：新增 `ui/motion.rs`：
  - `bob`（3.6s）、`sway`（5.2s）四舍五入到 `-1/0/1`，`breath` 0..1，
    `blend` 只对 RGB 插值、非 RGB 返回原色；模块内不持全局时钟。
  - 启动页运行期 30fps（`event::poll(33ms)`，超时也重绘），`draw_splash()` 保留为
    phase=0 静态入口，新增 `draw_splash_at(phase)`；`ui.motion=false` 或
    `NP_TUI_NO_ANIM=1` 时静态、200ms poll。
  - 只有 6 行 LOGO 上下 ±1 行、宽屏左右 ±1 列，左对齐按精确 x 坐标绘制；主题名与
    Press Enter 固定居中。LOGO 从正文色 450ms 渐入，并在正文色与 accent 之间
    35% 幅度呼吸，不闪烁。
  - 窄 / 矮终端自动禁用 sway 或回退原居中排版，不 panic；切主题用当前 phase 重绘。
- 音效：新增 `sound.rs`（零 crate、零资源文件）：
  - Windows `PlaySoundW` + `SND_MEMORY|SND_ASYNC|SND_NODEFAULT`，非 Windows no-op；
    WAV 缓冲区放 `OnceLock`，异步播放期间只读、活到进程结束。
  - 启动时合成 4 个 44.1kHz mono 16-bit WAV：Move 1.8kHz/12ms、Focus 1.2kHz/18ms、
    Confirm 880+1320Hz/70ms、Back 600Hz/18ms，带 attack/decay，峰值约为 i16 上限的
    14%–20%。
  - `SoundPlayer` 保存开关与上次发声时间，35ms 去抖；`controller::execute` 对比
    before/after 的 focus / view_index / row_index 后发声，设置编辑态
    ←/→/Enter/Esc → Move/Confirm/Back；Quit 与播放控制不响；打字、搜索、命令、
    弹幕输入不响。
- 设置：`FIELDS` 末尾追加「动效 / 音效」，默认 true；动效切换提示「下次启动生效」，
  音效切换立即 `app.sound.set_enabled` 并保存。

  - `cargo test -p np-tui`：328 passed / 0 failed / 1 ignored（新增 motion 5 条、
    sound 4 条、splash 网格/降级 3 条、设置 3 条）；
  - `cargo clippy -p np-tui --all-targets -- -D warnings`：通过；
  - `cargo build -p np-tui`：通过，PE 导入表含 `WINMM.dll` / `PlaySoundW`；
