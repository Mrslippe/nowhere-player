## 0. 事实基线

| 项 | 当前值 |
|---|---|
| 登录态 | `np-live::BiliAuth`，SESSDATA/bili_jct/DedeUserID |
| Transport | GET + `get_with_headers`；无 form POST |
| 发送 API | `POST https://api.live.bilibili.com/msg/send` |

## 1. 背景

登录态已可用；先做无 UI 的弹幕发送层，Live 页的 `c chat` 后续直接调用。

## 2. 目标

- `Transport` 增加 `post_form`（窄接口，FakeTransport 可测）。
- `np-live::danmaku::send_danmaku(transport, auth, room_id, message) -> Result<(), DanmakuError>`。
- 使用 cookie、`csrf=bili_jct`、`csrf_token=bili_jct`、`roomid`、`msg`。
- 速率限制：同一连接至少 5s 间隔；重复内容不自动重试。
- 错误映射：未登录、csrf 失效、风控、房间禁言、网络、服务端 code。
- 不打印 cookie 或完整请求体中的敏感值；测试用假 Transport，不触网。

## 3. 非目标

- 不做输入框/快捷键/本地回显；
- 不做弹幕接收；
- 不改登录 UI。
