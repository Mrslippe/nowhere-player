## 0. 事实基线

- 标题栏当前只在顶部 32px 热区呼出，但显示/隐藏是瞬时的。
- 控制条当前只要鼠标在客户区内就显示，即使鼠标在视频中间也不收起。
- 控制条高 40dp，距底边 12dp；标题栏高 32dp。
- 视频 surface 始终是完整客户区；overlay 显示/隐藏不能 resize 视频。

## 1. 呼出热区

### 标题栏

- 保持顶部 32dp 热区；
- 只有鼠标进入该区域才呼出；
- 鼠标离开后按现有 500ms 延迟收起；
- 鼠标在窗口中下部时，即使仍在窗口内也收起。

### 控制条

- 隐藏时：只有窗口**底部 40dp 热区**能呼出（与显示时控制条高度一致）；
- 显示后：鼠标在控制条本身或底部 40dp 热区内都保持；
- 鼠标离开这两块区域后，**即使仍在窗口内**，2 秒后收起；
- 不再因为鼠标在客户区任意位置而一直显示；
- 拖动音量 / 菜单展开期间不收起。

## 2. 动画

- 标题栏：从顶部 `-height` 滑到 `0`；
- 控制条：从底部 `client_h` 滑到 `bar.top`；
- 呼出 160ms `ease-out`；
- 收起 140ms，从当前位置滑出，结束后 `SW_HIDE`；
- 定时器从 50ms 调整为约 16ms，动画结束后仍保持低开销；
- 只移动 overlay，不改变视频 Rect、mpv 尺寸、标题栏/控制条内部布局；
- 动画中 hover 正常；动画结束后才隐藏，避免静态画面残影；
- 不支持 alpha 淡入，避免分层子窗口与 mpv surface 冲突。

## 3. 状态机

- 可见状态立即切换，overlay 位置由动画进度决定；
- 显示中再次触发显示 / 隐藏中再次触发显示，从当前偏移继续，不跳变；
- 收起完成后清空 hover；
- resize / DPI 变化时，显示中的 overlay 直接落到最终位置；隐藏中的 overlay 使用新几何；
- 关闭窗口 / 退出时停止动画，不等待。

## 6. 结果

**状态：完成（代码 + 单元测试 + 全量门禁）；T3 真机项未验证（未在真实桌面交互窗口里做鼠标滑动 / 截图，本机未做手工验收）。**

### 变更

- `crates/np-video/src/layout.rs`：
  - 新增 `CONTROL_HOTZONE_HEIGHT_DP`（= 控制条高度 40dp）与 `control_hotzone_rect(width, height, dpi)`：窗口最底部 40dp，横向覆盖控制条左右范围（左右各留 12dp 边距，与任务卡 §1 建议一致）；热区只由客户区尺寸与 DPI 决定，不随 overlay 显示 / 隐藏变化。
  - `ControlBarState::update` 增加 `dpi` 参数：隐藏时只认底部热区；显示时认控制条本体或热区；鼠标在中部 / 中下部（仍在窗口内）按既有 `CONTROL_HIDE_DELAY` 2s 收起；拖动 / 菜单的 `set_interacting` 语义保留。
  - 新增 `SlideAnimation`（`from`/`to`/`duration`/`start`/`Easing`，`offset`/`finished`）与 `ease_out_cubic` / `ease_in_cubic`；新增 `OverlaySlide`（`hidden`/`shown` 两个静止偏移 + 进行中动画，`begin_show` / `begin_hide` / `advance` / `set_geometry` / `stop`）与 `titlebar_hidden_offset` / `titlebar_shown_offset` / `controls_hidden_offset` / `controls_shown_offset`。全部是纯状态，不碰 Win32。
- `crates/np-video/src/host/mod.rs`：
  - `Host` 新增 `titlebar_slide` / `controls_slide: OverlaySlide`；启动按标题栏 `-height → 0`、控制条 `client_h → bar.top` 初始化。
  - 隐藏 → 显示：`ShowWindow(SW_SHOWNOACTIVATE)` 后置于当前偏移，再启动 160ms `ease-out`；每 tick 只 `SetWindowPos` 移动 overlay。
  - 显示 → 隐藏：从当前偏移启动 140ms `ease-in`，动画期间保持 overlay 可见，走完才 `SW_HIDE`；随后给被覆盖的视频区域标脏补画。
  - 显示中再次显示 / 隐藏中再次显示：`OverlaySlide` 从当前偏移续接，不跳变；收起完成后才清 `hovered_control`，动画期间 hover 正常。
  - resize / DPI：`sync_overlays` 先换新几何；显示中的 overlay 直接落最终位置，隐藏 / 正在收起的用新几何落隐藏位置并 `SW_HIDE`；`set_dpi` 复用同一路径。
  - 定时器 `50ms → 16ms`；`tick` 改为返回 `Option<CloseReason>`；隐藏只做 `ShowWindow(SW_HIDE)` + 非阻塞标脏（`RDW_INVALIDATE | RDW_ALLCHILDREN | RDW_ERASE`，去掉 `RDW_UPDATENOW`），避免在 `&mut Host` 借用期间重入 `WM_PAINT`；关闭 / 退出时 `shutdown` 停止动画。
  - 未改 `paint.rs`、主题、图标、控制条内部布局、协议、`np-tui/**`、`render.rs`；未新增依赖；未改视频 surface / mpv 尺寸。

### 未验证 / 风险

- **T3 全部未验证**：真实滑动观感（160ms / 140ms 的实际节奏、是否闪一下）、16ms 定时器在静止 / 动画时的 CPU 占用、暂停画面收起后的残影、125%–150% DPI 与跨屏拖动时的位置、hover / 音量拖动 / 清晰度菜单的真机回归；本轮未打开真实视频窗口做鼠标交互与截图。
- 暂停画面残影：收起结束用 `RedrawWindow(RDW_INVALIDATE | RDW_ALLCHILDREN | RDW_ERASE)` 标脏，由消息循环补画；mpv 的 `--wid` 子窗口在暂停时是否响应补画无法用单测覆盖，需 T3 确认。
- 控制条热区横向覆盖整个客户区；窗口底边左右 12dp 边距也能呼出（主线集成时从“仅控制条宽度”改为全宽）。
- resize / DPI 打断收起动画时按“立即落隐藏位置并 `SW_HIDE`”处理（不继续滑出），真机拖拽时的观感未验证。
- `host/mod.rs` 1791 行，低于 1800 硬上限但超过 800 目标线，`check-hygiene` 为 warning；`layout.rs` 1532 行同样超过 800 目标线。
