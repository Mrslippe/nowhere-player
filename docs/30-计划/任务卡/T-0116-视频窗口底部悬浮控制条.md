## 0. 事实基线

- 视频窗口是自建 Win32 宿主；客户区全部给视频，顶部 32px overlay 标题栏。
- 现有窗口按钮只有最小化/最大化/关闭；`np-video` 已有 mpv IPC（volume/pause、cache 遥测）。
- 用户要求基础控件：暂停、刷新、音量；清晰度由 T-0117 单独做。
- 必须等 T-0114/T-0115 完成后再施工，避免同文件冲突。

## 1. UI

底部悬浮控制条，**盖在视频上，不 resize 视频**：

```text
┌──────────────────────────────────────┐
│ 32px 悬浮标题栏                      │
│                                      │
│              视频画面                │
│                                      │
│  ▶/❚❚   ↻   🔊━━━━━━   1.5s         │
└──────────────────────────────────────┘
```

- 高度 40px（96 DPI 缩放），距底边 12px，左右留 12px；
- 深色半透明/纯色背景，与标题栏同一套 GDI 色板；
- 鼠标进入客户区时显示，离开 2 秒后隐藏；
- 鼠标在控制条上时不隐藏；
- 顶部标题栏显示/隐藏逻辑不变；视频 16:9 约束不变；
- 控制条是独立子窗口 overlay，z 序在视频 surface 之上，不改变 surface Rect。

## 2. 控件

- 播放/暂停：单击切换；图标 `▶`/`❚❚`；
- 刷新：单击回到 live edge；第一版走 TUI 重取当前 qn，再通过 T-0117 的 `load` 发回 mpv；
- 音量：静音图标 + 80px 滑杆；点击/拖动即时改 mpv，静音按键切换；
- 右侧小字显示 `cache_ms`（来自 T-0112 遥测），无数据时显示 `--`；
- 清晰度入口留给 T-0117，不在此卡画菜单。

## 3. 状态同步

- 暂停：`np-video` 本地暂停 mpv，并 stdout 发 `control paused 1/0`；TUI 只更新状态，不再回发 pause，避免双控制。
- 音量：`np-video` 本地改 mpv，并 stdout 发 `volume 65`；TUI 更新 `self.volume`/静音态；不回发。
- 刷新：stdout 发 `control refresh`；TUI 走当前清晰度重新取 URL，再发 `load <url>`。
- TUI 键盘 `space`/音量键仍可用；宿主事件到达后以宿主为准。

## 6. 结果

**状态：完成（代码 + 单元测试 + 门禁）；T3 真机项未验证（本机无法交互验证 Win32 窗口 / GDI 绘制）。**

### 变更

- `crates/np-video/src/layout.rs`：新增控制条纯几何与状态机。
  - `control_bar_rect`：高 40dp、距底边 12dp、左右各 12dp；只由客户区尺寸决定，不参与 `video_rect`，显示 / 隐藏不会 resize 视频（16:9 约束不变）。
  - `control_layout`：播放 / 暂停、刷新、静音、80dp 音量滑杆、清晰度、cache 小字；绘制与命中测试共用同一份几何。
  - `control_hit` / `slider_volume` / `control_bar_contains`；滑杆 x → 0–100 音量。
  - `ControlBarState`：鼠标在客户区显示；离开客户区 2s 后隐藏；鼠标在控制条上（仍在客户区）不隐藏；拖动 / 菜单期间 `set_interacting` 阻止收起。
- `crates/np-video/src/host/mod.rs`：
  - 新增 `NowherePlayerVideoControls` 独立子窗口 overlay，Z 序在视频 surface 之上；`resize_client` 只移动 / 缩放 overlay，不经手视频 Rect。`WS_CLIPSIBLINGS` 保证 surface 重绘不盖掉控制条。
  - 50ms 定时器 tick 同时驱动标题栏与控制条状态；显示 / 隐藏走 `ShowWindow` + `RedrawWindow`。
  - 鼠标处理：播放 / 暂停、刷新、静音、音量滑杆点击 + 拖动（`SetCapture` / `WM_CAPTURECHANGED` 兜底）、cache 小字每秒级刷新。
  - `Control` 通道新增 `Load(String)`（供 T-0117）；TUI 的 `volume` / `pause` 本地应用但不再回发事件。
  - 本地播放 / 暂停与音量变化通过 stdout 发 `control paused 1|0`、`volume 65`；刷新发 `control refresh`。
- `crates/np-video/src/host/paint.rs`：控制条 GDI 绘制（背景、上 / 下边线、播放 / 暂停 / 刷新 / 喇叭图标、音量轨道 + 进度 + 圆点、清晰度文字、cache 文字），沿用标题栏色板。
- `crates/np-video/src/protocol.rs`：`Event` 增加 `Paused` / `Volume` / `Refresh` / `Quality` 单行事件；新增 `quality` / `current_qn` 请求字段与 `validate_stream_url`。
- `crates/np-video/src/mpv_ipc.rs`：新增 `cache_ms` 原子读数（无数据 `None`），供控制条小字使用；命令日志只记字节数，不记内容。
- `crates/np-tui/src/video.rs`：解析 `control paused` / `volume` / `control refresh` / `control quality`；宿主事件到达后更新 `state.audio`，`poll_video` 把音量同步回 `self.volume`、把暂停同步回 `live_state`，**不回发** pause/volume，避免双控制。
- 未触碰 `crates/np-tui/src/render.rs`（用户 WIP）。

### 未验证 / 风险

- **T3 全部未验证**：控制条真实出现 / 2s 收起、按钮 hover 观感、滑杆拖动、静音、cache 小字刷新、窗口缩放 / 最大化 / 高 DPI 下的 GDI 绘制。
- 控制条是纯色背景（未用分层透明度）；与视频画面的对比度需真机确认。
- 极小窗口（宽度 < 约 300dp）时右侧清晰度 / cache 与滑杆会互相挤压；窗口最小尺寸 400×225 下可用，但未逐一真机验证。
- 控制条显示期间不改变视频内容尺寸；mpv 仍按 `--keepaspect` 在 surface 内 letterbox。
