### 1.1 尺寸规则

| 区域 | 高度/宽度 |
|---|---|
| 顶部标题栏 | 1 行（`Block` 上边框嵌标题） |
| 左栏 | **22 列固定**，不收起（产品已定） |
| 中栏 | 剩余宽度 |
| 播放器条 | **10 行固定**（封面 8 行 + 标题/进度/视觉各 1–2 行） |
| 状态栏 | 1 行（底部，反白或 accent 前景） |
| 命令输入行 | **1 行**，仅在 Command / Filter 模式出现 |

**注意**：输入行不再常驻。Normal 模式下不显示，`:` 或 `/` 才出现并占据底部一行。

### 1.2 焦点模型

```rust
enum Focus { Library, List }
```

- `Tab` 切换；焦点栏边框 `accent`，非焦点 `faint`。
- 播放器条与状态栏**不可聚焦**。
- 焦点在左栏时按 `Enter` → 切到中栏；焦点在中栏时按 `Esc` → 回到左栏。

### 1.3 左栏内容（视图树）

| 项 | 数据来源 |
|---|---|
| 媒体库 | `library list` |
| 搜索结果 | 最近一次 search 结果（无则灰显） |
| 队列 | `queue list` |
| 歌单 | `playlist list`，每个歌单一行 |

- 第一次进入时默认选中「媒体库」并加载。
- **中栏显示左栏选中项的条目**。

## 6. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | 小窗口（< 80×20）布局崩 | 定义降级：先收播放器条 → 再收左栏 → 最后只留列表 |
| 2 | 左栏数据要在启动时加载四次（库/搜索/队列/歌单） | 懒加载：进入视图才查 |
| 3 | 播放器条固定 10 行会挤压小屏 | 见降级规则；`< 24` 行时降到 6 行 |
| 4 | Sixel 封面在横向条里高度小 | 封面取 8 行；Sixel 任意尺寸都支持 |
