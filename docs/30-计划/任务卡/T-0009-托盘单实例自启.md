## 1. 背景

M0 的收尾能力：让应用"像个常驻桌面程序"——关掉窗口不退出、托盘能唤回、开机自启、二次启动不重复开进程。

## 2. 目标

1. **托盘**：图标 + 菜单（显示/隐藏播放器、打开终端、开机自启 ✓、退出）。
2. **关闭到托盘**：点播放器窗的关闭（当前无边框窗没有关闭按钮，改为 `Ctrl+W` 或托盘菜单隐藏），进程保留。
3. **单实例**：第二次启动唤起已有实例的播放器窗，不产生新进程。
4. **开机自启**：托盘菜单可勾选，调用系统注册。

## 3. 非目标

- 不做托盘图标动态（播放/暂停状态图标）。
- 不做托盘气泡通知。
- 不做窗口位置记忆（`window-state` 插件留到 M1）。
- 不动 `crates/np-system`（见 §6.2）。

## 6. 实施要求

### 6.1 插件

允许新增 Rust 依赖（仅限这三个）：

- `tauri-plugin-single-instance`（2.x）
- `tauri-plugin-autostart`（2.x）
- `tauri` 启用 `tray-icon` feature

### 6.2 代码归属（重要）

**托盘逻辑写在 `apps/desktop/src-tauri/src/` 里，不要放进 `np-system`。**
原因：托盘 API 需要 `AppHandle`，而 `np-system` 按规范不得依赖 tauri（见结构规范 §3）。`np-system` 留给以后不需要 AppHandle 的平台能力（如媒体键的底层封装）。

建议拆文件：

```
src/
├─ lib.rs          # 装配：插件注册 + setup
├─ windows.rs      # 现有窗口创建逻辑迁出
├─ tray.rs         # 托盘菜单与事件
└─ shortcut.rs     # 现有全局快捷键
```

拆分是为了让 `lib.rs` 保持在 60 行以内；不要求过度设计。

### 6.3 行为细节

| 行为 | 要求 |
|---|---|
| 托盘左键单击 | 显示/聚焦播放器窗 |
| 托盘右键 | 弹出菜单 |
| 菜单项 | `显示播放器` / `打开终端 (Ctrl+Shift+P)` / `分隔线` / `开机自启`（勾选态） / `退出` |
| 关闭播放器窗 | 拦截 `CloseRequested`，改为 `hide()`；日志 `[window] player hidden to tray` |
| 退出 | 只有托盘菜单"退出"和 `Ctrl+Q` 真正退出（`app.exit(0)`） |
| 单实例 | 第二次启动时显示已有播放器窗并聚焦（回调里 `show + set_focus`） |
| 自启 | 托盘菜单点击切换，调用 `autostart` 插件的 enable/disable，勾选态用 `is_enabled()` 回读 |

### 6.4 无边框窗口的关闭入口

播放器窗 `decorations: false`，没有系统关闭按钮。本卡需提供 `Ctrl+W` 隐藏窗口（注册为窗口级快捷键或前端 `keydown`），并在 README 记录。

## 7. 验收标准

- [ ] `cargo build -p nowhere-desktop` 通过，`cargo clippy --workspace --all-targets -- -D warnings` 零警告
- [ ] `pnpm -C apps/desktop tauri dev` 启动后**托盘图标出现**（附截图，Windows 任务栏右下角）
- [ ] 右键托盘有 4 个可点项 + 1 个分隔线，菜单文案与 §6.3 一致
- [ ] 点"显示播放器"能唤出/聚焦小窗
- [ ] `Ctrl+W` 后小窗隐藏、进程仍在（日志 `player hidden to tray`）
- [ ] 托盘"退出"后进程结束
- [ ] 二次启动（再跑一次 exe/`tauri dev` 的产物）不产生第二个进程，且唤出已有窗口
- [ ] 托盘"开机自启"勾选后，`is_enabled()` 返回 true（日志打印），再点变 false
- [ ] `pwsh scripts/check.ps1` 退出码 0（本卡可跑全量，无并行冲突）

## 8. 测试要求

- Rust：不为托盘菜单写单测（UI 事件难以单测）；但要为"菜单项构造"这类纯函数（如果有）写测试。
- 不要求 e2e。

## 11. 风险

- `tauri-plugin-single-instance` 必须是**第一个注册**的插件，否则不生效。
- 单实例验证需要跑两次真实可执行文件；`tauri dev` 下路径在 `target/debug/`，注意别把 dev server 起两次。
- macOS 上托盘叫菜单栏图标，位置不同但 API 一致；本卡只需 Windows 验证。
