## 1. 目标

把现有动效**全部映射到 DES-006 的八个角色**，删掉自造时长。

### 1.1 token 归并

| 新 token | 值 | 取代 |
|---|---|---|
| `--np-dur-instant` | 80ms | — |
| `--np-dur-fast` | 120ms | 旧的 `-fast`（同值） |
| `--np-dur-base` | 180ms | `-mid:220`、`-progress:200` |
| `--np-dur-slow` | 240ms | `-focus-in:220` |
| `--np-ease-standard` | `cubic-bezier(.2,0,0,1)` | 各处散写 |
| `--np-ease-decelerate` | `cubic-bezier(.05,.7,.1,1)` | `(.22,1,.36,1)` |
| `--np-ease-accelerate` | `cubic-bezier(.3,0,.8,.15)` | `(.4,0,1,1)` |
| `--np-ease-linear` | `linear` | — |

**旧的 `-mid` / `-progress` / `-focus-in` / `-focus-out` 全部删除**，不要留别名。

### 1.2 交互映射表

| 交互 | 角色 | 属性 | 时长 / 缓动 |
|---|---|---|---|
| 块（block）出现 | enter | opacity + translateY(4px) | base / decelerate |
| 错误卡出现 | enter | 同上 | base / decelerate |
| 候选弹层出现 | enter | 同上 | base / decelerate |
| **候选弹层关闭** | exit | opacity | fast / accelerate |
| **候选选中项移动** | select | background + 左缘条 | fast / standard |
| 输入框焦点条 | switch（聚焦）/ exit（失焦） | clip-path | base / decelerate；fast / accelerate |
| 焦点条**颜色** | — | 不动 | — |
| 播放器切歌 | switch | 交叉淡化 | slow / standard |
| 播放/暂停图标 | select | opacity + scale(.9→1) | instant / standard |
| 音量浮层 | enter / exit | opacity + translateY | base·fast |
| 控制键 hover | feedback | opacity | instant / standard |
| 进度填充 | progress | transform | linear（时长由数值定） |
| 播放器主题切换 | switch | 交叉淡化 | slow / standard |

### 1.3 五条规则的落实点

1. **禁用布局动画**：`grep` 所有 `transition.*width|height|top|left|margin` 应为 0。
2. **时长分级**：用户操作类不得 > 180ms（当前切歌 220ms 属系统状态，允许 240ms）。
3. **单元素单动效**：候选弹层的 enter 与 select 不得同时跑（select 只动背景，不动位移）。
4. **进入期可交互**：检查有无 `pointer-events: none`。
5. **reduced-motion**：全部 0ms，且**最终状态不变**（尤其焦点条要显示为全长）。

## 9. 风险

- **归并 token 会改动很多文件**，容易漏改一处导致某处动效时长变成默认 0 或 200ms（CSS 初始值）。**改完 grep 一遍所有 `transition` 的值是否都来自 var()**。
- 切歌从 220ms 提到 240ms 是**变慢**，要确认观感没有变拖沓；若变慢明显，允许切歌留在 220ms 并在回报里说明为何偏离规范。
- `reduced-motion` 下焦点条必须仍可见（显示全长），**不能因为 animation 归零而变成不可见**——这是最容易写错的地方。
