## 1. 背景

现在主题是写死在 CSS 里的（`[data-theme="graphite|amber|ice|phosphor"]`）。要让用户放一个 JSON 就能换色，需要一层加载器：读文件 → 校验 → 应用为 CSS 变量 → 出问题时回退。

## 2. 目标

1. **用户主题文件**：`<appdata>/themes/<id>.json`，结构见 §6.1。
2. IPC：`theme.list`（列出内置 + 用户）、`theme.apply { id }`、`theme.exportBuiltin { id }`（导出样例给用户改）。
3. 应用方式：把 tokens 写到 `document.documentElement.style`，`data-skin` 同步设置。
4. **对比度检查**：`fg`/`bg` < 4.5:1 时在终端输出一条 `hint`（不阻止应用）。
5. **安全模式**：应用后 300ms 检查哨兵元素尺寸，异常则回退到上一个可用主题并发一条错误块。
6. CSP：只允许 `self` + `asset:` 的图片与样式（见 §6.4）。

## 3. 非目标

- 不做主题编辑器 UI（M6）。
- 不做用户 CSS（L2）——只写契约文档（T-0030）。
- 不做社区分享。

## 6. 实施要求

### 6.1 主题文件格式

```jsonc
{
  "id": "my-theme",
  "name": "我的主题",
  "contract": 1,
  "skin": "plain",
  "tokens": {
    "bg": "#14100E", "bgElev": "#1E1916", "fg": "#E8DCC8",
    "fgMuted": "#A08D76", "accent": "#D98A3D", "danger": "#C6402F",
    "line": "rgba(255,255,255,.07)"
  }
}
```

- `contract` 必填；不等于 1 时**加载但给出警告**（未来升级用）。
- `skin` 必须是已知枚举（`plain` / `phosphor`），未知则回落 `plain`。
- `tokens` 缺项 → 用内置默认补，不报错。
- 颜色值只接受 `#RGB` / `#RRGGBB` / `#RRGGBBAA` / `rgba(...)`；其它形式视为非法，跳过该项。

### 6.2 应用

- 写 `<html>` 的 inline style（`--bg` 等），**不要**注入 `<style>` 字符串。
- 切换时先移除上一个主题写入的属性，避免残留。
- `color-scheme` 同步（暗色主题设 `dark`）。

### 6.3 安全模式（哨兵）

- 应用后 300ms 检查 `document.querySelector('[data-window] .np-player-card')` 的 `getBoundingClientRect()`：宽或高为 0 → 判定崩坏。
- 崩坏时：回退到 `graphite`（内置，永远可用），发一条 `E_THEME_BROKEN` 错误块，并在控制台打印被回退的主题 id。
- 只尝试一次，不循环。

### 6.4 CSP

`tauri.conf.json` 的 `app.security.csp` 设为：

```
default-src 'self'; img-src 'self' asset: http://asset.localhost data:; style-src 'self' 'unsafe-inline'; script-src 'self'
```

> `style-src` 必须留 `'unsafe-inline'`（主题变量是 inline style）；`img-src` 必须含 `asset:` 与 Windows 的 `http://asset.localhost`。

### 6.5 xterm 主题（T-0028 留下的债，本卡一并清）

**问题**：`xterm-theme.ts` 在 JS 里硬编码 graphite 色值，xterm 画在 canvas 上读不到 CSS 变量。结果 `phosphor` 下终端左半边琥珀、右半边石墨（见 `docs/30-计划/截图/M4-phosphor-terminal.png` 第三格）。

**做法**：创建 `Terminal` 实例前，从 `getComputedStyle(document.documentElement)` 读 `--bg` / `--fg` / `--accent` / `--danger` / `--warn` / `--success` / `--fg-muted`，生成 `ITheme` 传给 `XtermSurface`。主题切换时 dispose 重建（xterm 不支持运行时换主题）。

**验收**：`data-theme="phosphor"` 下 `?variant=xterm` 截图必须是琥珀底，与左侧 blocks 视图同色系。

**非目标**：不做 xterm 的字体/行高跟随（它有自己的 fontFamily 配置，M6 再说）。

## 7. 验收标准

- [ ] `cargo test -p np-core` 通过：主题校验 ≥ 8 例（缺 contract、未知 skin、非法颜色、缺 token、`contract: 2`、空 id、超长 name、正常）
- [ ] `cargo test -p nowhere-desktop` 通过：3 个 IPC 名与参数映射
- [ ] `pnpm -C apps/web exec vitest run src/shared` 通过：加载器 ≥ 6 例（应用/回退/清理残留/非法值跳过/对比度警告/安全模式触发）
- [ ] `cargo clippy --workspace --all-targets -- -D warnings` / `fmt --check` 零问题
- [ ] 手动：放一个 JSON 到 `themes/`，`theme.list` 能看到，`theme.apply` 后窗口变色
- [ ] 手动：放一个 `bg` 与 `fg` 同色的主题，终端出现对比度 `hint`，但不崩
- [ ] CSP 生效后封面仍能显示（`asset:` 未被拦）

- 前端加载器用假 `document` 注入测试（jsdom 不可用，用最小 stub）。

## 11. 风险

- **CSP 是最容易打破现有功能的一步**：加上之后封面（`asset:`）、inline style（主题变量）、WebSocket（未来）都可能被拦。**必须逐项验证**，不能只看页面没白屏。
- 主题文件是用户输入：`id` 用于文件名，必须过滤路径分隔符。
- 安全模式的哨兵选择器要稳定（`[data-window] .np-player-card`），且**不能依赖播放器窗**——终端窗也要能判崩坏。
