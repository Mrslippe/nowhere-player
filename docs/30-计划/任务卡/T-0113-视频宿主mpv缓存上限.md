## 0. 事实基线

- T-0112 真机：`cache_ms≈5100–5300`、`speed=1.0`、`buffering=100`，持续 30s。
- mpv 默认 `--cache-secs=3600000`；`--demuxer-readahead-secs=1` 没有限制总缓存。
- 本地 `--cache-secs=1` 时 `Cache: 1.0s`。

## 1. 目标

- `mpv_args` 显式：
  ```text
  --cache=yes
  --cache-secs=1.5
  ```
- 不自动改 speed，不 seek。
- 日志字段 `duration` 改名 `cache_duration`，避免误认为媒体总时长。
- 真机观察 `cache_ms` 是否从约 5s 降到约 1.5–2s。

## 2. 非目标

- 不加 speed 追帧（T-0114 再做）。
- 不改 `--demuxer-readahead-secs`。
- 不改 TUI 音频链路。

## 3. 授权路径

```text
crates/np-video/src/mpv.rs
crates/np-video/src/mpv_ipc.rs
```

## 4. 验收

- [ ] `mpv_args` 含 `--cache=yes`、`--cache-secs=1.5` `[数字]`
- [ ] 单元测试覆盖参数 `[数字]`
- [ ] 真机 `mpv-cache cache_ms` 从约 5s 降到约 1.5–2.5s `[数字]`
- [ ] 视频不卡顿、音画正常 `[人工]`
- [ ] fmt/clippy/test `[数字]`

## 5. 结果

2026-11-20：

- 缓存上限固定 1.5s；日志字段改为 `cache_duration`。
- 待真机：如果 1.5s 卡顿，回退 2.0s；若稳定，再上 speed 追帧。
