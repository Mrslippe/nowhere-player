## 1. 背景

产品原话：「终端和播放器显得突兀，原因在于它们没有合适的边框，但系统默认边框又太丑」。

**结论**：加自绘边框，不用系统 decorations。

## 2. 目标

### 2.1 边框规格

| 项 | 值 |
|---|---|
| 宽度 | **1px**（视觉上是"边缘高光"，不是"框"） |
| 颜色 | 顶部偏亮、底部偏暗的**渐变**：`linear-gradient(to bottom, rgba(255,255,255,.10), rgba(255,255,255,.04))` |
| 实现 | **`box-shadow: inset 0 0 0 1px`**，不用 `border`（避免改变盒模型尺寸） |
| 圆角 | 跟随容器（播放器卡 14、终端 0） |

### 2.2 两个窗口

**播放器**：卡片本身加这圈 1px；与已有的 1px 内高光合并成一条（不要叠两层）。

**终端**：窗口根容器加同一圈 1px（`inset 0 0 0 1px`），顶栏与内容区之间保持现有的 1px 分隔线。

### 2.3 顶栏（终端）

- 已有 34px 自绘顶栏 + 最小化/关闭，**本卡只做视觉对齐**：
  - 顶栏底部与内容区之间那条 1px 线，颜色与边框同源；
  - 窗口控制钮 hover 底色与边框色协调。

### 2.4 两套 skin

- `plain` 与 `phosphor` 都要有边框；`phosphor` 的边框可以更弱（它本来就是全出血）。
- 边框色从 token 取值，**不要在组件里写死 rgba**。

## 3. 非目标

- 不改窗口尺寸、不留新边距（边框画在既有内容边缘内）。
- 不加标题栏到播放器（产品明确：标题栏只给终端）。
- 不做窗口吸附、不做点击穿透。
- 不做"聚焦/失焦时边框变亮"（可作为后续）。

## 10. 风险

- **1px 边框在 125%/150% DPI 下可能变成 1.5px 或消失**：用 `box-shadow` 时浏览器会做亚像素渲染，一般没问题，但要实际截一张高 DPI 的图确认。
- **边框与阴影的关系**：边框是"边缘高光"，阴影是"离开桌面"，两者叠加时别让边框被阴影吃掉（浅色壁纸上最容易）。
- 终端是 880×560 的整块窗口，**四周都加边框会让它看起来像一个大卡片**；如果视觉上太重，可以只保留顶部与左右，底部省略（回报里说明选择）。
