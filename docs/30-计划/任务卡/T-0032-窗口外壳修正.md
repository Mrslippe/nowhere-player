## 1. 背景

真机验收发现 6 个问题，全部来自"窗口外壳"这一层——它们是 dev 期用截图验证看不到的，只有真跑在桌面上才暴露。

## 2. 问题清单（产品原话）

**播放器窗**

| # | 问题 | 判定 |
|---|---|---|
| P1 | 拖动不了 | 窗口没有可拖拽区域 |
| P2 | 边缘有白色描边，影响桌面挂件观感 | Windows 11 给无边框窗口画的 DWM 边框 + 圆角 |
| P3 | 边缘能拖动改变宽高 | 窗口可缩放，但产品不需要 |
| P4 | 滚轮能改音量，但界面上没有音量标识 | 缺反馈 |

**终端窗**

| # | 问题 | 判定 |
|---|---|---|
| T1 | 系统默认标题栏太突兀 | 改为自绘标题栏 |
| T2 | 滚动条样式与美学风格差异大 | 重绘滚动条 |

## 3. 目标

### 3.1 播放器窗

1. **可拖动**：整张卡片作为拖拽区（`data-tauri-drag-region`），**控件与进度条区域不可拖**。
2. **无描边**：窗口 `transparent: true` + `decorations: false` + `shadow: false`，由 CSS 自己画背景；确保 Windows 11 不再出现 1px 亮边与圆角。
3. **不可缩放**：`resizable: false`，同时去掉窗口边缘的 resize 热区。
4. **音量反馈**：滚轮改动后显示一个 1.2s 的浮层（如 `音量 42%`），跟随再次滚动重置计时；静音显示 `静音`。

### 3.2 终端窗

5. **自绘标题栏**：`decorations: false`，顶部 32–36px 的自绘栏，含：标题文字、拖拽区、最小化、关闭按钮（关闭 = 隐藏到托盘，不是退出）。
6. **滚动条重绘**：`::-webkit-scrollbar` 全套（宽 10px、圆角、`--line` 轨道、`--fg-faint` 滑块、hover 变亮），两套 skin 都要协调。

## 4. 非目标

- 不改终端内容区布局。
- 不改播放器卡片内部布局（T-0031 刚做完）。
- 不做窗口吸附/置顶开关。
- 不做标题栏的主题切换按钮（M6）。

## 6. 实施要求

### 6.1 拖动

- 拖拽区用 `data-tauri-drag-region` 属性，**加在卡片背景层**，不要加在 `button` 上。
- 若卡片内有子元素覆盖整块，需要把这些子元素的该属性一并声明或设 `pointer-events` 兼容。
- **验收**：能拖动、点点控制键不会拖动、拖动时不触发播放/暂停。

### 6.2 白边与圆角

> **先验假设**：P2 与 P3 可能是同一个根因。Windows 11 会给带 `WS_THICKFRAME`（可缩放）的窗口画 1px 边框与圆角。设 `resizable: false` 后 THICKFRAME 消失，白边与圆角可能一起没了。**先试这一条，再决定要不要 `transparent`。**

- `tauri.conf.json` 播放器窗：`resizable: false`、`decorations: false`、`shadow: false`；`transparent` 按上面假设的结果决定（能不加就不加，透明窗有合成开销）。
- 若设了 `resizable: false` 仍有 1px，再试 `transparent: true` + CSS 铺底。
- 背景由 CSS 画：`html,body { background: transparent }`，卡片本身铺 `--bg`。
- **验收**：截一张桌面上窗口边界处的放大图（含壁纸），肉眼确认无亮边、无露底。

### 6.3 音量反馈

- 新增浮层 `.np-player-card__volume`：居中、半透明底、等宽数字、1.2s 后淡出。
- 位置：不遮挡封面与标题，建议在进度条上方居中。
- 复用已有滚轮 handler，不要新增监听。
- **验收**：滚轮 → 出现 → 1.2s 消失；连续滚动不闪烁（重置计时而不是叠加）。

### 6.4 终端自绘标题栏

- 高度 34px，与现有 `.np-lab__topbar` 合并（不要新增第二条栏）。
- 左侧：品牌/标题；中间：拖拽区；右侧：最小化、关闭（关闭 = `hide`，不是 `close`）。
- 按钮 32×24，hover 有底色，**不显示系统图标库之外的图形**（用简单 SVG 线条）。
- **窗口拖拽与内容滚动不能冲突**：标题栏的拖拽区不能覆盖内容区。

### 6.5 滚动条

- 轨道：`--line`；滑块：`--fg-faint`；hover：`--fg-muted`；圆角 999。
- 宽度 10px，`::-webkit-scrollbar-thumb` 加 `border: 2px solid transparent; background-clip: content-box` 使其比轨道窄。
- **暗底 + 琥珀主题下不能出现系统默认的浅灰滚动条**。

## 11. 风险

- **`transparent: true` 会连带影响性能与点击穿透**：窗口透明后 Windows 上合成开销略增，且需要确认点击仍能正常落到窗口上。
- 去掉系统标题栏后，**终端窗无法用系统按钮关闭**——自绘的关闭必须是"隐藏到托盘"，否则用户可能失手退出。
- 拖动区域设太大 → 用户点控件时窗口跟着动；设太小 → 拖不到。**必须两个方向都实测**。
- `resizable: false` 后如果某处代码依赖 resize 事件，会静默失效——检查一遍。
