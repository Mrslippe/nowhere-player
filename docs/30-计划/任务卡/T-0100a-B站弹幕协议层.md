## 0. 事实基线

- 依赖允许已确认，但当前 crates.io registry 不可达；`tungstenite`/brotli 无法拉取。
- 本卡只做协议数据层，不建立网络连接、不加依赖。
- 后续 T-0100a2 再接 `tungstenite` + 压缩。

## 1. 目标

在 `np-live` 新增纯 Rust 协议模块：

```text
16 字节包头 encode/decode
op=2 心跳包
op=7 认证 JSON 包
op=5 body 拆分
DANMU_MSG JSON 解析
用户/文本/颜色/时间字段
坏包/截断包返回可读错误，不 panic
```

- 不访问网络；
- 不加第三方依赖；
- 测试用构造包/fixture；
- 为后续 WS 客户端提供稳定接口。

## 2. 接口建议

```rust
pub struct DanmakuPacket { operation: u32, body: Vec<u8> }
pub fn encode_packet(op: u32, body: &[u8]) -> Vec<u8>;
pub fn decode_packets(bytes: &[u8]) -> Result<Vec<DanmakuPacket>, DanmakuProtocolError>;
pub fn auth_body(room_id, uid, protover, key) -> Vec<u8>;
pub fn heartbeat_body() -> &'static [u8];
pub struct DanmakuMessage { user, text, color, timestamp }
pub fn parse_danmu_msg(json: &[u8]) -> Result<Option<DanmakuMessage>, ...>;
```
