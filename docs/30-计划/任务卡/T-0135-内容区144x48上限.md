## 0. 事实基线

- Ratatui 当前使用整个终端区域，窗口拉大时 Browse/List/Player 全部拉伸。
- Windows Terminal 的窗口大小由终端控制；应用只能控制内容布局。
- 默认内容尺寸 72×24。

## 1. 目标

- 新增布局上限：内容区最大 144 列 × 48 行，居中绘制。
- 终端更大时：先清整个终端背景，再只在居中的 144×48 区域画 UI。
- 终端小于上限时行为与现在完全一致。
- 启动请求尺寸仍为 72×24；不强制改变用户终端窗口。
- `layout` 暴露纯函数 `content_area(area)`；72×24、100×30、160×50、200×60 单测。
- 所有绘制入口（外框、三区、状态栏、Controller、登录层）都使用 capped area。

## 2. 非目标

- 不通过 Win32 强制限制 Windows Terminal 窗口尺寸。
- 不改 72×24 设计基线。
- 不改鼠标（未启用）。
