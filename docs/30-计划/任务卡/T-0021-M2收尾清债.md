## 1. 背景

M2 的功能卡都过了，但留下了四笔债。其中**两笔是我给卡的约束造成的**（禁改 `Cargo.toml` → 手写 JSON；没要求 `onError` → 订阅失败静默）。技术债要连"为什么会有这笔债"一起清，否则下次还犯。

## 2. 四笔债与做法

### 2.1 `cmd.exec` 的返回值是手写 JSON

**现状**：`src-tauri` 不是 `serde` 直接依赖，不许改 `Cargo.toml`，所以手写 `IpcResponse` + 字符串拼装。

**做法**：给 `apps/desktop/src-tauri/Cargo.toml` 增加 `serde = { version = "1", features = ["derive"] }`（该 crate 已在依赖树里，零新增体积），把返回结构改成派生 `Serialize` 的小结构体，删掉手写拼装与对应的转义测试。

### 2.2 `terminal:block` 订阅失败时静默

**现状**：订阅失败后命令回执仍 `ok`，但块永远不出现，用户只看到"输入了没反应"。

**做法**：
- `command-bridge.ts` 的 `subscribeBlocks` 增加可选 `onError` 回调；`listen` 失败时调用一次。
- 终端窗收到后：推入一条本地 `error` 块（`code: "E_STREAM_LOST"`，message "实时输出不可用，请重开终端窗"），并设置一个可重试标记（不自动重试，避免刷屏）。

### 2.3 `clear` 之后在途的最终块会追加回来

**现状**：`clear` 清空块数组后，若某条命令的最终块还在路上，会按 id 追加。

**做法**：清空时记录 `clearedAt` 时间戳（或维护 `ignoredIds` 集合）；`upsertBlock` 收到 `startedAt < clearedAt` 的块时丢弃。**用 `startedAt` 而不是到达时间**——到达时间不可靠。

### 2.4 前端 `APP_VERSION` 硬编码 `0.0.0`

**做法**：改用 `@tauri-apps/api/app` 的 `getVersion()`（运行时读取，无需构建期注入、不用改 `vite.config.ts`）；浏览器 mock 下回退 `"0.0.0"`。欢迎块改为异步获取（拿不到就显示版本未知，不阻塞首屏）。

## 3. 非目标

- 不做异步 `cmd.exec`（当前同步执行满足"发一条即见事件"）。
- 不做 `Ctrl+R` 反向搜索。
- 不做弹层鼠标点选。
- 不动 `np-audio` / `np-core` 的领域逻辑。

## 10. 风险

- 加 `serde` 后 `Cargo.lock` 会变（已存在，不会新增下载）——这是预期内的。
- `getVersion()` 是异步的：不要让它阻塞首屏渲染，欢迎块可以先渲染后补版本。
- 丢弃旧块要小心误杀：`clear` 后用户立刻敲新命令，新块的 `startedAt` 一定大于 `clearedAt`，测试要覆盖这个边界。
