## 1. 目标

### A. 补全弹层

**布局**：输入行**上方**固定 **6 行**区域（无候选时留空，不重排布局）。

```
┌ 候选 ────────────────┐
│ search  命令          │
│ search [关键词] …      │
│ ◀ 高亮               │
└──────────────────────┘
› sea█
```

| 行为 | 键 |
|---|---|
| 打开 | 输入变化后 80ms 防抖 |
| 移动 | `↑`/`↓`（仅非历史导航时） |
| 采纳 | `Tab` → 采纳当前高亮；`Enter` → 执行（不采纳） |
| 关闭 | `Esc`；继续输入且无匹配时自动关 |
| 历史导航中 | **不显示候选** |

**必须复用** `np_app` 的补全函数（`cmd.complete` 对应的 Rust 实现），**不要在 TUI 重写一套命令表**。

### B. 在线搜索异步

- TUI 起**后台线程**跑 `run_online_search`，结果通过 `mpsc` 回主循环。
- 执行期间：块显示 `progress`（"搜索中…"），**输入行仍可打字**（不阻塞）。
- 后台线程**不得持有 UI 状态**；只回传 `Block`。
- 超时/失败：回 `error` 块，不 panic。

### C. 真实封面

- 播放曲目时按 `track_id`（路径或远程 id）解析封面：
  - 本地：`np-library` 已存封面文件 → 路径。
  - 远程：缓存封面（`np-library::store_cover`）→ 路径。
- 找不到 → 字符占位（现状保留）。
- **不发起网络请求**（封面在搜索/播放准备阶段已落盘）。

## 6. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | **弹层占 6 行会让内容区变矮** | 无候选时该区域可显示"最近一条输出"，或改为覆盖式绘制 |
| 2 | 在线搜索阻塞主循环 | 强制线程 + channel；**禁止**在渲染路径里做网络 |
| 3 | `np-app` 补全函数可能返回数据但 UI 已变 | 每次结果带请求序号，过期回包丢弃 |
| 4 | 封面路径解析失败导致面板空白 | 失败回退字符占位，并打日志一行 |
