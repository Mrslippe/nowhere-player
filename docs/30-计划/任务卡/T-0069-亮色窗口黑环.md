## 0. 现象

亮色主题（`tui-paper`，底 `#f2efe9`）下，**Windows Terminal 的 padding 区域仍是 profile 的黑色背景**，视觉上一圈黑围着白色界面。

## 1. 根因

| 层 | 说明 |
|---|---|
| **WT padding** | fragment 里写了 `padding: 10,10,10,10`，该区域用 profile 背景色绘制 |
| 未绘制单元格 | 已解决（整屏铺主题底） |
| 标题/标签栏 | WT 装饰，本卡不处理 |

## 2. 方案（按顺序实施）

### A. padding 归零 + TUI 自绘内边距

- fragment：`"padding": "0,0,0,0"`；
- TUI 在主题模式（有显式 bg）下，**在内容区外画 1 格主题底色**作为视觉留白。

**效果**：黑环消失，且留白颜色由主题控制。

**注意**：跟随终端模式（无主题）**不画**这层留白，否则会覆盖用户终端背景。

### B. OSC 11 运行时设置终端背景（增强，需先探测）

```
设置：\x1b]11;#rrggbb\x1b\\      （ST 结尾）
恢复：\x1b]111\x1b\\
```

- **先探测**：启动时发 OSC 11 查询（`\x1b]11;?\x1b\\`），读取响应判断终端是否支持。
- **支持则**在切到有 bg 的主题时设置；退出/切回跟随模式时恢复。
- **不支持则跳过**，只靠 A。
- **不得**假设支持——WT 对"设置"的支持需实测确认。

### C. 兜底：双 profile

若 A+B 后仍明显，提供 `nowhere-dark` / `nowhere-light` 两个 profile，`theme set` 提示用户切到对应 profile（不自动重启）。

**本卡不实现 C**，仅在回报里说明是否需要。
