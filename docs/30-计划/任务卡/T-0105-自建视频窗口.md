## 0. 目标

把外部播放器窗口升级为自建 Win32 宿主窗口：

```text
原生 WS_THICKFRAME / MAXIMIZEBOX
+ WM_NCCALCSIZE 去掉系统标题栏
+ 自定义悬浮标题栏
+ mpv --wid 嵌入
```

### 用户确认的两条硬约束

1. **隐藏后顶部热区 = 标题栏高度**（32px），不是 4px；
2. **标题栏直接覆盖在视频上**，显示/隐藏都不 resize 视频子窗口。

## 1. 窗口

- 创建 `WS_OVERLAPPEDWINDOW`；
- `WM_NCCALCSIZE` 去掉 caption；
- `DwmExtendFrameIntoClientArea` 保留阴影/边框；
- 保留 `WS_THICKFRAME | WS_MAXIMIZEBOX | WS_MINIMIZEBOX`；
- 处理 `WM_GETMINMAXINFO`、`WM_DPICHANGED`；
- 标题栏 overlay 在客户区顶部，视频子窗口始终占满客户区。

## 2. 标题栏

```text
高度：32px @ 96 DPI
左侧：Nowhere Player · 房间标题
右侧：最小化 / 最大化 / 关闭
```

- 标题栏是宿主窗口的 overlay 子窗口，盖在视频上；
- 显示/隐藏只 `ShowWindow`，**不改变视频子窗口 Rect**；
- 隐藏后保留 32px 顶部热区；
- 用定时器轮询 `GetCursorPos` 检测热区/hover，避免 mpv 子窗口吞掉鼠标移动；
- 鼠标离开后延时收起；
- 拖动、缩放、菜单期间不收起；
- 点击标题栏空白：向宿主发送 `WM_NCLBUTTONDOWN` / `HTCAPTION`；
- 最大化按钮：`HTMAXBUTTON`，尽量保留 Windows 11 Snap Layouts；
- 关闭：`WM_CLOSE`。

## 3. mpv 嵌入

```text
mpv.exe
  --wid=<video_hwnd>
  --no-audio
  --no-osc
  --no-osd-bar
  --force-window=no
  --input-ipc-server=\\.\pipe\nowhere-video
```

- 视频 URL/header 通过 stdin 传入，不放在命令行；
- stdout/stderr 不继承；
- TUI 关闭时 kill/wait；
- 不做自定义暂停/进度。

## 4. 进程

新增 `crates/np-video` 二进制：

```text
np-tui 启动 np-video.exe
stdin: {url, headers}
stdout: ready / closed / error
```

- 单窗口、单实例；
- 视频窗口关闭通知 TUI；
- TUI `v` 打开/关闭；
- 停播/换房/F5/退出关闭；
- 失败时回退现有 mpv/ffplay 外部窗口或中文提示。

## 7. 风险

- overlay 标题栏与 mpv 子窗口的 z-order/焦点；
- HTMAXBUTTON 在子窗口上可能无法触发 Snap Layouts；
- 32px 热区会挡住顶部 32px 的视频鼠标事件；
- `WM_NCCALCSIZE` 最大化裁切、DPI；
- mpv --wid 的 resize/焦点/退出；
- 4–6 天是含真机调试的估计。
