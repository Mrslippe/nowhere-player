## 1. 目标

### A. Normal 模式键位（DES-012 §4）

**全局**

| 键 | 动作 |
|---|---|
| `Space` | 播放 / 暂停 |
| `n` / `p` | 下一首 / 上一首 |
| `+` / `-` | 音量 ±5%（状态栏短暂显示新音量） |
| `Tab` | 切焦点 |
| `/` | Filter 模式 |
| `:` | Command 模式 |
| `?` | Help 覆盖层 |
| `q` | 退出（播放中二次确认） |

**中栏（列表）**

| 键 | 动作 |
|---|---|
| `j`/`k`、`↑`/`↓` | 移动 |
| `gg` / `G` | 首 / 尾 |
| `Enter` | **播放选中项** |
| `a` | 加入队列 |
| `d` | 从歌单移除（仅歌单视图） |
| `f` | 切视觉模式（频谱/波形/矢量） |
| `Ctrl+F` | 沉浸模式 |

**左栏（视图）**

| 键 | 动作 |
|---|---|
| `j`/`k` | 切视图 |
| `Enter` | 进入并聚焦中栏 |

### B. 三种模式

**Filter（`/`）**

- 底部出现单行输入；输入即时过滤**当前列表**；
- `Enter` 确认并保持过滤；`Esc` 清除过滤；
- 状态栏显示 `过滤: <关键词>`。

**Command（`:`）**

- 底部单行输入，**复用现有命令解析与执行**（`np-app` 不动）；
- `Enter` 执行、`Esc` 取消；
- 历史：`↑`/`↓` 翻上一条命令。

**Help（`?`）**

- 覆盖层（`Clear` + 居中块），列出当前模式全部键位；
- 任意键关闭。

### C. 命令与键位共存

- 所有现有命令**仍然可执行**；
- **`/` 以 `!` 开头 → 转 Command 模式**（`/!search 晴天` 等于 `:search 晴天`）；
- `Enter` 播放 = `play <当前行>`；两者结果必须一致。

## 5. 测试要求

- 键位 → 动作映射：表驱动单测（每行一个用例）。
- 模式状态机：Normal/Filter/Command/Help 四态转换全覆盖。
- 过滤函数：纯函数，中文/大小写/空词各一例。

## 6. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | 单键操作误触（`d` 删除） | 删除类必须二次确认；`dd` 才执行 |
| 2 | `gg` 需要超时判定 | 300ms 内连按才算；超时重置 |
| 3 | Filter 与 Command 输入行共用，状态易串 | 一个 `InputMode` 枚举，互斥 |
| 4 | 帮助覆盖层在窄窗口溢出 | 内容按宽度自适应折行，最小 60 列 |
| 5 | IME 在这两个输入行里的行为 | 沿用现有输入行（已验证可用） |
