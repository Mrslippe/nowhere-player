## 0. 事实基线

| 项 | 现状 |
|---|---|
| `TuiAudio::play(path)` | **`path.is_some()` 直接返回 `E_UNSUPPORTED`** |
| `Enter` 播放选中项 | 拼成 `play <n>` 走真实命令 → 同样报错 |
| `a` 加入队列 | 用**标题**入队，不是路径 |
| `n/p`、`+/-` | 只改状态提示，无真实行为 |
| 队列 | 内存里存的是标题字符串 |
| 结论 | **新界面能操作，但放不出声音** |

---

## 1. 目标：让"选中 → 播放"真的出声

### A. 行数据带身份

列表行必须能定位到**可播放资源**：

| 来源 | 身份 |
|---|---|
| 媒体库 | 文件路径 |
| 队列 | 文件路径（或远程 id） |
| 搜索结果（本地） | 路径 |
| 搜索结果（远程） | `(source, source_id)` |

- 表格行需要携带 `TrackRef`（枚举：`Local(PathBuf)` / `Remote{source, id}`）；
- **不能靠标题匹配**——同名曲目会串。

### B. `TuiAudio::play` 真正播放

```rust
fn play(&self, path: Option<String>) -> Result<PlaybackState, CmdError>
```

- `None` → 继续当前曲目（现状）；
- `Some(path)` →
  - 本地：直接交给 `np_audio::Player` 播放；
  - 远程：调 `np-app` 的 prepare（下载/缓存）→ 拿到本地缓存路径 → 播放；
- **不允许再返回 E_UNSUPPORTED**。

### C. 队列存路径

- `queue add` 存 `TrackRef`，不是标题；
- `queue list` 能从 `TrackRef` 还原标题（本地查库、远程用冗余元数据）；
- `n/p` 按队列真实步进；
- 队列空时给明确提示，不是静默。

### D. 音量

- `+/-` 调真实的 `np_audio::Player` 音量；
- 状态栏短暂显示百分比（2 秒后恢复）。

## 2. 非目标

- 不做连续播放（播完自动下一首）——另开卡。
- 不做远程预取。
- 不改 `np-app` 的命令语义（只补 TUI 侧的适配）。

## 3. 授权路径

```
crates/np-tui/**
```

**若 `np-app` 缺少"按 TrackRef 准备远程音频"的公开入口 → 停下来报告**，不要改 `np-app`。

## 5. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | 远程 prepare 是阻塞下载，会卡 UI | 走后台线程 + 消息（TEA 的 Message），期间状态栏显示"准备中" |
| 2 | 表格行加 TrackRef 会改 `Output::Table` 契约 | **不改契约**：行数据在 TUI 侧旁路保存（按行号索引），契约不动 |
| 3 | 队列存 TrackRef 后序列化/持久化 | 本卡只做内存队列，不持久化 |
| 4 | 远程 id 失效（下架） | 播放时给明确错误，不崩 |
