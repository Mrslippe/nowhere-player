## 2. 布局算式（**运行时计算，不写死**）

```rust
let inner = frame.area().inner(Block::default().borders(ALL)); // 外框
let [status, controller, player, top] = Layout::vertical([
    Constraint::Length(1),                                   // 状态栏
    Constraint::Length(3),                                   // Controller（常驻）
    Constraint::Length(player_h),                            // Player
    Constraint::Min(6),                                      // 上半区
]).areas(inner);

let player_h = (inner.height as f32 * 0.40).round() as u16;  // clamp 8..=14
```

| 窗口 | 上方区 | 列表数据行 |
|---|---:|---:|
| 100×30 | 13 | **≈9** |
| 140×40 | 19 | ≈15 |

## 3. 三块要点

### 3.1 外框

- `Block::bordered()`；
- 左上标题 `NOWHERE PLAYER v{版本}`（版本取 `env!("CARGO_PKG_VERSION")`）；
- 右上标题：**当前主题名**（`Alignment::Right`）。

### 3.2 Browse / List 共用框

- **一个** `Block`，内部用 `Layout::horizontal([Length(22), Length(1), Min(10)])` 分出竖线列；
- 竖线列手绘 `│`（颜色 `line`）；顶边在分隔处画 `┬`、底边画 `┴`；
- 标题：左 `Browse`、右 `List`（`title` / `title(Alignment::Right)`）；
- 底边两个 `title_bottom`：左 `1 of 7`、右 `total 4`（数字由数据算）。

### 3.3 Controller 常驻

- 永远显示，3 行（边框 2 + 输入 1）；
- 焦点三态：`Browse` / `List` / `Controller`；
- `:` → 焦点跳 Controller（**不是切换模式**）；
- `Esc` → 从 Controller 回 List 并清空输入；
- 输入法照旧（正在用的实现）。

## 7. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | `Block` 不支持 `┬/┴` 接点 | 竖线列单独渲染；顶/底边在分隔列覆写 `┬`/`┴` |
| 2 | 列表行数骤降影响可用性 | 已确认可接受；P1 不做进一步压缩 |
| 3 | Controller 常驻后 IME 焦点行为变化 | 沿用现有输入实现，只改可见性 |
| 4 | 版本号格式 | 用 `CARGO_PKG_VERSION`，不硬编码 |
