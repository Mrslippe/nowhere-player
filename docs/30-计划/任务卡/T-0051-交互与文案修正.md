## 2. 各项要求

### A. 琥珀露角

**根因**：下层卡 `inset: 0 0 -2px 0` 与上层同圆角、同顶边，两个圆角的抗锯齿叠加，在顶部左右角各漏出 1–2 像素。

**做法**：下层卡不再是"整张卡往下挪 2px"，而是**只画底部那一条**：

```css
inset: auto 0 -2px 0;      /* 只贴底 */
height: 14px;              /* 够高即可，上方被上层盖住也无所谓 */
border-radius: 0 0 8px 8px;/* 只有下方两角是圆的 */
```

这样**顶部根本没有下层卡**，也就没有露角；而"两端上弯"的形状仍由下方两角提供。

**验收**：聚焦态 3× 放大顶部左右两角，**必须完全没有琥珀色**。

### B. 列宽

标题是主信息，必须最宽。

| 列 | 宽度 |
|---|---|
| 序号 | 48（固定） |
| **标题** | **`1fr`（吃掉剩余）** |
| 艺人 | 160（固定，超出省略） |
| 时长 | 72（固定） |
| 来源 | 72（固定） |

- 三个表格（`queue list` / `search` / `playlist show`）**用同一套列宽规则**。
- 艺人名过长时省略，不要挤占标题。

### C. 加歌到歌单

1. **不带序号 = 加当前正在播放的曲目**：

   ```
   playlist add <名字>          → 把当前播放加进去
   playlist add <名字> <序号>    → 从当前列表取（保持现状）
   ```

2. **来源必须覆盖四种列表**：`Search` / `Queue` / `Library` / `Playlist`。
   产品明确要求「先 `queue list` 或 `playlist show` 再 `playlist add 歌单 1` 也得能用」——**请逐条真机验证这四种**。

3. 没有任何列表且当前无播放 → `E_CMD_ARG` + hint：
   `先 search / queue list / playlist show，或先播放一首`

4. 已在歌单里的曲目重复添加 → **允许**（歌单可以重复），但输出提示「已在歌单中」。

### D. 候选的 ↑/↓

**目标行为**：

| 状态 | ↑/↓ 作用 |
|---|---|
| 正常输入、候选栏开着 | **在候选里移动** |
| 历史导航中（刚按过 ↑ 翻了历史） | 翻历史，**不出候选** |
| 从历史里再输入一个字符 | 回到正常输入 → 候选恢复、↑/↓ 归候选 |

- 现在的实现是"候选一开就永久禁用方向键"，过头了。
- 用一个显式状态：`historyNavigating`（已有）——只在它为 true 时禁用候选方向键，其余时候方向键优先给候选。
- **候选栏关闭时** ↑/↓ 仍是翻历史。

### E. 候选栏动效

- 出现 / 内容变化：淡入 + 上移 4px，**120ms**（`--np-dur-fast`）。
- 连续打字时候选集合变化频繁——**只在"可见"变"可见且内容变了"时做一次轻过渡**，不要每次都重播入场动画（会闪）。
- `prefers-reduced-motion` → 无过渡。

### G. 候选显示参数

候选第二行显示该命令的 **usage**（灰字），例如：

```
search   搜索本地库与在线音源
         search [关键词] [--artist <名>] [--source <平台>] [--limit <n>]
```

- usage 数据来自命令注册表（`CommandSpec` 已有 usage 字段，确认是否够用；不够就在注册表补）。
- 候选最多 5 条，每条约 2 行高——**注意别把终端内容顶出屏幕**。

### H. help 重做

**分组**（顺序固定）：

```
播放    play / pause / resume / next / prev / seek / volume / mode
媒体库  library add|scan|list|stat / search
歌单    playlist list|create|rename|delete|show|add|remove|play
系统    clear / version / help
```

**每条格式**：

```
play <序号>
  播放当前列表的第 n 首；不带参数继续当前曲目
  例：play 3
```

- `help`（无参数）→ 分组列表 + 每条一行摘要。
- `help <命令>` → 该命令的详细说明 + 全部参数 + 1–2 个例子。
- **不要输出英文字段名**（`--local` 这类参数名保留，但说明用中文）。

## 10. 风险

- **D 是这卡最容易改过头的地方**：方向键有三个归属（候选 / 历史 / 无操作），状态机写错会出现"翻历史时选中了候选"这种错乱。**三种状态各写一个用例**。
- help 变长后**可能超出窗口高度**——终端可滚动，但要确认最后几条能滚到。
- 列宽改了会影响 `search` 的三列/四列/五列变体，**三种都要看**。
- C 的"当前播放"依赖播放器状态，空闲时要有明确错误而不是加一个空条目。
