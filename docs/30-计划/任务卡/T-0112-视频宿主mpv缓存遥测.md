## 0. 事实基线

- 视频模式 C 由 mpv 同时输出音视频；`np-video` 目前只转发 volume/pause。
- mpv 默认 `--demuxer-readahead-secs=1`；本地 FLV 状态显示 `Cache: 1.0s`。
- 本轮只做只读遥测，不改 `speed`。

## 1. 目标

- `np-video` 连接 mpv 后观察：
  - `demuxer-cache-time`
  - `playback-time`
  - `demuxer-cache-duration`
  - `speed`
  - `cache-buffering-state`
- 每秒写一条 `target=mpv-cache` 日志：
  ```text
  cache_ms=... cache_end=... playback=... duration=... speed=... buffering=...
  ```
- 不改变播放速度、不 seek、不新增依赖。

## 2. 非目标

- 不自动 speed 追帧。
- 不调整 `--demuxer-readahead-secs`。
- 不改 TUI。

## 3. 授权路径

```text
crates/np-video/src/mpv_ipc.rs
```

## 4. 验收

- [ ] 本地 FLV 日志出现 `target=mpv-cache cache_ms=...` `[数字]`
- [ ] 日志含 `cache_end/playback/duration/speed/buffering` `[数字]`
- [ ] `speed` 仍为 1.0，播放行为不变 `[数字]`
- [ ] 单元测试覆盖 property-change 数字/null `[数字]`
- [ ] fmt/clippy/test `[数字]`

## 5. 结果

2026-11-20：

- IPC reader 连接后自动 `observe_property` 五项；每秒记录一次缓存差。
- 本地 FLV 实测：`cache_ms=7367/6367/...`、`speed=1.0`、`buffering=100`。
- 未改 speed；待真实 B 站直播日志确认 `cache_ms` 是否稳定，再决定 T-0113 控制策略。
