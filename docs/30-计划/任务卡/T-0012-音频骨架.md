## 1. 背景

M1 的第一块硬骨头：让 `np-audio` 真的能出声。本卡**只做库**——不接窗口、不做队列、不做 IPC。
目标是把"解码 → 重采样 → 输出"这条管线跑通，并留好独占/位完美的扩展点（ARCH-006）。

## 2. 目标

1. `np-audio` 提供 `Player`：`open(path)`、`play()`、`pause()`、`seek(ms)`、`set_volume(0.0-1.0)`、`position_ms()`、`duration_ms()`、`stop()`。
2. 支持 FLAC / MP3 / AAC(M4A) / WAV / OGG-Vorbis 解码（symphonia）。
3. 44.1k / 48k / 96k 源文件都能在 48k 设备上正确播放（rubato 重采样）。
4. 播放/暂停/切歌 有 8–15ms 淡入淡出，无爆音。
5. 提供 `format()` 返回当前源的 `AudioFormat`，`device_caps()` 返回设备能力（为独占预留）。

## 3. 非目标

- 不做队列、不做 gapless（下一卡）。
- 不做网络流（M1 后期）。
- 不做独占/位完美/DSD（只留接口）。
- 不接 Tauri、不接前端。

## 6. 实施要求

### 6.1 依赖（仅允许这些）

| crate | 用途 |
|---|---|
| `symphonia`（features: `all` 或按需启用 mp3/flac/aac/isomp4/ogg/vorbis/wav） | 解码 |
| `cpal` | 输出 |
| `rubato` | 重采样 |
| `thiserror` | 错误 |
| `ringbuf` 或自写无锁环形缓冲 | 缓冲 |

不得引入 `rodio`（我们要自己控制管线），不得引入 `tokio`（音频线程是 OS 线程）。

### 6.2 模块结构（建议）

```
np-audio/src/
├─ lib.rs         # 对外 API：Player
├─ sink.rs        # trait AudioSink + CpalSharedSink
├─ source.rs      # trait AudioSource + FileSource（symphonia）
├─ resample.rs    # ProcessingPlan + rubato 封装
├─ ring.rs        # 无锁环形缓冲
├─ format.rs      # AudioFormat / DeviceCaps
└─ error.rs       # AudioError（thiserror）
```

`lib.rs` 不超过 150 行（只做编排）。

### 6.3 关键约束

- 音频回调（`cpal` 的 `data` 闭包）内：**无分配、无锁、无 `println!`、无 `String`**。
- 解码失败、设备丢失必须返回 `AudioError`，不得 panic。
- `seek` 后位置以新位置为准，允许有 ≤50ms 误差。
- 音量用感知曲线（`gain = v^3`），不做线性。
- 淡入淡出在 `sink` 写入前做（增益斜坡），不依赖 cpal 的 fade。

### 6.4 可测性

- 纯逻辑（`ProcessingPlan` 计算、音量曲线、`AudioFormat` 协商）必须有单测。
- 真实出声不要求自动化测试；用 `examples/play.rs` 手动验证（见 §7）。

## 7. 验收标准

- [ ] `cargo test -p np-audio` 通过（≥ 8 个纯逻辑用例：格式协商、音量曲线、重采样计划、seek 换算）
- [ ] `cargo clippy -p np-audio --all-targets -- -D warnings` 零警告
- [ ] `cargo run -p np-audio --example play -- <某个 flac>` 能出声（附 15 秒录音或截图说明）
- [ ] 同一命令换 mp3、m4a 各播一次，都能出声
- [ ] 44.1k 源在 48k 设备上播放，无变速变调（人工听感 + 打印实际输出格式）
- [ ] 暂停→继续、seek、停止 各操作无爆音（人工听感，写进回报）
- [ ] 播放中 `position_ms()` 单调递增，`duration_ms()` 等于文件时长（±1s）
- [ ] `device_caps()` 能列出当前设备支持的采样率与通道数
- [ ] `lib.rs` ≤ 150 行

## 8. 测试要求

- 单测覆盖全在 `crates/np-audio/src/**` 内的 `#[cfg(test)]`。
- 不使用真实音频文件做单测（避免仓库塞二进制）；`examples/play.rs` 自己找系统里的文件。

## 11. 风险

- **cpal 在 Windows 上的默认设备可能是"无输出"**：先枚举可用设备，取 `default_output_device()`，失败要有清晰错误。
- 采样率不匹配时若直接丢帧，会变速——必须走 rubato。
- symphonia 对 M4A/AAC 需要 `isomp4` + `aac` features，容易漏。
- 环形缓冲太小会爆音（欠载），太大延迟高；建议从 300ms 起，实测调整。
