## 0. 事实基线

- 当前启动页 30fps：LOGO 上下 ±1 行、左右 ±1 列，并带颜色呼吸。
- 当前 UI 音效是正弦短音：Move/Focus/Confirm/Back。
- 用户要求：去掉 LOGO 位移动画；音色改为老式打字机。

## 1. 目标

- 删除 `bob` / `sway` 及其布局位移；LOGO 位置完全固定。
- 保留 450ms 淡入和克制的颜色呼吸（不位移）；`ui.motion` / `NP_TUI_NO_ANIM` 仍可关。
- 更新启动页测试：任何 phase 下 6 行 LOGO 的字符位置完全相同；只允许颜色变化。
- `sound.rs` 改为打字机音色：
  - Move：短促机械按键咔哒；
  - Focus：更轻的按键声；
  - Confirm：回车/字车声 + 打字机铃；
  - Back：退格/低沉的机械回弹。
- 仍为零依赖、内存合成 WAV；35ms 去抖、`ui.sound` 开关保持不变。
- 更新 WAV 时长/峰值/非静音测试。

## 2. 非目标

- 不引入音频采样文件或新 crate。
- 不改启动页布局、主题切换和 Press Enter。
- 不改 UI 音效触发点。

## 5. 结果

2026-11-21 实现完成；T2 通过，T3 人耳待验收。

- 启动页：删除 `bob` / `sway` / `BOB_PERIOD_SECONDS` / `SWAY_PERIOD_SECONDS`，以及 `splash.rs` 的 `can_bob` / `can_sway` / `shifted`；LOGO 的 x/y 只按 6 行块居中计算一次。保留 450ms 淡入与 `breath` × 35% accent 混色；`ui.motion=false` / `NP_TUI_NO_ANIM` 仍走 phase=0 静态入口。
- 音效：`sound.rs` 改为打字机音色（确定性 LCG 噪声 + 一阶低通/高通 + 指数衰减 + 机械共振；1.5ms attack，峰值归一化到 15%–25%）。Move 32ms、Focus 21ms、Confirm 130ms（3 下棘轮 + 2.8kHz 铃）、Back 40ms；`SoundCue`、35ms 去抖与 `ui.sound` 开关不变。
- 测试：`logo_anchors_never_move_for_any_phase`（8 个 phase 下 6 个锚点与整屏文本一致）、`splash_phase_changes_logo_colours_only`（只有 LOGO 行颜色变化）、小终端用例改名并逐 phase 比对文本；WAV 用例覆盖 RIFF/data 头、时长 ±1ms、首样本为 0、峰值 15%–25%、不削顶。

验证：

- `cargo fmt --all`：通过
- `cargo test -p np-tui`：377 passed / 0 failed / 1 ignored
- `cargo clippy -p np-tui --all-targets -- -D warnings`：通过
- 实测峰值：Move 6553（20.00%）、Focus 5243（16.00%）、Confirm 7209（22.00%）、Back 5898（18.00%）；样本数 1411 / 926 / 5733 / 1764
