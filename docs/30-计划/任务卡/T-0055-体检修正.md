## 1. 分工

### 1.1 音源代理（Rust）

| # | 问题 | 要求 |
|---|---|---|
| **1** | `queue add` 后 `play <n>` 仍指上一张表 | **不改规则**；`queue add` 成功后的 footer 追加一句：`现在 play <n> 仍指向<上一张表名>；要播队列先 queue list`。若没有上一张表则省略这句 |
| **2** | 拼写建议质量差（`foo` → `vol`） | 只在**可信**时给建议：候选与输入**首字母相同**且编辑距离 ≤ 2；否则不给建议 |
| **3** | 错误文案泄漏英文参数名 | `缺少参数：position/level/path` → 用参数的中文占位（`<位置>`/`<音量>`/`<路径>`）；`参数 target 需要…` → `参数 <类型> 需要…`。**检查所有 arg 定义**，把展示名与内部 id 分开 |
| **4** | 提示用点号命令名 | `theme set nope` 的 hint 里 `theme.list` → `theme list`；全局 grep 一遍 `.list`/`.show` 之类 |
| **5** | `queue add` 无参文案错位 | 无参 → `缺少参数：路径`；给多个参数 → `queue add 一次只接受一个路径` |
| **8** | `library stat` 行距过宽 | 改成两列排布（3 行 × 2 组），560px 内高度减半 |

### 1.2 UI 代理（web）

| # | 问题 | 要求 |
|---|---|---|
| **6** | dev 构建底部露出琥珀小弧 | dev 状态切换器在 380×160 下越界露出。**改成不占布局**（`position: fixed` 且放在窗口外/或默认折叠成一枚 12px 的小点），dev 可见但不破坏画面 |
| **7** | 数字列表头没右对齐 | 表头与数值同对齐方式：数字列（时长/序号）右对齐，文本列左对齐 |
| **9** | 占位封面渐变太艳 | 降低饱和度/明度，与中性色界面协调；保持"由专辑名确定性生成"，不引入随机 |
