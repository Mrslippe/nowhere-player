## 0. 事实基线

| 项 | 当前值 |
|---|---|
| 频谱 | 16 段块字符柱，**实际只占 4 行** |
| 沉浸模式 | 封面与常驻面板同尺寸（未放大） |
| 字形 | 混用 `▮▯ ◀▶ ▁▂▃▄▅▆▇█`，无统一表 |
| CPU | 播放 1.9% / 暂停 0.6% |
| emoji | **不可用**（WT 字体缺字形） |

## 1. 目标

### A. Braille 频谱（最高优先）

用 `ratatui::widgets::canvas::Canvas` + `Marker::Braille` 画频谱：

- 每个单元格 **2×4 点**，同样 4 行区域纵向精度 ×8。
- 画法：每列按对数频段取值，用 `canvas.draw` 画**折线 + 下方填充**（用竖线点阵模拟面积）。
- **保持 20fps、暂停不刷新**（不能因精度提升而增加重绘）。
- 颜色：默认模式用 `accent`（ANSI cyan），主题模式用主题 `accent`。

**验收要点**：同样的音频，Braille 版能看出**峰谷形状**，块字符版只能看出"高/低"。

### B. 沉浸模式大封面

- 封面区从"面板宽度"放大到 **屏宽的 40%**（受高度约束，保持纵横比）。
- 仍用同一个 `ThreadProtocol`（**不重复编码**）；尺寸变化时触发一次重编码，且在工作线程。
- 大标题：曲线（§C）或 `tui-big-text` 风格——**本卡先不做大字，保持单行标题但字号由终端放大**（见注）。

> 注：终端字号不可由程序控制。大标题只能靠"大字符字体"，本卡不做。

### C. 字形精选表（统一一处在 `glyphs.rs`）

| 用途 | 字形 |
|---|---|
| 播放/暂停 | `▶` `❚❚` |
| 上一首/下一首 | `◀◀` `▶▶` |
| 进度已完成/未完成 | `▰` `▱` |
| 频谱（块字符备份模式） | `▁▂▃▄▅▆▇█` |
| 占位封面 | `░` 填充 + `♪` |
| 选中指示 | `▸` |
| 状态点 | `●` `○` |
| 加载 | `⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` |
| **禁用** | 任何 emoji（🎵🎶🔊 等） |

**要求**：所有字形从 `glyphs.rs` 取，**组件里不许出现字面量**——这样才能一次性替换。

## 2. 非目标

- 不引 `tachyonfx`（需 ADR，DES-011 已定暂缓）。
- 不做大字符标题。
- 不改主题系统（T-0063 并行）。

## 5. 测试要求

- Braille 绘制：给定固定幅值数组，断言画布上某坐标有点。
- 字形表：一个遍历测试，确保每个 `Glyph` 变体非空且无 emoji。

## 6. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | Braille 逐点 `draw` 调用多，可能拖慢 | 每帧只画 4 行 × 面板宽，点数有限；实测 CPU，超 3% 降帧 |
| 2 | 沉浸模式封面重编码导致切换卡顿 | 切尺寸在工作线程；切换期间显示旧图 |
| 3 | 字形替换后布局变化（宽度不同） | 字形表标注 `width`，布局用 `unicode-width` |
| 4 | Braille 在某些字体下渲染成方块 | 真机截图确认；不可用则回退块字符（保留开关） |
