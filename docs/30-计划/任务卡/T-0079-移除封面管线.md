## 0. 事实基线

| 项 | 现状 |
|---|---|
| TUI | 已不显示封面（T-0078） |
| `np-library` | 扫描时提取内嵌封面 → 写 `covers/<key>.jpg` |
| `np-app` | 在线 prepare 时下载封面 → `store_cover` |
| `image` crate | 仍被 `np-library` 使用 → `np-tui` 仍有传递依赖 |
| 二进制 | 10.9 MB |

---

## 1. 目标

**把封面从"数据管线"里彻底摘掉，只保留数据库字段（不删列）。**

### A. `np-library`：停止提取与缓存

- 扫描时**不再解析内嵌封面**（省 CPU 与 IO，扫描更快）；
- 不再写 `covers/` 目录；
- **保留** `tracks.cover_key` 列（schema 不动，避免迁移风险）；
- `store_cover()` 保留签名但标记 `#[deprecated]` 或直接删除（见 B）。

### B. `np-app`：停止下载封面

- 在线 prepare 不再抓封面；
- 删除对 `store_cover` 的调用。

### C. 依赖清理

- `np-library` 移除 `image` 依赖（若无其它用途）；
- `cargo tree -p np-tui | grep -c image` 应为 **0**；
- 报告二进制体积变化。

## 2. 非目标

- **不删** `covers/` 目录里的存量文件（用户数据，删除需另行确认）；
- **不改** 数据库 schema（`cover_key` 列保留，未来可能恢复）；
- 不改命令语义（`library stat` 里的"封面缓存 N 个文件"改为不显示或显示 0，**如实反映**）。

## 3. 授权路径

```
crates/np-library/src/**
crates/np-app/src/**
crates/np-library/Cargo.toml
crates/np-app/Cargo.toml
```

**禁止**：`crates/np-tui/**`（已完工）、`crates/np-core/**`、`crates/np-audio/**`、`docs/**`

- [ ] `cargo test --workspace` 全绿（≥723） `[数字]`

- [ ] 二进制体积下降（报告前后） `[数字]`
- [ ] **扫描更快**：同一目录扫描耗时对比（报告前后数字） `[数字]`
- [ ] **在线播放更快**：`NP_TUI_SELFTEST="search 晴天;play 2"` 的耗时对比 `[数字]`

## 5. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | `image` 被其它 crate 间接使用 | `cargo tree --workspace -i image` 先查 |
| 2 | 删 `store_cover` 破坏 `np-app` 编译 | 一起改，先改调用方 |
| 3 | 扫描耗时对比不公平（磁盘缓存） | 清 OS 缓存不现实 → 用**同一文件集跑两次取第二次**，并在回报说明方法 |
| 4 | 未来想恢复封面要重写 | 记录在 `当前状态` 的"已知取舍"里 |
