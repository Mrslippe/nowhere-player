## 1. 背景

功能已经完整（本地库 + 在线源 + 播放 + 主题），但**界面还是开发期的样子**：终端顶栏写着"终端对比实验室"，旁边是视图切换按钮、主题色板、底部评分面板——这些是 M0 的对比实验留下的。

同时，两套窗口几乎没有动效：块是"啪"地出现，切歌时封面是硬切，进度是跳着走的。

**这一卡只做"看起来是产品"**：去掉实验台、补齐必要的动效、让终端和播放器都显得现代。

## 3. A 块：终端产品化

### 3.1 清掉实验台外壳

| 元素 | 处置 |
|---|---|
| `结构化 / xterm / 分屏` 切换 | **从产品视图移除**，只在 `?lab=1` 时出现 |
| `graphite amber ice` 色板 | 同上，只在 `?lab=1` |
| 底部「评分面板 A 4.30 B 3.40」+ `导出 JSON` | 同上，只在 `?lab=1` |
| 「终端对比实验室」标题 | 改产品名（当前顶栏已是 `Nowhere Player / 终端`，确认即可） |

> **不要删代码**，用 `?lab=1` 开关藏起来。xterm 渲染器仍要能被测试和调试访问。

### 3.2 顶栏（34px，已有自绘）

- 左侧：品牌 + 一个**状态指示**（在线源可用 / 本地库曲目数），用数据而不是装饰。
- 右侧：最小化、关闭（已有）。
- 中间留白即拖拽区。

### 3.3 块流

- 命令回显与输出之间的**层级**要更清楚（当前几乎同权重）。
- 每条命令的耗时（`618ms`）现在是灰字挂在右上，改成**与命令同行的右侧元信息**。
- 状态用**一个 4px 的点**（done/error/running），不要用整块背景色。

### 3.4 动效（按 motion-ref 选，只做这几处）

| 场景 | ref | 要求 |
|---|---|---|
| 新块入场 | `13-enter-exit` | 轻微上移 + 淡入，**禁止逐条延迟**（一次渲染多块时统一入场） |
| 状态切换（running→done） | `10-state` | 点的颜色过渡，不闪 |
| 进度条更新 | `01-loading` | 数值平滑，不跳格 |
| 错误块 | `02-button-feedback` 或 `10-state` | 只做颜色/边框变化，**不做抖动**（桌面工具不该抖） |

## 4. B 块：播放器动效

| 场景 | ref | 要求 |
|---|---|---|
| 切歌：封面 | `13-enter-exit` | 交叉淡入 180–240ms；**不要缩放**（小窗缩放很廉价） |
| 切歌：标题/艺人 | 同上 | 与封面**同一个过渡**，不要分开做 |
| 播放/暂停图标切换 | `08-icon` | 形变或交叉淡入，≤160ms |
| 进度条 | `01-loading` | 播放时每帧推进（`requestAnimationFrame` 或 CSS transition），**不要 1Hz 跳** |
| 音量浮层 | `04-overlay` | 出现/消失各 ≤160ms，已有 120ms 淡出 |
| 悬停控制键 | `02-button-feedback` | 已有，检查时长一致性 |

## 5. 全局约束

1. **`prefers-reduced-motion: reduce`** 时全部动效降为 0ms（motion-ref 硬要求）。
2. 动效时长统一在一个 token 文件里（如 `--np-dur-fast/mid/slow`、`--np-ease-*`），**不要在组件里散写**。
3. **`plain` skin 与 `phosphor` skin 都要好看**，动效参数可以共享（差别在材质不在动效）。
4. **不能破坏公开样式契约**（12 个钩子选择器不改名）。
5. `plain` 的零像素回归**不再要求**（这卡就是要改外观），但要求**逐块截图对比 before/after**。

## 7. 测试要求

- 动效本身不写单测，但**逻辑**要测：`?lab=1` 解析、进度的平滑推进（用假 rAF）、reduced-motion 分支。
- 视觉回归用 `scripts/tools/png-hash.mjs` 做 before/after 对照（这卡**预期有差异**，所以只做记录不做断言）。

## 10. 风险

- **动效最容易做成"到处都在动"**：motion-ref 的第一条原则是"有目的"。**宁少勿多**——只做上表列的八处，别的地方一律静态。
- 桌面工具的动效应比网页更**短、更克制**（160–240ms 为主）。motion-ref 说的 200–500ms 是网页语境，这里可以取偏小值，但要在回报里说明理由。
- 隐藏实验台时**别把 xterm 渲染器的引用一起删掉**，T-0007 的实现和测试还在用它。
- 改块流布局可能影响现有 DOM 测试（`.np-blocks-item` 是公开契约，不能改名）。
