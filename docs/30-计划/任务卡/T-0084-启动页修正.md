## 0. 三个问题（都来自产品真机截图）

### 0.1 大字少最后一个 E（**数据错误**）

`splash.rs::splash_art` 的字符串只有 **6 组字形**（N O W H E R），**第 7 个 E 根本不存在**——不是被裁掉，是没写。

### 0.2 没有垂直居中

当前实现是 `lines` 从顶部开始排（前面只加了一个空行）。窗口高 600+ 时内容全挤在顶部。

### 0.3 默认字体要换成 Sarasa Mono

产品已本地安装：
```
等距更紗黑體 CL Bold      (Sarasa Mono CL Bold)
等距更紗黑體 TC SemiBold  (Sarasa Mono TC SemiBold)
Maple Mono NF CN Medium
```

---

## 1. 目标

### A. 补齐第 7 个字母

在每行末尾追加 E 的字形：

```
███████╗
██╔════╝
█████╗
██╔══╝
███████╗
╚══════╝
```

**注意**：补齐后 art 宽度从约 55 列增到约 **64 列**。
- `splash_art` 的宽度阈值从 60 改为 **68**（border 2 + 左右留白 2）；
- 宽度不足时降级为单行 `NOWHERE`（已有逻辑，保留）。

### B. 垂直居中

```rust
let inner = block.inner(area);
let content = lines.len() as u16;                    // 含空白行
let top = inner.height.saturating_sub(content) / 2;  // 居中偏移
let area = Rect { y: inner.y + top, height: content, ..inner };
```

- 内容高度 ≥ 窗口时按 0 处理（不越界）；
- **水平仍居中**（`Alignment::Center` 保留）。

### C. 默认字体改为 Sarasa Mono

`launcher.rs` 的字体探测扩展为（按优先级）：

| 优先级 | 匹配 |
|---|---|
| 1 | `等距更紗黑體 CL`（Sarasa Mono CL） |
| 2 | `Sarasa Mono CL` |
| 3 | `等距更紗黑體 TC` / `Sarasa Mono TC` |
| 4 | `Maple Mono NF CN` |
| 5 | 都没有 → **不写 `font`**（现状，用 WT 默认） |

- 探测来源：`HKCU` 与 `HKLM` 的 `...\Windows NT\CurrentVersion\Fonts` **两处都要查**（本机 Sarasa 在 HKCU）；
- 写入 fragment 时若只有 **Bold/SemiBold** 字重，**照写**并在日志注明"仅检测到粗体"；
- fragment 变更后**幂等更新**（内容不同才重写）。

## 2. 非目标

- 不改启动页交互（←/→/Enter/q）。
- 不改主题列表顺序。
- 不做字体随包分发。
