## 0. 事实基线

| 项 | 现状 |
|---|---|
| TUI 数据目录默认 | `tmp/np-tui-data`（从 `tmp/bench` 拷测试库）或 `%TEMP%/nowhere-tui` |
| **真实应用目录** | `%APPDATA%\com.nowhere.player`（含 `library.db`、`covers`、`settings.json`） |
| 后果 | TUI 显示 2000 条**假曲目**、歌单为空、设置读的是另一份 |
| 目录逻辑 | `main.rs::tui_data_dir()` 与 `launcher.rs::focus_mode_enabled()` **各写一份** |

## 1. 目标

### A. 默认使用真实应用目录

```
Windows:  %APPDATA%\com.nowhere.player
macOS:    ~/Library/Application Support/com.nowhere.player
Linux:    ~/.config/com.nowhere.player  （cache 用 ~/.cache）
```

- 与 Tauri 版**完全一致**（Tauri 的 `app_config_dir` 就是这个路径），这样**旧数据直接可用**；
- 保留 `NP_TUI_DATA_DIR` 环境变量覆盖（开发/测试用）；
- **删除** `tmp/bench` / `tmp/np-tui-data` 的自动回退逻辑——那是开发期的脚手架。

### B. 目录计算只留一份

抽出 `fn app_dirs() -> Paths`：

```rust
pub struct Paths { pub config: PathBuf, pub cache: PathBuf, pub data: PathBuf }
```

- `main.rs` 与 `launcher.rs` 都调它；
- `focus_mode_enabled()` 改用同一份路径。

### C. 首次运行提示

- 目录不存在 → 建目录，状态栏提示「首次运行：用 `library add <目录>` 添加音乐」；
- **不要**自动扫描任何目录。

## 2. 非目标

- 不做数据迁移（本来就在同一路径）。
- 不改 `np-app::Paths` 字段。

## 3. 授权路径

```
crates/np-tui/**
```

**禁止**：其它 crate、`apps/**`、`docs/**`
