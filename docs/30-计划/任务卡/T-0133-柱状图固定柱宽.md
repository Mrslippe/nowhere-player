## 0. 事实基线

- `draw_bars` 固定 16 根柱，`slot = width / 16`，`bar_width = slot - 1`。
- 72×24 视觉区 66 列时每根柱 3 格 + 1 格间隔；窗口变宽时柱变粗，不是增加数量。
- 用户要求：尽量保证每根柱一样粗；窗口拉伸时增加柱数量。

## 1. 目标

- 固定柱宽 `2` 格、间隔 `1` 格（3 格 pitch）。
- 柱数 = 可用宽度 / 3，至少 1；66 列约 22 根，144 列约 48 根。
- 16 段频谱线性插值到当前柱数，保留原有高度映射。
- 剩余 1–2 格居中留边；每根柱宽度完全一致，不再出现 3 格柱。
- 72×24 / 100×30 / 144×48 测试：柱宽一致、柱数随宽度增加。
- 静音基线、accent 颜色、顶部部分块字形保持。

## 2. 非目标

- 不改 FFT、频谱平滑、颜色和其他样式。
- 不改窗口尺寸策略。

- `draw_bars` 改为固定 `2` 格柱宽 + `1` 格间隔（3 格 pitch），柱数 = 可用宽度 / 3，最多 64。
- 16 段频谱用 `spectrum_at` 线性插值到当前柱数；剩余宽度居中留边。
- 新增测试：66 / 100 / 144 列下柱数分别 22 / 33 / 48，且每根柱宽都正好 2 格。
