**规则**：

| 键 | 动作 |
|---|---|
| `←` / `→` | 切换主题（循环内置主题列表），**立即重绘预览** |
| `Enter` | 进入主界面，**并把当前主题写入设置** |
| `q` / `Esc` | 退出程序 |

- 大字用块字符（ASCII Shadow 风格），**居中**；窗口过窄时降级为 `NOWHERE` 单行文字；
- 主界面框用主题 `line` 色，背景整屏填主题 `bg`；
- 当前主题名居中显示，两侧 `◄ ►`。

### C. 默认主题改为 MilkGreen

- **新装默认** `theme.id = milkgreen`（不再是 `terminal`）；
- 已有用户设置**不被覆盖**（`settings.json` 里有值就以它为准）；
- `theme list` 里排在内置列表**第一位**。

### D. 跳过条件

启动页在以下情况**不显示**：

| 条件 | 原因 |
|---|---|
| `NP_TUI_SELFTEST` 存在 | 自动化 |
| `NP_TUI_NO_SPLASH=1` | 手动跳过 |
| 配置 `ui.splash = false` | 用户偏好 |
| 终端高度 < 20 行 | 放不下 |

## 2. 非目标

- 不做鼠标点击选择主题。
- 不做启动动画/淡入。
- 不改主界面布局。

- [ ] `cargo test --workspace` 全绿（≥723） `[数字]`

- [ ] 已有 `theme.id=tui-paper` 的用户启动 → **不被覆盖** `[数字]`
- [ ] `NP_TUI_SELFTEST="library list"` **不显示启动页** `[数字]`
- [ ] 窄窗口（60×18）降级为单行 `NOWHERE`，不溢出 `[图]`
- [ ] 启动页到主界面**无闪烁**（DECSET 2026 生效） `[数字]`

## 5. 测试要求

- 主题循环：给定当前 id 求 next/prev，单测（含边界回绕）。
- 大字渲染：宽度不足时降级逻辑单测。
- 默认主题：空设置 → `milkgreen`；有设置 → 保留。

## 6. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | 大字块字符在窄终端溢出 | 宽度 < 60 时降级单行 |
| 2 | 切换主题时闪烁 | 已启用 DECSET 2026 同步更新 |
| 3 | 默认主题变更影响老用户 | **只在无 `theme.id` 时使用**，绝不覆盖 |
| 4 | 启动页阻塞自动化 | 三个跳过条件，SELFTEST 必跳 |
