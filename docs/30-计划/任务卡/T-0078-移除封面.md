## 0. 事实基线

| 项 | 当前值 |

| 封面来源 | `track.cover_key → covers_dir`（T-0062） |
| 终端要求 | **必须支持 Sixel/Kitty**，否则回退半块 |
| 二进制 | 13.2 MB |

---

## 1. 产品决定

> **一首歌只用「名称 + 作者名」标识。封面结构项整体移除。**

## 2. 目标

### A. 删除封面显示

- 删除 `crates/np-tui/src/cover.rs`；
- 播放器条不再有封面区域；
- 移除 `ratatui-image` 与 `image` 依赖（np-tui 侧）；
- 删除 `Picker` 探测、`ThreadProtocol`、Sixel 相关代码。

### B. 播放器条重排（10 行 → **6 行**）

```
晴天 · Jay Chou · Currents
▮▮▮▮▮▮▮▯▯▯▯▯   00:10 / 04:29
⣀⣤⣶⣿⣶⣤⣀⣀⣤⣶⣿⣶⣤⣀            ← 视觉区 2 行
◀◀   ▶   ▶▶
```

- 省下的 4 行还给中栏列表；
- 视觉区（频谱/波形/矢量）保持，`f` 切换；
- 标题过长按字符宽度截断（中文 2 列）。

### C. 不再下载封面

- 在线 prepare 时**跳过封面抓取**（省带宽与时间）；
- ⚠️ 该路径在 `np-app`，**超出本卡授权 → 停下来报告**，先只做 TUI 侧移除。

### D. 终端能力依赖归零

移除后，产品应能在**任何终端**运行：

| 终端 | 之前 | 之后 |
|---|---|---|
| Windows Terminal | ✅ | ✅ |
| Alacritty / WezTerm | 🟡 封面退化 | ✅ |
| VS Code 终端 / SSH / tmux | ❌ | ✅ |
| 老 conhost | ❌ | ✅ |

## 3. 非目标

- **不删** `np-library` 的封面扫描与缓存（数据仍在，只是不显示）；
- 不改 `np-app` 的封面抓取（需另开卡授权）；
- 不改主题系统。

## 4. 授权路径

```
crates/np-tui/**
Cargo.toml
crates/np-tui/Cargo.toml
```

**禁止**：其它 crate、`apps/**`、`docs/**`

## 6. 测试要求

- 删除 `cover.rs` 相关单测；
- 补一条：无封面字段时播放器条渲染不 panic；
- 布局单测：播放器条高 6 行，列表占用剩余。

## 7. 风险

| # | 风险 | 缓解 |
|---|---|---|
| 1 | 缩到 6 行后视觉区被压扁 | 视觉区保底 2 行；`<24` 行窗口时降为 0 行 |
| 2 | 移除 `image` 依赖影响 workspace 其他 crate | `cargo tree --workspace` 复核，只准 np-tui 侧减少 |
| 3 | 二进制体积不降反升（依赖合并） | 报告数字；若异常，检查 `image` 是否仍被其它 crate 使用 |
| 4 | 之前靠封面识别的场景丢失 | 产品已确认可接受；标题+作者足够 |
