## 0. 事实基线

- 72×24 是现有布局基线；Live 页单独占满屏幕，不再显示 Browse/List。
- 信息行**叠加**在视觉区最后一行，右对齐 `直播标题 - 分区`；不额外占高度。
- Player 上边左侧是**主播名**，右侧音量；控制条画在 Player 下框线。
- 音高条参照现有进度条：填充/未填充都用 `▰`，只靠颜色区分，不使用 `▱` 等空四边形字符。
- 小于 72×24 仍进入 Live 页，压缩视觉区，不退回底部 LIVE 条。

## 1. 目标

- 72×24 下 Live 页按基准布局渲染；坐标/尺寸可测。
- 视觉区 19 行；信息行叠加最后一行；音高行 1 行；控制条在下框线；状态栏在外框下边。
- 音高条 64 格，颜色区分，不可 seek。
- 主播名/标题/分区从 API 取；分区取 `area_name`/`parent_area_name`，主播名取房间/用户 API。
- 小尺寸压缩视觉区：`visual_h = max(1, H-5)`；`player_w = W-4`；最小 40×10。
- 接入 `live.buffer_ms` 显示与设置编辑（设置 UI 由本卡负责；T-0093 提供 key）。
- `r` 刷新、`space` 暂停、`c` 弹幕入口（先占位）、`/` 命令；F5 保留。

## 2. 非目标

- 不实现弹幕发送逻辑（T-0094）；
- 不做 WSOLA（T-0093）；
- 不改默认流参数；
- 不做图片/视频解码。

## 4. 布局基准

```text
总览：
纵向 24 = 上框 1 + Player 22 + 下框 1
横向 72 = 左框 1 + 左间距 1 + Player 68 + 右间距 1 + 右框 1

1. Player：
纵向 22 = 上框 1 + 视觉区 19 + 音高 1 + 下框 1
横向 68 = 左空白 1 + 内容 66 + 右空白 1
注：Player 只有上下框线；主播名/音量在顶边，控制按钮在底边。

2. 视觉区：
66×19；信息行叠加在第 19 行，右对齐 `直播标题 - 分区`；
标题过长从左侧截断，保留右侧分区。

3. 音高行：
66×1 = 左空 1 + 音高条 64 + 右空 1；
填充/未填充均用 `▰`，只颜色不同（accent/muted），不用 `▱`。

4. 控制条（Player 下框线）：
68 = 左空 1 + ↻ 1 + 空 1 + ►/❚❚ 1 + 中间 ━ + 右侧 target/actual + 右空 1。

5. 外框上边：
左 NOWHERE PLAYER；右主题名。

6. Player 上边：
左主播名；右 Vol + 20 格 + 末 1 空；中间 ─。

7. 状态栏（外框下边）：
LIVE · r refresh · space pause · c chat · / command

8. 小尺寸：
仍进 Live 页；visual_h=max(1,H-5)，player_w=W-4，content_w=W-6；
最小 40×10；更小时保留状态栏和输入恢复路径。
```
