## 0. 事实基线

- 控制条每 16ms tick 比对 `demuxer-cache-time` 小字；文本变化就 `invalidate_controls()` 整条重绘。
- `paint::controls` 每次整条 `BeginPaint` 重画，没有双缓冲。
- `SpeedTuner` 在 `file-loaded` 时只重置 telemetry，不重置 speed。
- `loadfile` 回复槽位可能被旧 request id 覆盖；宿主最多等 5s 后回退。
- 刷新走重新取流 + `loadfile replace`，不是保持旧播放位置。

## 1. 目标

- 控制条 cache 小字最多 500ms 更新一次；只在控制条可见时更新。
- cache 文本变化只重绘 cache 小字区域，不重绘整条控制条；如仍有闪烁，再加内存 DC 双缓冲。
- `file-loaded` 时强制 `speed=1.0` 并重置 `SpeedTuner`；避免刷新后停留在 0.60x/1.30x。
- `loadfile` 只接受当前 request id 的回复；旧回复不得覆盖新请求槽位。
- 增加纯函数单测：cache 节流、速度重置、request id 过滤。
- 保留 `loadfile replace`；不改成重启 mpv。

## 2. 非目标

- 不改视频窗口布局、标题栏动画、mpv 参数。
- 不改 TUI 的刷新入口和取流 API。
- 不做 mpv 进程重启或窗口重建。
