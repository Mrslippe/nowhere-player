## 1. 背景

播放器小窗是产品的门面，M0 要把它的**样子**定下来。当前 `PlayerView.tsx` 只有一行占位文字。
本卡只做静态原型（假数据），不接播放引擎。

## 2. 目标

用 `design/` 的 token 与组件，做出 340×120 的小窗，覆盖 6 种状态，可一键切换预览。

**布局（340×120）**

```
┌──────────────────────────────────────────────┐
│  ┌────────┐  标题（15px / 600，单行省略）      │
│  │ 封面   │  艺人 · 专辑（12px / muted）      │
│  │ 64×64  │                                │
│  └────────┘  ━━━━━━━━━━━━━━━━━━━  01:23/04:05│
└──────────────────────────────────────────────┘
```

**6 种状态**：`idle` / `loading` / `playing` / `paused` / `error` / `hover`（用 URL 参数 `?state=` 切换，仅 dev）。

## 3. 非目标

- 不接真实播放状态（M1）。
- 不做窗口拖拽、置顶、透明（M0 后续卡）。
- 不做标题 Marquee 滚动（M6 打磨）。
- 不做右键菜单。

## 6. 实施要求

### 6.1 结构

- `PlayerView.tsx`：读 `?state=` 决定状态，渲染 `<PlayerCard />`。
- `PlayerCard.tsx`：纯展示组件，props 为 `{ title, artist, album, coverSeed, durationMs, positionMs, state }`。
- `mock.ts`：假数据（3 组曲目，中文标题 + 英文标题各一，用于测省略）。
- `cover.ts`：由 `coverSeed` 生成**确定性渐变**（同一 seed 永远同色），不依赖图片资源。
- 时间格式化函数单独放 `format.ts`，纯函数，便于测试。

### 6.2 细节要求

| 元素 | 要求 |
|---|---|
| 封面 | 64×64，圆角 `--r-lg`；无图时用确定性渐变 + 居中的专辑首字 |
| 标题 | 15px/600，单行，`text-overflow: ellipsis` |
| 副标题 | 12px，`--fg-muted`，艺人 · 专辑，同样省略 |
| 进度条 | 2px；hover 态变 4px；`transform: scaleX()` 驱动，不用 width |
| 时间 | 10px，`font-variant-numeric: tabular-nums`，`01:23/04:05` 格式 |
| 控制键 | 默认 `opacity: 0`，卡片 hover 后 120ms 淡入；上一首/播放暂停/下一首 |
| 状态色 | error 态右上角一个 6px 圆点，`--danger`；不弹窗、不显示长文案 |
| 拖拽区 | 整张卡片加 `data-tauri-drag-region`（M1 才生效，先加上） |

### 6.3 状态表现

| 状态 | 表现 |
|---|---|
| idle | 显示"未在播放"，整体 60% 不透明度 |
| loading | 封面位置显示 Spinner，进度条不确定态 |
| playing | 正常；进度条 `--accent` |
| paused | 整体 `filter: saturate(0.85)`，播放键为 ▶ |
| error | 右上角红点 + 标题位置显示"播放失败" |
| hover | 强制显示控制键（用于截图与视觉验收） |

## 7. 验收标准

- [ ] `pnpm -C apps/web typecheck` 通过
- [ ] `pnpm -C apps/web test` 通过（新增用例，见 §8）
- [ ] 340×120 下无横向滚动、无文字溢出遮挡（用 dev 页固定尺寸容器验证）
- [ ] 6 种状态均可通过 `?state=` 切换
- [ ] 同一 `coverSeed` 两次渲染得到相同渐变（单测断言）
- [ ] 组件内无 `#RRGGBB` 字面量（只引用 CSS 变量）
- [ ] `prefers-reduced-motion` 下无过渡
- [ ] 不跑 `scripts/check.ps1`（并行期间由主线合并时执行）

## 8. 测试要求

- `format.test.ts`：时长格式化（0、59s、1:00、61:30、超 1 小时）。
- `cover.test.ts`：确定性（同 seed 同输出）+ 不同 seed 输出不同。
- `PlayerCard.test.tsx`：6 状态各渲染一次，断言关键文本/类名。

## 9. 文档影响

- 回报中给出：最终像素布局（各元素间距）、6 状态截图路径。
- 若发现 token 不够用（例如缺少某个灰阶），**不要自己加变量**，在"未决"里提出。

## 10. 回报格式

四段式；验证段逐条对应 §7，附截图路径。

## 11. 风险

- 卡片尺寸是 340×120 的**窗口内容区**，不要按 340×120 含边框来算；预览容器固定 `width:340px; height:120px`。
- 不要引入任何图片资源；封面一律渐变。
