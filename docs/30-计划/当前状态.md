## 3. 架构速查

| crate | 职责 | 边界 |
|---|---|---|
| `np-core` | 领域模型、命令定义/解析、错误码、终端输出、主题 schema、设置 | 不碰 IO、不碰网络、不碰音频设备 |
| `np-audio` | 解码、重采样、cpal 输出、播放状态机、样本 tap | 不碰数据库、不碰网络、不碰 UI |
| `np-library` | 扫描、标签、SQLite、歌单、检索 | 不碰播放、不碰在线源 |
| `np-sources` | B 站 / 网易云适配、下载缓存、可注入 Transport | 不碰播放、不碰 UI |
| `np-app` | 与宿主无关的命令执行器（端口 trait + 适配器） | 不依赖 Tauri / Ratatui |
| `np-tui` | UI、事件循环、启动器、托盘、热键、自检 | 不直接写 SQL / 网络协议 |
| `np-system` | **空壳**（历史遗留）；能力已并入 `np-tui` | 不再新增职责，除非先提 ADR |

依赖方向：`np-tui → np-app → np-library / np-sources → np-core`，`np-tui → np-audio`。

## 4. 运行与验收

```bash
cargo build --release -p np-tui
target/release/np-tui.exe

# 无头自检（不依赖真实音频设备）
NP_TUI_SELFTEST="search 晴天;play 2" target/release/np-tui.exe

# 数据目录隔离
NP_TUI_DATA_DIR=<dir> target/release/np-tui.exe
```

| 目的 | 命令 |
|---|---|
| 格式 | `cargo fmt --all -- --check` |
| 静态检查 | `cargo clippy --workspace --all-targets -- -D warnings` |
| 单元测试 | `cargo test --workspace` |
| 全量门禁 | `pwsh scripts/check.ps1` / `bash scripts/check.sh` |
| 真机验收 | `pwsh scripts/verify.ps1 -Card <卡号> -Selftest "<命令>"` |

## 6. 恢复清单（压缩后按顺序做）

1. 读本文件 → 知道当前事实。
2. 读 [`AGENTS.md`](../../AGENTS.md) → 红线与命令。
3. `git log --oneline -10` + `git tag --sort=-creatordate | head` → 确认分支与基线。
4. `git status --short` → 有未提交改动时先判断归属，不要覆盖别人的 WIP。
5. `cargo test --workspace` → 确认环境没坏。
6. 看 `docs/30-计划/任务卡/` 最近改的文件；按卡继续，不凭记忆。

**判断有没有卡在跑**：最近修改的任务卡 + `git status` + `base/T-xxxx` tag。
