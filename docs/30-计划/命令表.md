# 命令表

> 本文是**已实现**的命令参考。代码是唯一权威：`crates/np-core/src/command/registry.rs`。
> 两者不一致时，先改代码再改本文（或反过来，但必须同时）。

---

## 1. 语法

```
命令    := 动词 [子命令] [位置参数...] [--标志[=值]...]
动词    := 小写英文单词；别名须显式登记
位置参数 := 数字 | 区间 | 时间（mm:ss） | 字符串 | 路径 | URL
标志    := --json | --limit=20 | --force（裸标志值为空串）
```

### 1.1 分词规则（T-0017 实现，测试锁死）

| 规则 | 说明 |
|---|---|
| 空白分隔 | 连续空白折叠 |
| 空输入 | 纯空白 = **不做任何事**（`Ok(None)`），不是错误 |
| 引号 | `"..."` / `'...'` 包裹整体（用于含空格路径）；**引号内不处理转义** |
| 引号未闭合 | `E_CMD_ARG` |
| **反斜杠** | **是字面量，不是转义符**：`C:\Music\a.flac` 原样保留 |
| 标志 | **只接受 `--name=value`**；空格形式 `--name value` 视为"缺少取值"报 `E_CMD_ARG`（不静默吞下一个 token） |
| 重复标志 | 后者覆盖 |

> 反斜杠这条是**与 POSIX shell 的有意差异**——Windows 路径优先于 shell 习惯。改它会连锁影响全部路径参数，已用测试锁死。

### 1.2 查找与建议

- 规范名与别名都命中，大小写不敏感。
- 拼写错误给**编辑距离 ≤ 2** 的建议，同距离按字典序；错误信息形如 `did you mean 'play'?`。

### 1.3 分层：形状 vs 语义

- **解析层只校验形状**：类型、必填、参数个数。
- **不校验语义**：`vol 999`、`seek 1:30` 都能解析成功；范围钳制由执行层负责。
- 枚举值在解析层**归一化为规范写法**（`mode repeat ALL` → `all`），执行层不需要再转小写。

## 2. 已登记命令（12 条，解析层可用）

| 分组 | 命令 | 说明 |
|---|---|---|
| 播放 | `play [序号\|路径]` `pause` `resume` `next` `prev` | `play` 无参 = 继续当前 |
| 播放 | `seek <ms\|mm:ss\|±s>` `vol <0-100\|±N>` | 范围钳制在执行层 |
| 队列 | `queue`（别名 `q`；无参 = `list`） | 子命令：`add` / `remove` / `clear` / `jump` / `list` |
| 模式 | `mode repeat <off\|one\|all>`、`mode shuffle <on\|off>` | 必须有子命令 |
| 媒体库 | `library`（别名 `lib`） | 子命令：`add <路径>` / `scan [--full]` / `list [--limit=N]` / `stat` |
| 检索 | `search <关键词> [--local]` | 默认**本地 + 在线**；序号 1 基**跨源连续**；结果存会话上下文（上限 100） |
| 主题 | `theme list` / `theme set <id>` / `theme export <id>` | `set` 立即生效并写入 settings |
| 音源 | `source list` / `source enable <id>` / `source disable <id>` | 禁用的源不参与搜索；旧结果 `play` 给人话错误 |
| 缓存 | `cache stat` / `cache clear [streams\|covers\|all]` | `clear` 前若在播远程曲目会先停播 |
| 配置 | `config list` / `get <key>` / `set <key> <value>` / `unset <key>` / `reset` | 点分 key；值类型按字面推断 |
| 系统 | `help [命令] [--all]`（别名 `?`） `version` `clear` | 前端处理 |

### 2.1 编号与参数约定（T-0018 定）

- **所有队列序号对用户一律 1 基**（`play 3` = 第 3 首，`queue remove 2` = 删第 2 首），执行层内部转 0 基；`queue list` 的序号列与全部成功文案都按 1 基显示。`play 0` → `E_CMD_ARG`「序号从 1 开始」。
- `queue add` 当前**只接受文件路径**（库/搜索未实现，没有序号可解析）；纯数字会被当路径处理。
- `clear` 由**前端**处理（视图操作），后端遇到会返回 `E_CMD_ARG` 作为防御。
- **`play <n>` 的序号来源**（T-0023 定）：
  1. 队列非空 → 播队列第 n 首，footer 写「来源：播放队列」；
  2. 队列为空且会话里有 `search` 结果 → 播第 n 条结果，footer 写「来源：搜索结果（共 N 条）」；
  3. 两者都没有 → `E_CMD_ARG`。
- **`library stat` 输出六项**：曲目 / 专辑 / 艺人 / 总时长 / 最近扫描 / **封面缓存**（`N 个文件 / X MB`，二进制 MB、一位小数；只统计 covers 下顶层 `.jpg`，不跟随符号链接）。
- **`search` 输出**：
  - 默认 5 列 `序号 | 来源 | 标题 | 艺人 | 时长`，来源为 `本地` / `B站` / `网易云`；排序为本地在前、在线在后。
  - `--local` 时保持 4 列（序号/标题/艺人/时长），行为与 M4 完全一致。
  - 序号**跨源连续**（不是每源从 1 起点），否则 `play <n>` 有歧义。
  - 在线源部分失败不影响本地结果，末尾给一条 hint「在线源暂时不可用」。
- **`play <n>` 命中在线结果**：立即返回并推 `running` 块；后台 resolve → 下载（进度按时间节流 1–2 Hz）→ 播放本地缓存。完成 footer 写「来源：<源> · 已缓存 X MB」，命中缓存写「来源：<源> · 命中缓存」。

### 2.1 与早期规划的差异

| 早期写法 | 改为 | 原因 |
|---|---|---|
| `queue rm` / `queue move` | `queue remove` / `queue jump` | 全词更易补全与朗读；`move` 未实现，v1 不登记 |
| `shuffle on\|off`、`repeat off\|one\|all` | `mode repeat <...>` / `mode shuffle <...>` | 收进 `mode` 子命令，避免顶层动词膨胀 |
| `toggle` / `stop` / `mute` | 未登记 | 执行层还没有对应能力，留到后续卡 |

## 4. 错误码

| 码 | 触发 |
|---|---|
| `E_CMD_UNKNOWN` | 未知顶层命令 / 未知子命令 / 空命令名 |
| `E_CMD_ARG` | 引号未闭合、缺参、多参、类型不符、未知标志、标志缺值、序号越界 |
| `E_BUSY` | 命令队列满 / 已有扫描在跑 / actor 应答超时（5s） |
| `E_UNSUPPORTED` | 能力未实现（如队列为空时的 next） |
| `E_DECODE` | 解码 / IO / 参数非法（播放域） |
| `E_DEVICE_LOST` | 无可用输出设备 / 设备丢失 |
| `E_LIB_DB` | SQLite 打开或查询失败 |
| `E_LIB_IO` | 扫描时目录/文件不可读 |
| `E_LIB_TAG` | 标签解析失败（单文件，不中断整轮） |
| `E_LIB_SCAN` | 扫描整体失败（如根目录不存在） |
| `E_STREAM_LOST` | 终端事件订阅断开（前端本地产生） |
| `E_NET_TIMEOUT` | 连接超时 / DNS / 连接被拒（网络层） |
| `E_SRC_UNAVAILABLE` | 音源不可用：风控（-412）、HTTP 错误、响应解析失败 |
| `E_SRC_DOWNLOAD` | 下载中断 / 写入失败 / 文件不完整 |
| `E_SRC_NOT_IMPLEMENTED` | 该源能力尚未实现（内部占位，用户不应看到） |

`E_CMD_ARG` 一律带 `usage`；引号未闭合因无法定位命令，可无 `usage`。

## 5. 补全契约（`cmd.complete`，T-0020）

**入参**：`{ input: string, cursor: number }`
**出参**：`{ replaceStart, replaceEnd, items: [{ text, kind, summary }] }`

| 字段 | 说明 |
|---|---|
| `replaceStart` / `replaceEnd` / `cursor` | **字符数（Unicode 码点）**，不是字节、不是 UTF-16。前端负责与 `selectionStart` 互转 |
| `kind` | `command` / `subcommand` / `enum` / `dynamic` / `suggestion` |
| 数量 | 后端最多 20 条；弹层只显示 8 条 |
| 动态候选 | 仅 `play <n>` 这类需要队列长度时调用一次 `snapshot()`；失败或未知降级为**空列表**，不阻塞 |
| 别名 | 候选只列规范名（`q` / `?` 仍可解析，但不出现） |

**历史**：`localStorage["np.cmd.history"]`，上限 500，连续重复不入栈，读写 `try/catch`。

**按键归属**：弹层打开时 `↑/↓` 归弹层；关闭时归历史。`Ctrl+R` 反向搜索 v1 未做。

## 2.2 序号上下文与补全（T-0043 起生效，**取代 §2.1 里 play 的旧规则**）

### 序号：最后一张列表拥有序号

| 最后渲染的表格 | `play <n>` 解析 |
|---|---|
| `search` | 搜索结果第 n 条（本地播路径、在线走下载） |
| `queue list` | 队列第 n 首 |
| `library list` | 媒体库第 n 首 |
| `playlist show` | 歌单第 n 首（T-0044） |
| 没有表格 | `E_CMD_ARG`「没有可用的序号列表」+ 教学 hint |

- **不再有"队列优先"的隐式回退**；启动后直接 `play 1` 也会报错。
- 空搜索（0 条）**会把上下文设成空的 Search**，`play 1` 报「搜索结果只有 0 条」。
- 越界：`<来源>只有 N 条/首，没有第 n 条`。
- footer 统一为 `来源：搜索结果（共 N 条）` / `来源：播放队列（共 N 首）` / `来源：媒体库（共 N 首）`。

### `queue add`

```
queue add <path>                  # 必须是已存在的文件
queue add --from-search <n>       # 从当前搜索结果取第 n 条
```

- 路径不存在 → `E_CMD_ARG`「文件不存在：<path>」+ hint「只接受本地文件；搜索结果用 --from-search <n>」。
- 不再把任意字符串当路径。

### 内联补全

| 事件 | 行为 |
|---|---|
| 输入变化（命令名位置、非空） | debounce 80ms，最多 5 条候选，首条高亮 |
| 参数位置 / 含空格 / 空输入 | 不出候选 |
| Tab（列表开） | 采纳第一条，**不执行** |
| Enter | 执行当前输入（不采纳候选） |
| Esc | 关闭列表 |
| ↑/↓ | 列表开时移动高亮，关时翻历史 |
