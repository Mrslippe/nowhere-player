# 命令表

> 本文是**已实现**的命令参考。代码是唯一权威：`crates/np-core/src/command/registry.rs`。
> 两者不一致时，先改代码再改本文（或反过来，但必须同时）。
> 2026-11-13 修订：按当前 19 条顶层命令重写；移除封面包；补充歌单、UP 检索、`--from-search`。

---

## 1. 语法

```
命令    := 动词 [子命令] [位置参数...] [--标志[=值]...]
动词    := 小写英文单词；别名须显式登记
位置参数 := 数字 | 区间 | 时间（mm:ss） | 字符串 | 路径 | URL
标志    := --json | --limit=20 | --force（裸标志值为空串）
```

### 1.1 分词规则（测试锁死）

| 规则 | 说明 |
|---|---|
| 空白分隔 | 连续空白折叠 |
| 空输入 | 纯空白 = **不做任何事**（`Ok(None)`），不是错误 |
| 引号 | `"..."` / `'...'` 包裹整体（用于含空格路径）；**引号内不处理转义** |
| 引号未闭合 | `E_CMD_ARG` |
| **反斜杠** | **是字面量，不是转义符**：`C:\Music\a.flac` 原样保留 |
| 标志 | **只接受 `--name=value`**；空格形式 `--name value` 视为“缺少取值”报 `E_CMD_ARG` |
| 重复标志 | 后者覆盖 |

> 反斜杠这条是**与 POSIX shell 的有意差异**——Windows 路径优先于 shell 习惯。

### 1.2 查找与建议

- 规范名与别名都命中，大小写不敏感。
- 拼写错误给**编辑距离 ≤ 2** 的建议，同距离按字典序；错误信息形如 `did you mean 'play'?`。
- 解析层只校验形状；范围钳制（`vol 999`、`seek` 越界）由执行层负责。

| 分组 | 命令 | 说明 |
|---|---|---|

## 3. 子命令

### 3.1 `queue`

| 子命令 | 用法 | 说明 |
|---|---|---|
| `add` | `queue add <路径>` 或 `queue add --from-search <序号>` | 加本地文件或最近搜索结果第 n 条 |
| `remove` | `queue remove <序号>` | 1 基 |
| `clear` | `queue clear` | 清空 |
| `jump` | `queue jump <序号>` | 跳到并播放第 n 首 |
| `list` | `queue list` | 等价于不带参数的 `queue` |

### 3.2 `library`

| 子命令 | 用法 | 说明 |
|---|---|---|
| `add` | `library add <路径>` | 登记扫描根 |
| `scan` | `library scan [--full]` | 默认增量；`--full` 全量重解析 |
| `list` | `library list [--limit=<条数>]` | 最近入库（默认 20） |
| `stat` | `library stat` | 曲目 / 专辑 / 艺人 / 总时长 / 最近扫描（**无封面行**） |

### 3.3 `mode`

| 子命令 | 用法 |
|---|---|
| `repeat` | `mode repeat <off\|one\|all>` |
| `shuffle` | `mode shuffle <on\|off>` |

### 3.4 `theme`

| 子命令 | 用法 | 说明 |
|---|---|---|
| `list` | `theme list` | 内置 + 用户主题，当前项有标记 |
| `set` | `theme set <主题 id>` | 立即生效并写 settings |
| `export` | `theme export <主题 id>` | 导出为可编辑 JSON |

### 3.5 `config`

| 子命令 | 用法 |
|---|---|
| `list` | `config list` |
| `get` | `config get <设置项>` |
| `set` | `config set <设置项> <值>` |
| `unset` | `config unset <设置项>` |
| `reset` | `config reset` |

### 3.6 `source`

| 子命令 | 用法 |

| `enable` | `source enable <bilibili\|netease>` |

### 3.7 `cache`

| 子命令 | 用法 | 说明 |
|---|---|---|
| `stat` | `cache stat` | 只统计 `streams` 文件数/体积 |
| `clear` | `cache clear [streams\|all]` | 清空下载缓存；播放中的远程曲目先停播 |

> 封面子系统已移除（ADR-0007）；缓存命令没有封面类别。

### 3.8 `playlist`

| 子命令 | 用法 | 说明 |
|---|---|---|
| `list` | `playlist list` | 列出歌单 |
| `create` | `playlist create "<名字>"` | 新建 |
| `rename` | `playlist rename "<旧名>" "<新名>"` | 重命名 |
| `delete` | `playlist delete "<名字>"` | 删除 |
| `show` | `playlist show "<名字>"` | 显示条目 |
| `add` | `playlist add "<名字>" [序号]` | 当前播放或当前列表第 n 条 |
| `remove` | `playlist remove "<名字>" <序号>` | 删除条目（1 基） |
| `play` | `playlist play "<名字>" [序号]` | 从第 n 首开始播放，默认 1 |

## 4. 参数约定

| 规则 | 说明 |
|---|---|
| 队列序号 | **1 基**；`play 0` / `queue remove 0` → `E_CMD_ARG` |
| `play <n>` 来源 | 最近一次带序号列表（`search` / `queue list` / `library list` 等）；没有列表 → `E_CMD_ARG` |
| 搜索序号 | 跨源连续，本地在前、在线在后；`play <n>` 可直接命中在线结果 |
| 在线播放 | 先 resolve → 下载 → 播放本地缓存；完成块写「来源 + 已缓存/命中缓存」 |
| 远程元数据 | 会话级映射；缓存文件消失后自动回退到本地库查询 |
| 失败语义 | 本地部分失败不影响在线结果；在线源失败给 `E_SRC_*` 或一条 hint |

## 5. 错误码（摘要）

| 码 | 含义 |
|---|---|
| `E_CMD_ARG` | 参数形状/取值不合法 |
| `E_CMD_UNKNOWN` | 未知命令；可能带 `did you mean` |
| `E_UNSUPPORTED` | 当前实现不支持 |
| `E_BUSY` | 播放器线程/后台任务忙 |
| `E_AUDIO` | 解码/输出/设备错误 |
| `E_LIB_*` | 数据库/IO/标签/扫描错误 |
| `E_SRC_*` | 在线源不可用/网络/风控/取流失败 |
| `E_THEME_*` | 主题 id/JSON/写盘失败 |

> 完整定义与映射见 `crates/np-core/src/player.rs`、`crates/np-app/src/command.rs`。
> 修改错误码必须同时改文档；CI 的契约检查会比对 `SCHEMA_VERSION` 与 ADR。
