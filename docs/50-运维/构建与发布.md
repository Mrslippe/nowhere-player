# 构建与发布

> 当前发布形态：**单一二进制 `np-tui`**。不发布 crate（`publish = false`），不做安装器/商店分发。
> 目标：任何一次 tag 都能从干净 checkout 复现，并知道它对应哪份 changelog。

---

## 1. 环境

| 项 | 要求 |
|---|---|
| Rust | `rust-toolchain.toml` 锁定 1.98.0；MSRV 1.90（未单独 CI 验证） |
| Linux | ALSA 开发库（`libasound2-dev`）、`pkg-config` |
| Windows | MSVC 工具链；建议 Windows Terminal |
| macOS | Xcode command line tools |
| Python | 3.x（文档/契约/卫生检查；非产品依赖） |

---

## 2. 构建

```bash
cargo build --release --locked -p np-tui -p np-video
```

- release profile：`lto = true`、`codegen-units = 1`、`strip = true`（根 `Cargo.toml`）。
- 产物：`target/release/np-tui.exe`（约 11.8 MB）与 `target/release/np-video.exe`（约 318 KB）；两者必须同目录发布。缺 `np-video.exe` 时 TUI 静默回退外部播放器窗口。
- 本机 mpv：`E:\tools\mpv-v0.42.0-x86_64-pc-windows-msvc` 已加入用户 PATH；新开终端/重启 Explorer 后 `np-video` 可直接找到。工作区 `tools/mpv` 副本会被 Windows 安全策略拦截，不作为运行路径；二进制不提交（`.gitignore`）。
- 应用内 `/mpv`：从 [mpv-player/mpv git-release](https://github.com/mpv-player/mpv/releases/tag/git-release) 下载 x86_64 Clang ZIP，SHA256 固定校验，安装到 `%LOCALAPPDATA%\NowherePlayer\mpv\current`；`np-video` 自动发现。下载/解压失败只写状态栏，不破坏现有播放器。
- 随包分发：`scripts/package-windows.ps1 -MpvDir <解压目录>` 生成 `dist/NowherePlayer-windows-x64.zip`，内置 `mpv/mpv.exe`、许可证和源码要约；`np-video` 优先使用同级 `mpv/mpv.exe`。
- 推荐桌面启动方式：`pwsh -File scripts/install-nowhere-shortcut.ps1`，快捷方式直接调用 `wt --size 77,26 -p "Nowhere Player"`（WT 内容区为 72×24），避免 console 自举闪窗。
- 不要用 `cargo build` 的 debug 产物做验收；`verify.ps1` 会记录 HEAD 与构建戳。

## 3. 冒烟

```bash
NP_TUI_SELFTEST="version" target/release/np-tui.exe
NP_TUI_SELFTEST="help" target/release/np-tui.exe
NP_TUI_SELFTEST="search 晴天;play 2" target/release/np-tui.exe
```

- 前两条不依赖音频设备；`play` 需要真实设备或测试 WAV。
- 数据目录用 `NP_TUI_DATA_DIR=<dir>` 隔离，不要动真实库。
- 托盘/媒体键/自启/声音属于人工验收项。

## 4. 版本、tag、CHANGELOG

1. 改根 `Cargo.toml` 的 `[workspace.package].version`。
2. `cargo check` 更新 `Cargo.lock`。
3. 在 `CHANGELOG.md` 写 `## [X.Y.Z] - YYYY-MM-DD`，按 Added/Changed/Removed/Fixed 分类。
4. 打 tag：`vX.Y.Z` 或 `vX.Y.Z-<阶段>`；tag 必须与 Cargo 版本一致。
5. 里程碑/基线 tag：`base/T-XXXX`、`vX.Y.Z-*`。

> 当前 `0.1.0` 对应 `v0.1.0-tui` 之后的文档/质量收口；`version` 命令读 `CARGO_PKG_VERSION`。

## 6. 回滚

| 场景 | 做法 |
|---|---|
| 代码回归 | `git revert <commit>`，保留历史；重新跑门禁 |
| 版本回退 | 回退 tag 到上一个 `vX.Y.Z-*`；不要删旧 tag |
| 数据迁移 | 只从 `<db>.bak` 恢复；不要手改 `user_version` |
| 发布撤回 | 删除发布附件/说明，保留 tag 与 commit 以便追溯 |

## 7. 平台差异

| 平台 | 状态 |
|---|---|
| Windows | 主平台；托盘、热键、单实例、自启、WT 启动器已接 |
| Linux | 可编译/播放；ALSA 依赖；托盘/自启/单实例未等价 |
| macOS | 可编译/播放；系统集成未等价；CI 仅编译/测试 |

**不要**在 README 写“全平台完整体验”；平台矩阵以本节为准。

## 8. 明确不做

- 不做签名/公证（需要时再立 OPS 卡）。
