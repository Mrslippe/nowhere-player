Nowhere Player　视觉方向评审　2026-11

四个方向

同一份内容、同一组尺寸：播放器 340×120、终端 880×560；曲目《晴天》、队列五首、四条命令（help / search / perm / library scan）。四页只有材质与规则不同；缩略图是按各自材质画的示意，真实渲染请点开看。

  1. 深夜电台方向 A

    把播放器当设备做：细边框、刻度尺、一颗状态灯。没有投影，纵深只靠面板与底面的明度差。

    最像 Braun TG 60 面板 × OP-1

    打开

  2. 磷光方向 B

    两个窗口是同一块磷光屏的两个分区：等宽、全出血、无卡片，扫描线只在材质层里，不盖住字。

    最像 ncmpcpp × VT220 琥珀屏

    打开

  3. 纸与针方向 C

    唱片封套的排版逻辑：标题大过一切，分割线只有 1px，留白比内容多；终端也印在同一张纸上。

    最像 ECM / Blue Note 封套

    打开

  4. 混合方向 D　建议

    播放器取 C 的纸，终端取 B 的磷光；两者只共享 #C6402F 一个信号色，在纸上它是唱针，在屏上它是错误。

    最像 80 年代录音室的双屏工作台

    打开

一句话对比

方向播放器终端判断
A 深夜电台暖黑面板 + 刻度同一套面板材质最稳，长期挂在桌面不烦；个性最弱。
B 磷光琥珀读数琥珀等宽最锋利，辨识度最高；但最挑环境光，也最像“主题”。
C 纸与针唱片封套亮底印刷最美，但夜里刺眼；终端用亮底是真实代价。
D 混合取 C 的纸取 B 的磷光两个窗口各自成立，红色把它们绑成一件事。
建议

走 D。它不是 A/B/C 的平均，而是把“播放器是物件、终端是机器”这个判断显式化：纸负责手里，磷光负责屏上，红负责在两者之间指路。打开 D
