# 四个方向 · 自评

> 评审标准：`frontend-design` 里的「反模板化」清单。
> 方法：本地 headless Edge 实际渲染截图（1×，1440 宽）+ `getBoundingClientRect()` 实测尺寸 + WCAG 相对亮度算对比度。
> 一句话：**C 最好看，D 最值得做，A 最安全，B 最危险。**

---

## 0. 先过一遍「AI 模板感」清单

| # | 清单里的特征 | 这四页的命中情况 |
|---|---|---|
| 1 | 暖奶油底 + 高反差衬线标题 + 陶土色强调 | C / D 的纸材质命中「暖底 + 强调」，但**去掉了衬线**：换 Helvetica 系 grotesque；强调色 #C6402F 是一枚唱片标签，不是文字色 |
| 2 | 近黑底 + 单一荧光色强调 | B 直接命中（琥珀 #FFB454 + 朱红 #E05B3C），D 的终端继承 |
| 3 | 报纸式版式：发丝线、零圆角、密排 | A / C 命中——但这是 brief 指定的母题（细边框、刻度、无圆角），躲开等于不做题 |
| 4 | SaaS 卡片套装：统一圆角 + 同一层柔影 + 渐变当装饰 | 四页都没中：A 无投影无独立卡片，B 无卡片，C 无圆角，D 两个窗口都没有卡套 |
| 5 | 模板零件：全大写 tracked eyebrow、`A · B · C` 中点串、`WORD — 片段`、#0B0B0B 当黑、小数据用等宽、链接带 "→" | 改了三处，见下 |

**具体改掉的三处**

1. 页眉的 `A · B · C` 中点串 → 换成 1px 竖线（A）、斜杠（B）、全角空格（C/D）。四页没有一处用中点连接页面元信息。
2. 索引页的 `打开 →` → 改成 `打开`；所有正文链接都不带箭头。
3. 全大写 eyebrow → B 的品牌一律小写 `nowhere`；A/C/D 的眉标是中文小字，不做 tracking-caps。

**一处故意不躲**：第 3 条。A 和 C 的细线、零圆角就是 brief 的母题，判断标准换成「线有没有功能」——A 的每条线对应一个设备分区或一格刻度；C 的每条线都是印刷规则的实线（表头上下、印章边框、页脚）。

---

## 1. 方向 A 深夜电台

- **中了一条**：#3 的细线与零圆角。这是母题，保留，但把它从「报纸」改写成「仪器面板」：刻度分主次两级（每 25% 一根长针，每格一根短针），线只出现在设备边界，不在内容之间堆叠。
- **避开了 #4**：全页零投影，左栏的队列、色板都不是卡片，是同一块底面上的分区，没有独立边框也没有独立圆角。
- **改了什么**：brief 给的次色 `#6B5D4F` 在面板上实测 **2.74:1**，撑不住「周杰伦 / 叶惠美」这类正文字；派生 `#A08D76`（**5.45:1**）承担可读次级，原色退回刻度、时长注脚这类不可读装饰。这是对给定色板唯一一次偏离，已在页面里写明。
- **还差什么**：暖棕 + 琥珀离 #1 的暖调只差「奶油底 + 衬线」半步，靠「设备」的物理感（灯、键、刻度、无阴影）撑住；把饱和度调高 10% 就会滑向复古滤镜。

## 2. 方向 B 磷光

- **直接命中 #2**（近黑 + 单一亮色），这是最高危的一条；另外 #3 的零圆角也在。
- **改了什么**：不发光、不闪烁、不打 ASCII art。扫描线只放在**背景层**（`rgba(255,180,84,.022)`，周期 3px），不覆盖文字——盖上去的一瞬间就变成贴图式复古。品牌用小写 `nowhere`，避开终端主题最爱的全大写。等宽不是拿来当「小数据标签」（#5），而是整个材质本身，所以列宽就是结构。
- **红的纪律**：`#E05B3C` 只出现在「错误」和「当前项」两处；正文 11.34:1、次级 5.59:1、注释 3.45:1 三层，操作类文字（控制键、导航、输入提示）一律提到 5.5:1 以上。
- **还差什么**：单色磷光天然有「主题」味。它到底是原创还是皮肤，取决于表格和块流排得够不够严谨，而不取决于颜色——这一版是靠 19px 行高、列宽对齐和层级差撑的。

## 3. 方向 C 纸与针

- **面上最接近 #1**（暖奶油底 + 高饱和强调），但我拆掉了它的关键配方：**不用衬线**。#1 的高反差来自衬线标题，这里换成 Helvetica 系 grotesque，「唱片封套」的气质由字号、字距、留白给出，而不是字体本身。
- **红色不是强调色**：它先是一枚实体唱片标签（圆、同心纹、中心孔），然后才成为颜色。进度条上的红方块是唱针，不是「高亮」。
- **也命中 #3**（零圆角、1px 实线、大量留白），brief 指定，保留。亮底终端不做卡片化，而是「打印纸」：表头上下各一条实线夹住，错误块是一枚盖上去的红框章，进度是一根实墨。
- **改了什么**：试过纸纹（内联 `feTurbulence` data URI、0.16 透明度、multiply），实测把底色从 `#F2EFE8` 压到 **#CCC9C3**，而且给全页引入了一个 `url()`；删掉。纸感交给字号、留白和 1px 实线，不交给噪声——这也是页面上写的「纸感做重就成文创」。
- **还差什么**：亮底窗口在夜里刺眼，这是真代价。`#C6402F` 在纸上只有 **4.38:1**，只用在 13px/700 的印章码和导航当前位置上，不再往下压字号。

## 4. 方向 D 混合

- **同时带着 #1 和 #2**，最大的风险是「两个主题拼接」。
- **改了什么**：把红从「配色」提升为「规则」——纸上是标签与唱针，屏上是错误、当前项、进度针，全页只此一色。终端里的错误码本身用琥珀色（11.34:1），红只做 3px 竖线、16px 叹号和进度针：`#C6402F` 在 `#0A0806` 上只有 **3.98:1**，它不负责阅读，只负责指认。
- **没做**：两个窗口之间没有任何渐变、光晕或过渡装饰（一做就落回 #4 的「渐变当装饰」）；也没有给纸窗加投影，它只是比背景亮。
- **还差什么**：两窗亮度差约 10 倍，来回切换的「换了一台设备」感消不掉，只能靠红色的一致性缓解。另外 D 的播放器与 C 完全相同——这是有意的，D 的主张就是「C 的纸 + B 的屏」。

| a-late-night | 340 × 120 | 880 × 560 | 无 |
| b-phosphor | 340 × 120 | 880 × 560 | 无 |

溢出检查同时看了 `scrollHeight / scrollWidth`：`pl`、`tm`、`tm-stream` 三个容器都没有超出（C 的第一版曾多出 7px，已通过压行高修掉）。

## 6. 四页共有的问题

1. **页框是同一套**（眉标 → 标题 → 三条说明 → 导航 → 两窗 → 最像）。这是刻意的：评审要比材质，不是比版面。代价是四页的「版面」看起来像同一个产品的四种皮肤。如果进下一轮，建议只留 D 的页框。
2. **只渲染了 `playing` 一态**。`播放器小窗.md` 定了六态，但 brief 要求的是「播放中的内容」，其余五态没出现在样例里。这是已知缺口。
3. **控制键的处理偏离了现有实现**。`播放器小窗.md` 里控制键是 hover 才出现的浮层；样例页没法 hover，所以 A 把三个键做成面板上的常驻按键，B 用 `[space]` 键位提示，C/D 用印刷小图标。属于探索，不是实现建议。
4. **说明控制在 3 条**，每页渲染 3–5 行，没有超过 6 行。
5. 纯静态：四页没有一处 `url()`、没有外部字体与图片、没有网络请求；`prefers-reduced-motion` 与 `:focus-visible` 都做了。

---

## 7. 结论

**推荐 D。**

- 它没有把 A/B/C 平均，而是把「播放器是物件、终端是机器」这句话显式化：纸负责手里，磷光负责屏上，红负责在两者之间指路。
- 它保住了三个方向里最强的两个判断（C 的唱片封面感、B 的终端纪律），而这两个判断在单一路线里都会付出代价：C 的终端亮底刺眼，B 的播放器失去物件感。
- 代价也清楚：约 10 倍的亮度差、只能在终端里做标记的红、以及一套需要长期调校的双材质。

**如果只能选一个不冒险的**：A。它在任何环境光下都不出错，代价是「最不像一个记得住的产品」。

**B 与 C 更适合当组件，而不是整套**：B 的块流可以直接搬进 D 的终端，C 的播放器已经是 D 的播放器。
