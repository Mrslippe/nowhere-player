# Ratatui 视觉效果参考

> 来源：[ratatui.rs 官网](https://ratatui.rs/) 的 Showcase / Third Party Widgets / Ecosystem。
> 只记录**能用在音乐播放器上**的手法；纯仪表盘类的不列。

---

## 1. 生态里有什么

### 1.1 第三方控件（视觉相关）

| 控件 | 效果 | 我们能用来做什么 |
|---|---|---|
| `ratatui-image` | Sixel/Kitty/iTerm2 图像 | **已用**：专辑封面 |
| **`tui-big-text`** | 用 font8x8 渲染**大像素字** | **沉浸模式的大标题 / 大时间** |
| **`throbber-widgets-tui`** | 多种 spinner（Braille/方块/箭头） | 搜索中的加载指示 |
| `ratatui-textarea` | 多行编辑器 | 暂不需要（我们是单行命令） |
| `tui-piechart` / `tui-nodes` / `tui-tree-widget` | 饼图 / 节点 / 树 | 不需要 |
| `tui-scrollview` | 可滚动视口 | 长列表可选 |

### 1.2 生态项目

| 项目 | 价值 |
|---|---|
| **`tachyonfx`** | **特效与动画库**：淡入、扫过、溶解、颜色过渡，可组合叠加。**这是"TUI 也能有动效"的答案** |
| `ratcn` | 组件库集合 |
| `ratzilla` | Ratatui → 浏览器（我们用不到，已否决） |
| `mousefood` | 嵌入式 |
| `uefi` | UEFI 环境 |

### 1.3 内置示例里可直接偷的

| 示例 | 手法 |
|---|---|
| **`shadow`** | 用块字符在控件右下画**假阴影**（`░`） |
| **`collapsed-borders`** | 相邻面板共享边框，不重复画线 |
| **`canvas`** | **Braille 画布**（2×4 点/格） |
| `sparkline` | 单行折线（`▁▂▃▄▅▆▇█`） |
| `scrollbar` | 自带滚动条控件 |

## 2. 我们该用哪几个（按收益排序）

| # | 手法 | 收益 | 依赖 |
|---|---|---|---|
| **1** | **Braille 画布画频谱** | 纵向 8 倍分辨率，曲线像曲线 | 无（内置 `Canvas` + `Marker::Braille`） |
| **2** | **沉浸模式大封面** | Sixel 支持任意尺寸，清晰度显著提升 | 无 |
| **3** | **`tui-big-text` 风格的大字** | 沉浸模式显示大号时间/曲名 | 可用 crate 或手写 font8x8 子集 |
| 4 | **spinner 加载指示** | 搜索时有"在动"的反馈 | 手写 4–6 帧 |
| 5 | 假阴影 | 弹层浮起来 | 手写 |
| 6 | **tachyonfx 过渡** | 面板展开/切歌淡入 | **需 ADR**（新依赖） |

### 2.1 为什么 Braille 是第一位

一个单元格里 Braille 有 **2×4 = 8 个点**。同样是 4 行的频谱区：

```
块字符（现在）：      Braille：
▁▃▅▇▅▃▁              ⣀⣤⣶⣿⣶⣤⣀   ← 8 倍纵向精度
▁▃▅▇▅▃▁              ⣀⣤⣶⣿⣶⣤⣀
```

**同样的空间，能画出真正的波形。**

### 2.2 tachyonfx 要不要引

| 支持 | 反对 |
|---|---|
| 让"切歌""面板展开"有过渡，观感提升明显 | 新依赖（红线要 ADR） |
| 社区验证、官方生态页推荐 | TUI 动效收益远小于 GUI；且我们已把"无动效"当默认 |

**建议：先不引。** 等 TUI 功能收尾、产品稳定后，作为"锦上添花"再评估。

## 3. 不可迁移的手法

Showcase 里大量项目是**仪表盘/监控**类（btop 风格、图表密集型），它们的美学依赖：

- 常驻刷新的大面积色块
- 多面板同时更新
- 高密度数字

**我们是单任务播放器**，抄这些会显得吵。**只取"精度"和"层次"，不取"密度"。**

---

## 4. 结论

- **立刻做**：Braille 频谱、沉浸大封面、字形精选（`▁▂▃▄▅▆▇█` `░▒▓█` `◐◑`）。
- **候选**：`tui-big-text` 风格大字、spinner。
- **暂缓**：tachyonfx（需 ADR，收益中等）。
