# 配置窗（终端）

> CLI 风格的配置窗口。**代码为准**：`apps/web/src/features/terminal/`（`TerminalLab.tsx`、`components/CommandInput.tsx`）+ `renderers/blocks/`。
> 交互契约与命令见 [命令表](../30-计划/命令表.md)；数据模型见 [ARCH-005](../20-架构/终端输出模型.md)。

---

## 1. 布局

```
┌──────────────────────────────────────────────┐
│ 顶栏 36px：variant · 主题 · 清空              │
├──────────────────────────────────────────────┤
│ 块流（可滚动，默认贴底）                       │
│   › help                      12ms           │
│   ┌────────────────────────────────────────┐ │
│   │ play    播放队列中的曲目或文件…          │ │
│   │ queue   查看或编辑播放队列               │ │
│   └────────────────────────────────────────┘ │
├──────────────────────────────────────────────┤
│ › 输入框（40px，原生 input + Tab 补全弹层）    │
├──────────────────────────────────────────────┤
│ 状态栏 24px                                  │
└──────────────────────────────────────────────┘
```

| 区域 | 高度 | 说明 |
|---|---|---|
| 顶栏 | 36px | dev 期含 variant/主题/清空；生产只保留清空 |
| 块流 | 自适应 | 虚拟化未做，回滚上限由 `blocks` 数组长度控制 |
| 输入 | 40px | 原生 `<input>`，**IME 交给系统**，不画假光标 |
| 状态栏 | 24px | 键位提示 |

---

## 2. 块（Block）

一条命令 = 一个块，结构见 ARCH-005：

| 部分 | 内容 |
|---|---|
| 输入行 | `›` + 命令原文 + 右侧状态（running 转圈 / 完成显示毫秒） |
| 输出区 | 6 种原语：`text` / `table` / `progress` / `error` / `hint` / `media` |
| 尾注 | `footer`，12px `--fg-muted` |

**同 id 覆盖**：后端先发 `running` 再发最终块，前端按 `id` 原位替换，不追加。

### 2.1 错误卡（T-0045）

错误输出是块内的一张卡，不包住命令回显：

- 左侧 `4px` `--danger` 竖线 + `--bg-hover` 底 + `--np-radius-control` 圆角。
- 标题行：错误码（11px mono，muted）+ 一句话原因（13px）。
- 下一行 hint（11px，muted）。
- 底部按钮来自**块级** `Block.actions`（不是旧 `Output::Error.actions`）：
  - 「重试」主按钮 = 原命令；
  - search 失败时追加「只用本地搜索」= `search <关键词> --local`；
  - 非 search 只有「重试」，不造「跳过该目录」假按钮。
- 按钮是原生 `<button>`：Tab 可达、Enter/Space 触发、`title` 显示将执行的命令；点击走与输入框相同的 `cmd.exec`，不进 ↑/↓ 历史。
- 前端遇到非法 actions 时整组丢弃，但保留块本体。

## 3. 键盘

| 键 | 弹层关闭时 | 弹层打开时 |
|---|---|---|
| `Enter` | 执行命令 | **采纳**当前候选 |
| `Tab` | 请求补全；有候选才弹层 | 循环下一项 |
| `↑` / `↓` | 翻历史 | 移动高亮 |
| `Esc` | — | 关闭弹层 |
| `Ctrl+L` | 清屏（等同 `clear`） | — |

> 键位归属是这类界面最容易出 bug 的地方（`↑/↓` 被两处抢），已用 `decideKey` 纯函数收口并单测。

---

## 4. 补全

| 项 | 规则 |
|---|---|
| 触发 | `Tab`，调用 `cmd.complete { input, cursor }` |
| 候选来源 | 命令名 / 子命令 / 枚举值 / 动态队列序号 / 拼写建议 |
| 数量 | 后端最多 20，弹层只显示 8 |
| 替换 | 按 `replaceStart/replaceEnd`（**字符数**）替换当前 token，不重写整行 |
| 无候选 | 不弹层、不改变输入 |
| 失败降级 | 拿不到动态数据时返回空列表，不阻塞输入 |

---

## 5. 历史

| 项 | 规则 |
|---|---|
| 存储 | `localStorage["np.cmd.history"]`，上限 500，超限丢最旧 |
| 入栈 | 每条命令执行后（成功失败都入）；**连续重复不入栈** |
| 翻页 | `↑` 向旧、`↓` 向新；到底恢复"未提交的当前输入" |
| 容错 | 读写 `try/catch`（隐私模式） |

## 6. 特殊块

| 块 | 触发 | 表现 |
|---|---|---|
| 欢迎块 | 首次挂载 | 版本（`getVersion()`，失败回退 `0.0.0`）+ "输入 help 查看命令" |
| `E_STREAM_LOST` | `terminal:block` 订阅失败 | 固定 id 的错误块，只出一次；重开窗口可重试 |
| 清屏 | `clear` 或顶栏 | 清空块数组；`startedAt < clearedAt` 的在途块丢弃 |

## 7. 视觉

| 项 | 规格 |
|---|---|
| 字体 | `--font-mono`，13px，行高 1.6 |
| 背景 | `--bg`（全出血，无卡片） |
| 块间距 | 12px |
| 语义色 | 只用 `--accent` / `--danger` / `--warn` / `--success` / `--fg-muted` |

## 2.2 输入框与候选（T-0051 更新）

### 焦点条（下层琥珀卡）

- **形状**：输入框背后一张同宽卡，**只贴底**：`inset: auto 0 -2px 0`、`height: 14px`、只有下方两角圆（8px）。
- 视觉结果：露出一条 2px 的底边，两端**向上弯**（来自下方圆角）。顶部没有任何下层卡，不会漏色。
- **揭示动画**：`clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)`；聚焦 220ms `cubic-bezier(.22,1,.36,1)`，失焦 160ms `cubic-bezier(.4,0,1,1)`。
- 不用 `scaleX`（会拉伸圆角）。

### 表格列宽（三个表格统一）

| 列 | 宽 |
|---|---|
| 序号 | 48 |
| 来源 | 72 |
| **标题** | **`1fr`** |
| 艺人 | 160 |
| 时长 | 72 |

用 `data-role` 定位列，而不是按列序——`source` 在第 2 列或末列都能正确套用。

### 方向键归属（三态）

| 状态 | ↑/↓ |
|---|---|
| 候选开着、非历史导航 | **候选** |
| 历史导航中 | 历史（且不出候选） |
| 候选关闭 | 历史 |

用户再输入一个字符即清 `historyNavigating`，候选恢复。

### 候选动效

- 首次出现：淡入 + 上移 4px，**120ms**。
- 可见 → 可见且内容变化：更轻的 update 帧（opacity 从 .72），同 120ms。
- 内容不变：**不重播**。
- `prefers-reduced-motion`：无动画。

### 候选选中态（T-0051 修正）

- 背景 `--bg-hover` **加** 左缘 2px `--accent` 条（token `--np-shadow-completion-active`）。
- 原因：`#1a1e24` 与弹层底 `#14171c` 只差 6–8 个 RGB 级差，**单靠背景用户看不见**。
- 2px 琥珀条是"信号"，符合"琥珀只做信号"的原则；背景弱差保留但不再承担全部识别责任。
- 验收必须给像素或 3× 放大图证据（见 SPEC-001 §7.1）。

### Tab 采纳规则（T-0051 修正）

- **Tab 采纳当前高亮项**（`items[activeIndex]`），**不是列表第一条**。
- `activeIndex` 越界（列表刚刷新变短）→ 回退第一条，不崩。
- 采纳后立即**按新输入重算候选**；若新位置是参数位则关闭弹层。
- 弹层未打开时，Tab 只请求补全，不采纳。

实测：`p` → ↓（高亮 pause）→ Tab → `pause `；`p` → ↓↓（高亮 prev）→ Tab → `prev `。
