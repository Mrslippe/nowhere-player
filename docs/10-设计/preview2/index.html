A 太暗 / 无重点一个琥珀通道 全屏琥珀、靠透明度压次级；标题与正文同一亮度，没有落点。 换纸面。墨 16.6:1 + 20 px 标题；朱红只出现在播放头与错误边注，全窗两处。 五级明度。100/70/50/30/18，读数 15 px 最亮；t30 与 t18 只做线与底。 三级材质。#0d0f12 / #14171c / #1a1e24 + 唯一发光播放头。
B 比例不对拍出来的列宽 12 px 通排、29 px 行高，既不算紧也不算松；序号列空，标题列被截。 30 px 行 / 1.65。列宽 max-content + 1fr：序号 34、标题 616、艺人 68；41 行 0 截断。 22 px 行 / 4 px 栅格。列宽实测上取整到 4 的倍数；数字 tabular 右对齐。 28 px 行 / 8 px 阶。列宽全为 8 的倍数；底部三栏，控制键不随标题动。
C 像 DOS等宽 + 粗框 等宽 12 px 满屏、粗框、28 个碎块进度条；没有任何一处现代排版手段。 无衬线标题 + 等宽数据。没有一条内框；间距与字重代替线条。 保持等宽。这是它的选择；现代感来自刻度、点线与 tabular，不来自换字体。 无衬线界面 + 等宽数字。圆角、材质、模糊顶栏，走的是产品系统。
D 像调试工具没有产品动作 错误只有一行字，没有恢复路径；没有卡片、按钮、层级。 封面 + 内页。错误是边注，两行可点文字就是恢复路径。 面板式结构。键帽状控件、状态栏、点线统计——像设备，不像日志。 浮层命令行 + 卡片化错误。两个按钮，主次分明。

为什么是 D3。只有它同时动了三件事：明度（三级材质）、排版（无衬线界面 + 等宽数字）、产品动作（浮层命令行、错误卡的两个按钮）。A 与 D 是同一个问题的两端——「没有重点」和「没有产品」，D3 用「唯一发光的播放头」和「有恢复路径的错误」分别回答；C 由无衬线界面回答；B 由 8 px 间距阶与 28 px 行高给出明确决策。

但 D3 有一个真风险：它最容易被抄成「又一套深色 SaaS」。所以它必须保留两个反模板的东西——封面取色的光晕、以及只给一行的曲名。落到实现，把 D2 的表格规则（列宽实测、数字右对齐、表头 2 px 线）和 D1 的字阶（10/11/13/15/18/20）并进 D3，会比任何单一方向更稳。
