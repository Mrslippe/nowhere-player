# 动效规范

> 目的：**按"用户意图"而不是"元素"定义动效**，让所有切换、选取、加载、退出长得像同一个产品。
> 实现依据：token 在 `design/motion.css`；参考 [motion-ref](https://github.com/joepUI/motion-ref-skill)。

---

## 1. 八种角色

| 角色 | 用户感知 | 动什么 | 时长 | 缓动 |
|---|---|---|---|---|
| `enter` | 新东西出现 | `opacity` 0→1 + `translateY(4px)`→0 | 180ms | decelerate |
| `exit` | 东西消失 | `opacity` 1→0 | 120ms | accelerate |
| `select` | "当前"标记移动到别处 | `background` + 左缘条 | 120ms | standard |
| `switch` | 视图/主题/皮肤切换 | 交叉淡化（旧→新） | 240ms | standard |
| `expand` | 展开/收起 | `clip-path` | 180ms | standard |
| `progress` | 数值在推进 | `transform` | 线性 | linear |
| `feedback` | "我按到了" | `opacity` / `scale(.98)` | 80ms | standard |
| `load` | 还在等 | 循环/呼吸 | 循环 | linear |

**新增动效先归类**：归不进这八个，说明它大概率不该存在。

## 2. Token

```
--np-dur-instant: 80ms      feedback
--np-dur-fast: 120ms        exit / select
--np-dur-base: 180ms        enter / expand
--np-dur-slow: 240ms        switch
（progress 用 linear，时长由数值决定）

--np-ease-standard:    cubic-bezier(.2, 0, 0, 1)
--np-ease-decelerate:  cubic-bezier(.05, .7, .1, 1)
--np-ease-accelerate:  cubic-bezier(.3, 0, .8, .15)
--np-ease-linear:      linear
```

**已有但需归并**：`--np-dur-focus-in/out`（220/160ms）并入 `switch`/`exit` 语义；不再单独保留。

## 3. 五条硬规则

1. **只动 `opacity` / `transform` / `clip-path` / `box-shadow`**
   不动 `width` / `height` / `top` / `left` / `margin`（触发布局重算）。
2. **时长按触发方分级**
   - 用户操作（点、键、焦点）→ ≤ 180ms
   - 系统状态变化（加载完成、数据到达）→ ≤ 240ms
3. **同一元素同一时刻只跑一个动效**（叠加＝脏）。
4. **进入动画期间元素已可交互**——不得用 `pointer-events: none` 等动画播完。
5. **`prefers-reduced-motion: reduce` → 所有时长归 0**，只保留最终状态；**不得**因此改变布局或隐藏内容。

## 4. 什么时候**不该**加动效

| 情况 | 理由 |
|---|---|
| 高频重复的操作反馈（每敲一个键） | 会变成噪声 |
| 数据没变 | 无信息量 |
| 错误提示的"抖动" | 桌面工具里像故障 |
| 装饰性入场（每块都 fade-up 逐个延迟） | 拖慢阅读，且是 AI 生成感的典型标记 |

## 5. 反面清单（真实踩过）

| 现象 | 问题 |
|---|---|
| 用 `scaleX` 动画一条带圆角的条 | 圆角被拉伸变形 |
| 用 `width` 动画做进度条 | 每帧重排 |
| 只在首尾两帧验收动效 | 中间态可能完全不对（圆角消失） |
| 选中态只改背景 6 个色阶 | 逻辑对、用户看不见 |

## 6. 验收

动效必须给**中间帧**证据（`SPEC-001 §7.1`）：

- 进入/退出：至少一张 50% 时间点的截图或采样值；
- 选取：选中前后的**同一坐标像素差**；
- 进度：两次采样值递增。
