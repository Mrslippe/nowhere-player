# 公开样式契约 v1

> **这是对外承诺**：下面列出的选择器与 CSS 变量，升级时尽量不改名、不删。
> 其余所有类名都是内部实现，随时可能变。
>
> 用途：将来开放"用户 CSS"（ADR-0003 的 L2 层）。**现在只写文档、不实现加载**——但仍要守这份契约。

---

## 1. 窗口根

| 选择器 | 含义 |
|---|---|
| `[data-window="player"]` | 播放器小窗 |
| `[data-window="terminal"]` | 终端窗 |

`<html>` 上另有 `data-skin`（`plain` / `phosphor`）与 `data-theme`（主题 id），**可以用于选择器，但不要依赖具体取值**。

---

## 2. 颜色变量（14 个）

```
--bg  --bg-elev  --bg-hover
--fg  --fg-muted  --fg-faint
--accent  --accent-soft  --accent-fg
--danger  --warn  --success
--line  --line-strong
```

改它们就等于换色板。**不要在组件上直接写颜色**——覆盖变量是唯一被支持的方式。

---

## 3. 结构变量（skin 层）

圆角、描边、阴影、字体、密度、出血，完整清单见 [设计语言 §5.5](设计语言.md)。
它们由 skin 决定；用户 CSS **可以覆盖**，但覆盖后不再保证布局成立（后果自负）。

---

## 4. 播放器（8 个钩子）

```css
[data-window="player"] .np-player-card            /* 卡片根 */
[data-window="player"] .np-player-card__cover     /* 封面容器 */
[data-window="player"] .np-player-card__title     /* 标题 */
[data-window="player"] .np-player-card__sub       /* 艺人 · 专辑 */
[data-window="player"] .np-player-card__progress  /* 进度（线或分段条） */
[data-window="player"] .np-player-card__time      /* 时间 */
[data-window="player"] .np-player-card__controls  /* 控制键容器 */
[data-window="player"] .np-player-card__volume    /* 音量浮层 */
```

`.np-player-card` 上带 `data-status`：`idle` / `loading` / `playing` / `paused` / `error`。

---

## 5. 终端（4 个钩子）

```css
[data-window="terminal"] .np-blocks              /* 块流容器 */
[data-window="terminal"] .np-blocks-item         /* 单个块 */
[data-window="terminal"] .np-blocks-item__command/* 命令回显 */
[data-window="terminal"] .np-blocks-text         /* 文本输出 */
```

`.np-blocks-item` 上带 `data-status`：`pending` / `running` / `done` / `error` / `cancelled`。
`.np-blocks-text` 上带 `data-tone`：`accent` / `danger` / `warn` / `success` / `muted`。

---

## 6. 三个典型改法

```css
/* 1. 播放器换成硬边 */
[data-window="player"] .np-player-card {
  --np-radius-card: 0;
  --np-radius-inner: 0;
}

/* 2. 错误块加左侧竖线 */
[data-window="terminal"] .np-blocks-item[data-status="error"] {
  border-left: 2px solid var(--danger);
}

/* 3. 只改标题字重与字距 */
[data-window="player"] .np-player-card__title {
  font-weight: 700;
  letter-spacing: 0.04em;
}
```

---

## 7. 不承诺的部分

以下**不在契约内**，随时可变：

- 未在上面列出的任何 `.np-*` 类名（如 `__pane` / `__chip` / `__footer`）
- DOM 层级与元素类型（`div` 可能变 `span`）
- 内联 style 的具体值
- 动画时长与缓动曲线
- 主题 id 的具体取值（`graphite` / `phosphor` 等可能增删）

---

## 8. 变更策略

| 动作 | 允许度 |
|---|---|
| 给已列出的钩子**新增**样式 | 随时 |
| 改已列出的钩子的**语义**（比如标题改成显示专辑） | 需 ADR |
| **重命名 / 删除**已列出的钩子 | 破坏性；需主版本号 + 迁移说明 |
| 新增钩子 | 随时（但要先进本文件） |

契约版本记在 `Theme.contract`（当前 `1`）。破坏性变更时升到 `2`，加载器对旧主题给警告而非静默变形。

---

## 9. 现状

**本契约尚未对外承诺**——没有用户 CSS 加载器（ADR-0003 的 L2 已推迟）。
现在写它的目的是**约束我们自己**：内部重构时可以改任何东西，但上面这 12 个选择器与 14 个颜色变量，从今天起当作公开 API 对待。
