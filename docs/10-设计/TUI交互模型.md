# TUI 交互模型

> 产品决定（2026-11-12）：**不再"一切皆命令"**。参考社区同类 TUI 的做法重新设计交互。
> 命令系统**保留**，但降级为"高级模式"，不再是唯一入口。

---

## 1. 社区参照

| 项目 | 学它的什么 |
|---|---|
| **lazygit** | 多面板 + **底部上下文键位条**（随焦点变） |
| **k9s** | 列表为主 + `/` 就地过滤 + `:` 命令 |
| **ncmpcpp** | 音乐播放器的**窗格模型**（库/播放列表/浏览器多窗口切换） |
| **spotify_player** | 页面式布局 + `keymap.toml` 可配键位 + `?` 帮助 |
| **ranger / yazi** | 三栏（父/当前/预览）的视觉结构 |

**共同点**：**焦点 + 上下文键位 + 就地过滤**，而不是"输入命令再执行"。

## 2. 新布局

```
┌ Nowhere Player ──────────────────────────────── 本地 18 首 ┐
│ ▸ 媒体库        │ 1  晴天          周杰伦     04:29        │
│   搜索结果      │ 2  稻香          周杰伦     03:43        │
│   队列          │ 3  最长的电影    周杰伦     04:31        │
│   歌单          │ …                                       │
│     · 安可      │                                         │
│     · 夜跑      │                                         │
├─────────────────┴───────────────────────────────────────┤
│ [封面]  晴天 · Jay Chou                                  │
│ ▮▮▮▮▮▮▮▯▯▯▯▯   00:10 / 04:29                          │
│ ◀◀  ▶  ▶▶        ⣀⣤⣶⣿⣶⣤⣀  (频谱/波形/矢量)          │
├─────────────────────────────────────────────────────────┤
│ / 搜索 · : 命令 · ? 帮助 · Tab 切焦点 · Space 播放       │
└─────────────────────────────────────────────────────────┘
```

### 2.1 三个区域

| 区域 | 内容 | 宽度 |
|---|---|---|
| **左栏** | 视图/歌单列表（可折叠） | 20–24 列，可 `Ctrl+B` 收起 |
| **中栏** | 当前视图的条目列表（唯一可获得行焦点的地方） | 剩余宽度 |
| **下部** | 播放器条（封面 + 标题 + 进度 + 视觉区） | 固定高度 ~10 行 |

> 相比现在"右栏竖条"，**播放器改成横向条**——因为封面横着放更大，且不挤压列表宽度。

### 2.2 焦点

- `Tab` / `Shift+Tab` 在 **左栏 ↔ 中栏** 间切换（播放器条不可聚焦）。
- 当前焦点栏**边框高亮**，非焦点栏边框用 `faint`。
- 焦点在左栏时，`j/k` 切视图，`Enter` 进入该视图。

## 3. 模式

| 模式 | 进入 | 行为 |
|---|---|---|
| **Normal** | 默认 | vim 风格浏览；单键命令 |
| **Filter** | `/` | 就地过滤当前列表；`Esc` 退出过滤并保留结果 |
| **Command** | `:` | 打开命令输入行——**现有命令系统原样可用** |
| **Help** | `?` | 覆盖层：图示 + 全部键位（which-key 风格） |

**设计原则**：**常用操作单键，复杂操作命令**。
"播放选中"是单键，`play 3` 仍然可用；"导出主题"只有命令，不值得给键。

## 4. 键位表（Normal 模式）

### 4.1 全局

| 键 | 动作 |
|---|---|
| `Space` | 播放 / 暂停 |
| `n` / `p` | 下一首 / 上一首 |
| `+` / `-` | 音量 ±5% |
| `Tab` | 切换焦点 |
| `/` | 过滤 |
| `:` | 命令模式 |
| `?` | 帮助 |
| `q` | 退出（播放中二次确认） |

### 4.2 中栏（列表）

| 键 | 动作 |
|---|---|
| `j`/`k`、`↑`/`↓` | 移动 |
| `gg` / `G` | 首 / 尾 |
| `Enter` | **播放选中项** |
| `a` | 加入队列 |
| `A` | 加入歌单（弹选择层） |
| `d` | 从当前歌单移除 |
| `f` | 循环切换视觉模式（频谱/波形/矢量） |
| `Ctrl+F` | 沉浸模式 |

### 4.3 左栏（视图）

| 键 | 动作 |
|---|---|
| `j`/`k` | 切视图 |
| `Enter` | 进入并聚焦中栏 |
| `D` | 删除当前歌单（二次确认） |

## 5. 与命令系统的关系

**命令不消失，只是降级**：

| 场景 | 用哪个 |
|---|---|
| 播放第 3 首 | `Enter`（选中）或 `play 3`（命令） |
| 搜索在线 | `/` 过滤本地；**在线搜索仍需命令** `search 晴天`（或后续加 `/` 的前缀约定） |
| 导出主题、切缓存、改设置 | 命令 |
| 脚本化 / 可测试 | **全部命令仍然可调**（`np-app` 的 `Executor` 未变） |

**新增一个约定**：`/` 输入以 `!` 开头时走命令（如 `!search 晴天`），一个键搞定"过滤或搜索"。

## 6. 美学要点（承接 DES-010/011）

- 焦点栏边框 `accent`，非焦点 `faint`——**用边框表达焦点，不用背景色**（终端背景不可靠）。
- 选中行**反白**（`Reverse`），只给"当前行"，不给整列表。
- 播放器条上方一条 `─` 分隔，不用整个方块边框（省空间）。
- 视觉区固定 4 行，三种模式共用。
- **键位条随焦点变化**（lazygit 的核心做法）。

## 9. 上下文状态栏（2026-11-16 实现）

状态栏不再显示固定键位，也不显示页面标题，而是按当前焦点和页面显示：

```text
状态消息 / 当前页面特有功能 / 导航 / 全局键
```

优先级：

```text
确认状态
→ 页面特有功能
→ 播放/打开
→ 导航
→ 全局命令
```

确认统一为：

```text
第一次键进入待确认
Enter 执行
Esc 取消
```

歌单根：

```text
n 新建 · d 删除 · Enter 打开 · ↑↓ 选择 · Esc 返回
```

歌单子项：

```text
a 添加 · r 移除 · Enter 播放 · ↑↓ 选择 · Esc 返回
```

Queue：

```text
r 移除 · Space 暂停 · Enter 播放 · n/p 切歌 · Esc 返回
```

创建歌单输入框为 38×3，位于 List 内容区居中；删除歌单需 Enter 二次确认。
