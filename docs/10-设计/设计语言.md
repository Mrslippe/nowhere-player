# 设计语言

> 一句话：所有视觉决策都落在 `apps/web/src/design/tokens.css` 的变量里；组件里出现色值字面量即为 bug。
> 代码位置：`apps/web/src/design/`；可浏览的 demo：`pnpm -C apps/web dev` 后访问 `/design.html`。

---

## 1. 四条使用规则

1. **只从 `src/design` 取设计资源**：页面与业务组件不自己定义颜色/圆角/阴影。
2. **组件内禁止色值字面量**：只能 `var(--x)`；demo 页展示用的计算值除外（通过 `getComputedStyle` 取，不写死）。
3. **主题只靠 `data-theme` 切换**：`graphite`（缺省）/ `amber` / `ice`，在 `<html>` 或容器上设置。
4. **动效必须可降级**：`@media (prefers-reduced-motion: reduce)` 下所有过渡与动画归零。

## 2. Token 清单

### 2.1 颜色（`tokens.css`）

| 组 | 变量 |
|---|---|
| 背景 | `--bg`、`--bg-elev`、`--bg-hover` |
| 文本 | `--fg`、`--fg-muted`、`--fg-faint` |
| 强调 | `--accent`、`--accent-soft`、`--accent-fg` |
| 语义 | `--danger`、`--warn`、`--success` |
| 边线 | `--line`、`--line-strong` |

### 2.2 尺寸与动效

| 组 | 变量 | 值 |
|---|---|---|
| 间距 | `--sp-1..6` | 4 / 8 / 12 / 16 / 24 / 32 |
| 圆角 | `--r-sm/md/lg/xl` | 6 / 8 / 12 / 18 |
| 阴影 | `--shadow-1`、`--shadow-2` | — |
| 动效 | `--dur-fast/base/slow` | 120 / 160 / 240 ms |
| 曲线 | `--ease-out` | `cubic-bezier(.2,.8,.2,1)` |

### 2.3 字体（`typography.css`）

| 变量 | 值 |
|---|---|
| `--font-ui` | `Inter, "SF Pro Text", "Segoe UI", system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` |
| `--font-mono` | `"JetBrains Mono", "SF Mono", "Cascadia Code", monospace` |
| `--fs-10/12/13/15/20` | 字号阶 |
| `--lh-tight/base` | 行高 |
| `--tracking-caps` | 全大写小标题字距 |

**不打包字体文件**：先靠系统栈，M6 再决定是否自带（自带会让安装包 +2–4 MB）。

## 4. 组件 API

| 组件 | 关键 props | 说明 |
|---|---|---|
| `Button` | `variant: primary\|ghost\|danger`、`size: sm\|md` | `:focus-visible` 2px accent 环 |
| `IconButton` | `label`（必填，映射 `aria-label`）、`icon` | 32×32，图标 16px |
| `ProgressBar` | `value`、`max`、`indeterminate` | 用 `transform: scaleX()`；2px / 4px 两种高度 |
| `Spinner` | `size: sm\|md` | reduced-motion 下静止 |
| `Kbd` | `children` | 等宽、描边、底部 1px 厚边 |
| `Icon` | `name`（8 个具名图标） | 基于 `lucide-react`，**只允许具名导入** |

**图标集合**（v1 仅这 8 个）：`play`、`pause`、`skip-back`、`skip-forward`、`chevron-right`、`check`、`copy`、`alert-circle`。

> 注：lucide 1.x 把 `AlertCircle` 更名为 `CircleExclamationPoint`；对外 API 仍保留 `alert-circle` 名称，内部做映射，避免调用方跟着上游改名。

## 5. 界面使用约定

| 场景 | 约定 |
|---|---|
| 播放器小窗 | 见 [开发方案 §3.2](../30-计划/开发方案-v0.1.md)；圆角 18、内边距 16、封面 64 |
| 配置窗 | 见 [开发方案 §3.3](../30-计划/开发方案-v0.1.md)；等宽 13px，行高 1.6 |
| 悬停态 | `--bg-hover`，过渡 `--dur-fast` |
| 焦点态 | 2px `--accent` 外环 + 2px 偏移 |
| 危险操作 | 文字用 `--danger`，按钮用 `variant="danger"` |
