# 主题文件格式

> 用户主题放在 `<appdata>/themes/<id>.json`。改完重新应用即可生效（不需要重启）。
> 代码权威：`crates/np-core/src/theme.rs`（校验）、`apps/web/src/shared/theme-loader.ts`（应用）。

---

## 1. 一个完整例子

```jsonc
{
  "id": "my-theme",
  "name": "我的主题",
  "contract": 1,
  "skin": "phosphor",
  "tokens": {
    "bg": "#0A0806",
    "bgElev": "#120E08",
    "bgHover": "#1A140C",
    "fg": "#FFB454",
    "fgMuted": "#A87B3F",
    "fgFaint": "#5C4526",
    "accent": "#FFB454",
    "accentSoft": "rgba(255,180,84,.14)",
    "accentFg": "#0A0806",
    "danger": "#E05B3C",
    "warn": "#E5B45C",
    "success": "#7FC79A",
    "line": "rgba(255,180,84,.14)",
    "lineStrong": "rgba(255,180,84,.28)"
  }
}
```

## 2. 字段

| 字段 | 必填 | 规则 |
|---|---|---|
| `id` | ✅ | `[A-Za-z0-9._-]`，≤48 字节；**必须等于文件名主干**；禁止 `..`、路径分隔符、首尾点 |
| `name` | — | 缺省用 `id`；≤64 字符 |
| `contract` | ✅ | 当前为 `1`。不等于 1 时**仍加载**，但给一条警告（未来兼容用） |
| `skin` | — | `plain` / `phosphor`；未知值回落 `plain` |
| `tokens` | — | 缺项自动补 graphite 的值，不报错 |

## 3. 颜色格式

只接受四种：`#RGB`、`#RRGGBB`、`#RRGGBBAA`、`rgba(r,g,b,a)`（r/g/b 0–255，a 0–1）。

其它形式（`hsl()`、命名色、`color-mix()`）会被**跳过该项并记一条警告**——不是整个主题失败，而是那一项回落默认值。

## 4. token → CSS 变量

`camelCase` → `--kebab-case`：

```
bg→--bg          bgElev→--bg-elev      fg→--fg
fgMuted→--fg-muted   accent→--accent   danger→--danger
line→--line      lineStrong→--line-strong
```

## 5. 应用与回退

| 情况 | 行为 |
|---|---|
| 应用成功 | 写 `<html>` 的 inline 变量 + `data-skin` + `data-theme` + `color-scheme` |
| `fg`/`bg` 对比度 < 4.5:1 | 照常应用，终端输出一条 `hint` |
| 应用后 300ms 内哨兵元素宽或高为 0 | 判定崩坏 → 回退 `graphite`，输出 `E_THEME_BROKEN`，只尝试一次 |
| 窗口隐藏 / 找不到哨兵 | 跳过检查（不误回退） |
| 文件解析失败 | 该文件跳过，不影响其它主题 |

哨兵：优先 `[data-window]`（两个窗口都有），`.np-player-card` 只作兜底。

## 6. 内置主题

`graphite`（默认）/ `amber` / `ice` / `phosphor`。可以用 `theme.exportBuiltin` 导出一份到 `themes/` 作为改色起点（不覆盖已存在文件）。

## 7. 已知限制

- 主题只换**颜色**与 `skin`；结构（圆角、密度、字体）由 skin 决定，主题改不了。
- `phosphor` 的 xterm 视图会在主题切换时重建一次终端，可能有一帧闪烁。
- 没有主题选择 UI（M6），当前通过 `?theme=<id>` 或 dev 入口切换。
