# 主题文件格式

> 用户主题放在 `<appdata>/themes/<id>.json`。改完重新应用即可生效（不需要重启）。
> 代码权威：`crates/np-core/src/theme.rs`（校验）、`apps/web/src/shared/theme-loader.ts`（应用）。

---

## 1. 一个完整例子

```jsonc
{
  "id": "my-theme",
  "name": "我的主题",
  "contract": 1,
  "skin": "phosphor",
  "tokens": {
    "bg": "#0A0806",
    "bgElev": "#120E08",
    "bgHover": "#1A140C",
    "fg": "#FFB454",
    "fgMuted": "#A87B3F",
    "fgFaint": "#5C4526",
    "accent": "#FFB454",
    "accentSoft": "rgba(255,180,84,.14)",
    "accentFg": "#0A0806",
    "danger": "#E05B3C",
    "warn": "#E5B45C",
    "success": "#7FC79A",
    "line": "rgba(255,180,84,.14)",
    "lineStrong": "rgba(255,180,84,.28)"
  }
}
```

## 2. 字段

| 字段 | 必填 | 规则 |
|---|---|---|
| `id` | ✅ | `[A-Za-z0-9._-]`，≤48 字节；**必须等于文件名主干**；禁止 `..`、路径分隔符、首尾点 |
| `name` | — | 缺省用 `id`；≤64 字符 |
| `contract` | ✅ | 当前为 `1`。不等于 1 时**仍加载**，但给一条警告（未来兼容用） |
| `skin` | — | `plain` / `phosphor`；未知值回落 `plain` |
| `tokens` | — | 缺项自动补 graphite 的值，不报错 |

## 3. 颜色格式

只接受四种：`#RGB`、`#RRGGBB`、`#RRGGBBAA`、`rgba(r,g,b,a)`（r/g/b 0–255，a 0–1）。

其它形式（`hsl()`、命名色、`color-mix()`）会被**跳过该项并记一条警告**——不是整个主题失败，而是那一项回落默认值。

## 4. token → CSS 变量

`camelCase` → `--kebab-case`：

```
bg→--bg          bgElev→--bg-elev      fg→--fg
fgMuted→--fg-muted   accent→--accent   danger→--danger
line→--line      lineStrong→--line-strong
```

## 5. 应用与回退

| 情况 | 行为 |
|---|---|
| 应用成功 | 写 `<html>` 的 inline 变量 + `data-skin` + `data-theme` + `color-scheme` |
| `fg`/`bg` 对比度 < 4.5:1 | 照常应用，终端输出一条 `hint` |
| 应用后 300ms 内哨兵元素宽或高为 0 | 判定崩坏 → 回退 `graphite`，输出 `E_THEME_BROKEN`，只尝试一次 |
| 窗口隐藏 / 找不到哨兵 | 跳过检查（不误回退） |
| 文件解析失败 | 该文件跳过，不影响其它主题 |

哨兵：优先 `[data-window]`（两个窗口都有），`.np-player-card` 只作兜底。

## 6. 内置主题

`graphite`（默认）/ `amber` / `ice` / `phosphor`。可以用 `theme.exportBuiltin` 导出一份到 `themes/` 作为改色起点（不覆盖已存在文件）。

## 7. 已知限制

- 主题只换**颜色**与 `skin`；结构（圆角、密度、字体）由 skin 决定，主题改不了。
- `phosphor` 的 xterm 视图会在主题切换时重建一次终端，可能有一帧闪烁。
- 没有主题选择 UI（M6），当前通过 `?theme=<id>` 或 dev 入口切换。

## 6. 结构轴（T-0056 起）

主题 JSON 可选 `structure` 块，8 个枚举轴；缺项按 `skin` 预设补全。

| 轴 | 值 | 作用 |
|---|---|---|
| `radius` | `none / subtle / soft` | 卡片 0/6/14；播放器卡 0/6/14；封面 0/4/8；控件 0/4/8；**主播放键 0/4/50%** |
| `border` | `none / hairline / box` | `box` 只作用于块与表格，**不套窗口** |
| `density` | `compact / normal / relaxed` | 行高 20 / 26 / 30 |
| `progress` | `line / blocks / bracket` | 细线 / `▰▱` / `[■■□□]`；`blocks`/`bracket` 需 `font=mono` |
| `selection` | `bar / reverse / bg` | 左条 / 整行反白 / 仅底色 |
| `labels` | `sentence / tracked` | `tracked` = 字距 .06em + 字重 500 + uppercase（大写对中文无效，字距字重有效） |
| `stripe` | `off / on` | 表格隔行底色 |
| `font` | `mixed / mono` | mono 时界面也用等宽 |

**轴间互斥**（Rust 侧统一处理并给 warning）：

- `selection=reverse` + `stripe=on` → stripe 强制 `off`
- `progress=blocks|bracket` + `font=mixed` → progress 回退 `line`

**非法值**逐轴回落该 skin 预设，不整主题失败。

## 7. 内置 TUI 主题（T-0057）

| id | 名称 | structure 摘要 | 配色 |
|---|---|---|---|
| `tui-block` | TUI 块面 | 块面/紧凑/反白 | 暗色 + 去饱和青 `#8fbcbb` |
| `tui-wire` | TUI 线框 | 线框/紧凑/底色 | 暗色 + 琥珀 |
| `tui-paper` | TUI 票据 | 票据/常规/反白 | **亮色 + 单色墨（无强调色）** |

三个主题均为 `skin: "plain"` + 显式 structure，不新增 skin 枚举。
`theme list` 增加"结构"列，显示三轴缩写（如 `块面/紧凑/反白`）；用户主题显示"自定义"。

**设计约束**（不得违反）：

- `tui-block` 的 accent 必须是**去饱和**青，不得改为亮青（生成感最强的一类配色）。
- `tui-paper` 的 accent **等于墨色**——票据不印彩色，层级靠字重/反白/双线。
- `selection=reverse` 只用于「当前播放行」与「候选当前项」，不给所有可点行。
