# 播放器小窗

> 常驻桌面的一块 340×120 的卡片。**代码为准**：`apps/web/src/features/player/`（`player.css` + `PlayerCard.tsx`）。
> 本文记录已实现的尺寸、状态与交互；未实现的写在 §6。

---

## 1. 尺寸契约

| 项 | 值 |
|---|---|
| 内容区 | **340×120**（窗口装饰不在此内） |
| 缩放下限 | 300×104（低于此会出现裁切，见 §6） |
| 圆角 | `--r-xl`（18px） |
| 内边距 | `--sp-4`（16px） |
| 描边 | 1px `--line` |
| 背景 | `--bg-elev` + `--shadow-1` |

---

## 2. 结构

```
┌──────────────────────────────────────────────┐
│  ┌────────┐  标题 15/600（单行省略）           │
│  │ 封面   │  艺人 · 专辑 12/muted              │
│  │ 64×64  │                                  │
│  └────────┘  ━━━━━━━━━━━━━━━━━   01:23/04:05 │
│         └─ 控制键覆盖层（默认隐藏）            │
└──────────────────────────────────────────────┘
```

| 元素 | 规格 |
|---|---|
| 卡片布局 | `flex`，`gap: --sp-3`（12），垂直居中 |
| 封面 | 64×64，`--r-lg`（12）；无图时**确定性渐变** + 专辑首字（24px/600） |
| 文本列 | 单行省略；标题 15px/600，副标题 12px `--fg-muted` |
| 进度条 | 2px，hover 变 4px；用 `transform: scaleX()` 驱动，不用 `width` |
| 时间 | 10px，`tabular-nums`，格式 `mm:ss/mm:ss` |
| 控制键 | 绝对定位底部 22px 高带渐变遮罩；`opacity:0 + visibility:hidden`，卡片 hover 后 120ms 淡入；按钮为 `IconButton size="sm"`（20×20，图标 14） |
| 错误点 | 右上角 6×6，`--danger` |
| 拖拽 | 卡片带 `data-tauri-drag-region` |

---

## 3. 六种状态

| 状态 | 表现 | 触发 |
|---|---|---|
| `idle` | 显示"未在播放"，整体 60% 不透明度 | 无曲目 |
| `loading` | 封面位置 Spinner + 不确定进度 | 打开文件/解析中 |
| `playing` | 正常，进度条 `--accent` | `status: playing` |
| `paused` | `filter: saturate(.85)`，按钮变 ▶ | `status: paused` |
| `error` | 右上红点 + 标题位置"播放失败" | `error` 非空 |
| `hover` | 强制显示控制键（用于验收截图） | dev 预览 |

状态来源：真实数据来自 `player:state` 事件；`?state=` 仅供 dev 预览。

## 5.5 尺寸随 skin 变（T-0031）

同一份 DOM，`[data-skin]` 决定布局。**plain 是默认；phosphor 是第二种形态。**

| 项 | plain | phosphor |
|---|---|---|
| 封面 | 64×64 | **56×56**（圆角 0） |
| 内边距 | 16 | **8** |
| 内容高 | — | 104（8 + 80 + 10 + 14 + 8） |
| 进度 | 2px 细线 | **分段条：8px 高，6 实 + 3 空；红色播放头 6×12** |
| 控件 | hover 时浮在封面底部（64×22 热区） | **常驻底栏，14px 高；视觉 18×14，热区 28×22** |
| 空状态 | 整窗 60% 不透明度 | 同左（**不做分区透明度**） |
| 无封面 | 确定性渐变 + 专辑首字 | **单色块 + 首字**（不用 duotone，避免第二种颜色） |
| 布局 | 卡片内 flexible | 三段固定：信息 / 进度 / 控件 |

**进度驱动**：`--np-progress`（0–1）由 `progressRatio(positionMs, durationMs)` 计算，越界钳制。
分段条不新增 DOM：`.np-player-card__progress` 的 `background`（空轨道）+ `::before`（`clip-path` 填充）+ `::after`（播放头）。

**player 作用域变量**（仅 phosphor 定义）：`--np-player-pad` / `--np-player-cover` / `--np-player-progress-height` / `--np-player-controls-height`。
