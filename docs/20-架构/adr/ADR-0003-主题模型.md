# ADR-0003 主题模型

> 背景：产品要"多种内置主题 + 用户自定义主题"。四个设计方向（深夜电台 / 磷光 / 纸与针 / 混合）已经做出来，但它们的差别**一半是颜色，一半是结构**。

---

## 1. 问题的本质

| 差异 | 例子 | 能否靠配置表达 |
|---|---|---|
| 颜色、圆角、阴影、字体、间距 | 背景 `#14100E`、圆角 6px、无投影 | ✅ 变量 |
| 结构 | 「纸」是实线+零圆角+大字号；「磷光」是全出血+等宽；「面板」是细边框+刻度 | ❌ 必须换 CSS 规则 |

**如果只做变量**：四个方向会退化成"同一个界面换四种配色"——C 的纸配上圆角卡片就不再是纸。
**如果允许用户写 CSS**：不可验证、不可维护，且主题之间会互相污染。

---

## 2. 决定

**两层模型：`tokens`（完全开放）+ `skin`（有限枚举）**，且**两个窗口可各自指定 skin**。

```jsonc
{
  "id": "late-night",
  "name": "深夜电台",
  "skin": "device",                  // 默认 skin
  "windows": {
    "player":   { "skin": "paper" }, // 覆盖：播放器用纸
    "terminal": { "skin": "phosphor" }
  },
  "tokens": {
    "bg": "#14100E", "bgElev": "#1E1916",
    "fg": "#E8DCC8", "fgMuted": "#A08D76", "accent": "#D98A3D", "danger": "#C6402F",
    "radius": "6px", "shadow": "none",
    "fontMono": "…"
  }
}
```

**skin 枚举（v1 上限 3 个）**：`device` / `phosphor` / `paper`。
每个 skin 是一份结构性 CSS：圆角策略、边框、字号阶、密度、装饰母题。**新增 skin 是写代码，不是写配置。**

**D（混合）不是第四个 skin**，它是 `player: paper` + `terminal: phosphor` 的一组配置。

---

## 3. 备选方案与否决理由

| 方案 | 否决理由 |
|---|---|
| 只做 tokens（纯换色） | 四个方向里三个会失真，等于没做 |
| 允许用户注入 CSS | 无法验证布局是否还成立；主题可被用来做任意事；升级后必坏 |
| 每个主题一份完整组件树（React 换肤） | 维护成本 N 倍，且破坏了 `renderers/blocks` 的稳定性 |
| 用第三方主题引擎（如 Tailwind 主题） | 我们已有 token 体系（DES-001），再叠一层只增加复杂度 |

---

## 4. 后果

**正向**：
- 用户能调出任意配色，结构从 3 个里选；四个设计方向都能作为内置主题提供
- D 这类"双材质"天然支持，不需要特殊代码

**代价（必须接受）**：
1. **组合不可穷举**：3 skin × 任意配色。我们只能保证"token 齐全 + 对比度警告"，保证不了"每种组合都好看"。
2. **结构层重构是前置成本**：现有组件的结构写死在样式里，必须先拆成「token 层 / 结构层」，否则换 skin 会牵一发动全身。**约 3 天，且不能边做边改方向。**
3. **主题不解决夜间刺眼**：`paper` 的 `#F2EFE8` 在暗环境仍是光源。这需要独立的"夜间纸"机制（跟随系统时间/明暗），**不做成第五个主题**。

---

## 5. 落地顺序（已按"买架构、不买生态"收窄）

| 阶段 | 内容 | 状态 |
|---|---|---|
| M4-1 | 结构层重构（token 层 / 结构层分离） | ✅ 完成（T-0027，23 个变量，`plain` 零像素回归） |
| M4-2 | **只做 `phosphor` 一个 skin**（默认），保留现有观感为 `plain` | 待做 · 1 天 |
| M4-3 | 主题加载器（JSON → CSS 变量）+ 安全模式 + CSP 限制 | 待做 · 1 天 |
| M4-4 | 公开类名契约**只写文档**，不实现用户 CSS 加载 | 待做 · 0.5 天 |
| ~~M4-5~~ | ~~`paper` / `device` skin~~ | **推迟**（有用户后） |
| ~~M4-6~~ | ~~用户 CSS 加载（L2）~~ | **推迟** |
| ~~M4-7~~ | ~~主题编辑器 / 夜间纸 / 社区主题~~ | **推迟**（v1 后） |

**总计 5.5 天**（原方案 9–10 天）。

**默认 skin = `phosphor`**（产品决定，2026-11-09）。
理由：终端窗本来就是磷光质感，播放器与之统一后两个窗口是"一块屏的两个分区"；`plain` 作为回退保留。

### 为什么砍掉 L2（用户 CSS）但保留契约文档

- 契约文档是**零成本**的：只要类名稳定，将来加加载器只是 20 行代码。
- 反过来，若现在不写契约、类名随便改，将来要做用户主题就得先做一次全局重命名——**那才是真正的成本**。
- 没有真实用户时设计的契约，大概率是错的；先让 8–12 个类名在内部用三个月，再公开更稳。
