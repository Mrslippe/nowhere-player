# ADR-0010 直播缓冲设置、WSOLA 与弹幕发送基础设施

> 状态：**已接受**（2026-11-18）。T-0093/T-0094/T-0095 已完成，全量门禁 899 tests 通过。

---

## 1. 背景

直播默认已切到 `qn25000 HEVC only_audio + target900`。用户需要：

1. 在 Settings 自定义 buffer；
2. 参考网页脚本的追帧，但用 WSOLA 保持音高；
3. 先做可测试的弹幕发送层；
4. Live 页独立占满屏幕，信息行叠加、音高条用颜色而非空方块。

## 2. 决策

### 2.1 Buffer 设置

```text
live.buffer_ms
默认 900
范围 500–2000
```

- `np-core` 定义 key/default/min/max；
- Settings 页编辑，100ms 步进；
- 保存后下一次 `/live` 生效；
- `NP_LIVE_TARGET_MS` 仍为调试覆盖，优先级最高；
- `np_live::set_target_buffer_ms` 进程级 Atomic，宿主在 `start_live` 调用。

### 2.2 WSOLA

- `np-audio::WsolaTempo`：20ms 窗、10ms hop、±5ms 相位搜索、Hann 权重归一；
- 速度 1.00–1.10，不降速；
- buffer > target+100 → 1.05；> target+300 → 1.10；≤ target → 1.00；
- 1.00x 逐样本还原；
- target+500 硬丢帧兜底保留；
- 1.05/1.10 实测基频 1000Hz 保持，时长比接近理想。

### 2.3 弹幕发送

`np-sources::Transport::post_form` 窄接口；`ReqwestTransport` 实现 form POST。

```text
np_live::danmaku::send_danmaku(transport, auth, room_id, message)
```

form：

```text
csrf / csrf_token = bili_jct
roomid / msg
color=16777215, fontsize=25, mode=1, rnd, plat=1
```

- 5s 进程级限速；
- 错误映射：未登录、csrf、风控、限速、禁言、HTTP；
- 不打印 cookie/csrf/body；
- 不自动重试。

### 2.4 Live 页基准

```text
72×24
Player 68×22 at x2,y1
视觉区 66×19 at x3,y2
信息行叠加视觉区最后一行 y20，右对齐「直播标题 - 分区」
音高行 66×1 y21，64 格 ▰，只用颜色区分
控制条在 Player 下框线 y22
状态栏 y23
小尺寸 visual_h=max(1,H-5)，player_w=W-4，不降级
```

- 主播名 Player 上边左侧；
- 分区优先 `area_name`，回退 `parent_area_name`；
- 主播名 best-effort `get_anchor_in_room`；
- 小于 72×24 仍进 Live 页，压缩视觉区。
