# ADR-0010 直播缓冲设置、WSOLA 与弹幕发送基础设施

> 状态：**已接受**（2026-11-18）。T-0093/T-0094/T-0095 已完成，全量门禁 899 tests 通过。
> 2026-11-20 修订：WSOLA 阈值按 T-0108 改为脚本式；视频模式音频主时钟见 [ADR-0011](ADR-0011-视频模式mpv音视频主时钟.md)。

---

## 1. 背景

直播默认已切到 `qn25000 HEVC only_audio + target900`。用户需要：

1. 在 Settings 自定义 buffer；
2. 参考网页脚本的追帧，但用 WSOLA 保持音高；
3. 先做可测试的弹幕发送层；
4. Live 页独立占满屏幕，信息行叠加、音高条用颜色而非空方块。

## 2. 决策

### 2.1 Buffer 设置

```text
live.buffer_ms
默认 900
范围 500–2000
```

- `np-core` 定义 key/default/min/max；
- Settings 页编辑，100ms 步进；
- 保存后下一次 `/live` 生效；
- `NP_LIVE_TARGET_MS` 仍为调试覆盖，优先级最高；
- `np_live::set_target_buffer_ms` 进程级 Atomic，宿主在 `start_live` 调用。

### 2.2 WSOLA

> 2026-11-20 T-0108 按用户确认的浏览器追帧脚本策略修订；旧值（1.00–1.10、1.05/1.10、硬丢）作废。

- `np-audio::WsolaTempo`：20ms 窗、10ms hop、基础 ±5ms 相位搜索（低速时动态扩到 12ms）、Hann 权重归一；
- 速度 0.60–1.30；
- `buffer > target` → 1.10；`> target+1s` → 1.20；`> target+2s` → 1.30；
- `buffer < min(600ms,target)` → 0.60（脚本 0.2/0.3 档统一到 0.6 下限，20ms 窗更低会断）；
- 回到 target 恢复 1.00；**运行期不硬丢帧**；
- 1.00x 逐样本还原；1.20/1.30/0.60 基频保持，时长比接近理想。

### 2.3 弹幕发送

`np-sources::Transport::post_form` 窄接口；`ReqwestTransport` 实现 form POST。

```text
np_live::danmaku::send_danmaku(transport, auth, room_id, message)
```

form：

```text
csrf / csrf_token = bili_jct
roomid / msg
color=16777215, fontsize=25, mode=1, rnd, plat=1
```

- 5s 进程级限速；
- 错误映射：未登录、csrf、风控、限速、禁言、HTTP；
- 不打印 cookie/csrf/body；
- 不自动重试。

### 2.5 弹幕接收

- `getDanmuInfo` 需要 WBI 签名 + buvid3/buvid4；否则 -352。
- 先 plain 请求；命中 -352/-403/-412 后取 nav+spi、补 buvid 并签名重试；线程内缓存 1h。
- blocking tungstenite + rustls；op7/op8、30s 心跳、zlib/brotli、DANMU_MSG → mpsc。
- TuiAudio 500 条环形缓冲；断线 1/2/5/10/20/30s，最多 6 次。
- 真实 room 23197314 已验证 211 条/35s，心跳跨 30s。

### 2.6 弹幕输入

- Live 页 `c` 打开底部 3 行输入框（68 宽，内容 64）；
- Enter 发送、Esc 取消、20 字符上限、CJK 光标；
- 未登录提示 `/login bili`，不请求；
- 后台线程发送，generation 防旧结果串台；成功关闭、失败保留；
- T3 真实发送由人工执行。

### 2.4 Live 页基准

```text
72×24
Player 68×22 at x2,y1
视觉区 66×19 at x3,y2
信息行叠加视觉区最后一行 y20，右对齐「直播标题 - 分区」
音高行 66×1 y21：28×(▰+空格) + 8 格开播时长
控制条在 Player 下框线 y22
状态栏 y23：最左 LIVE/PAUSE
小尺寸 visual_h=max(1,H-5)，player_w=W-4，不降级
```

- 主播名 Player 上边左侧；
- 分区优先 `area_name`，回退 `parent_area_name`；
- 主播名 best-effort `get_anchor_in_room`；
- 小于 72×24 仍进 Live 页，压缩视觉区。
- T-0098：Browse/Settings 滚动、状态 3s TTL、Settings Enter 编辑态；音高条按内容宽度伸缩，buffer 显示固定在底边框内，不用字面短横。
