# ADR-0005 设置存储与命令族

> 产品决定（2026-11-10）：**all in terminal**。不做设置窗口，主题切换、音源开关、缓存管理全部通过命令完成。
>
> ⚠️ **部分被取代（2026-11-13）**：封面缓存相关约定（`covers` 类别）已由
> [`ADR-0007`](ADR-0007-移除封面子系统与schema-v3.md) 取代；设置存储与其余命令族仍然有效。

---

## 1. 一个存储，几个门面

设置只有一份存储：`<config_dir>/settings.json`（Tauri `app_config_dir()`）。

命令按域分组，但**读写的是同一份 store**：

| 命令族 | 作用 | 底层 key |
|---|---|---|
| `theme list/set/export` | 主题 | `theme.id` |
| `source list/enable/disable` | 音源开关 | `source.<id>.enabled` |
| `cache stat/clear` | 缓存 | 只读统计 + 删除，不存配置 |
| `config list/get/set/unset` | 通用 | 任意点分 key |

这样加新设置不需要新命令：`config set playback.crossfadeMs 300`。

## 2. key 与值

- key 用点分小写：`theme.id`、`source.bilibili.enabled`、`cache.streams.maxMb`。
- 值只允许三种：字符串 / 数字 / 布尔。**不允许嵌套对象**——嵌套用点分 key 表达。
- `config set` 的解析顺序：`true|false` → 布尔；纯数字 → 数字；其余 → 字符串。
- 未知 key **允许写入**（前向兼容），但 `theme.id` / `source.*` 这类**受控 key** 要校验取值。

## 3. 优先级

```
命令显式参数  >  settings.json  >  内置默认
```

例：`theme set phosphor` 写文件并立即生效；`?theme=ice`（dev 预览）只在本次会话覆盖，不写文件。

## 4. 启动时应用

`setup` 里读一次 settings：

1. `theme.id` 存在且能找到 → 注入该主题（前端启动时经 `theme.apply` 应用，与现在一致）。
2. `source.<id>.enabled == false` → 该源不进 `SourceRegistry`。
3. 读失败（JSON 坏）→ **备份为 `settings.bad.json` 并回落默认**，不阻塞启动。

## 5. 写入

- 原子写：`settings.json.tmp` → rename。
- 不保留注释、不保留键顺序（JSON 无注释；顺序按写入稳定排序，便于 diff）。
- 并发：进程内一把锁；不做跨进程（单实例应用）。

## 6. 缓存命令

> 2026-11-13 修订：封面子系统已按 [`ADR-0007`](ADR-0007-移除封面子系统与schema-v3.md) 移除，
> `cache` 不再管理 covers。以下为当前契约。

`cache stat` 只读，输出 streams 的文件数/体积与总计。

`cache clear [streams|all]`：
- 删除对应目录下的文件（**不删目录本身**）。
- 正在播放的远程曲目 → 先停止播放再删（避免删掉正在读的文件）。
- 删除后输出释放的体积。

## 7. 明确不做

- 不做设置窗口。
- 不做 GUI 内的开关控件。
- 不做配置热重载的文件监听（改完重新执行命令即可）。
