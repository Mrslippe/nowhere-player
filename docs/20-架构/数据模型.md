# 数据模型

> M3 的契约：**表结构不定，扫描与搜索都没法写**。
> 归属：`crates/np-library`（SQLite 只在这一个 crate 里出现，其他 crate 不直接依赖 rusqlite）。

---

## 0. 本版决定（2026-11-09）

| # | 决定 | 理由 |
|---|---|---|
| 1 | **建 `albums` / `artists` / `track_artists` 关联表** | 后续一定要做专辑视图与艺人页；现在建只多几十行 upsert，改起来却是 migration |
| 2 | 文件消失只标记、不删除 | 移动硬盘没插、网络盘掉线时避免"全库消失" |
| 3 | 解析并行（rayon）、写库单线程 | 避免 SQLite WAL 频繁 BUSY |
| 4 | 封面用内容哈希命名 | 同专辑只存一份，换目录不用重生成 |

---

## 1. 基本约定

| 项 | 约定 |
|---|---|
| 引擎 | SQLite（`rusqlite`，bundled），**WAL 模式** |
| 位置 | 应用数据目录 `library.db` |
| 时间 | 全部 Unix 毫秒（INTEGER） |
| 主键 | 全部 `INTEGER PRIMARY KEY` |
| 文本 | UTF-8；路径存绝对路径 |
| 迁移 | `PRAGMA user_version` 递增；升级前自动备份 `.db.bak` |
| 外键 | `PRAGMA foreign_keys = ON`，但**不做级联删除**（手动清理） |

**归一化与冗余并存**：分组/关联用 `*_id`，全文检索与展示用 `tracks.artist` / `tracks.album` 文本列。写入时同时更新，ids 是权威，文本是缓存。

## 2. 表

### 2.1 `artists`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | |
| `name` | TEXT | **UNIQUE COLLATE NOCASE**，去重靠它 |

### 2.2 `albums`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | |
| `title` | TEXT | |
| `album_artist_id` | INTEGER | 外键 → artists.id，可为 NULL |
| `year` | INTEGER | 0 表示未知 |
| `cover_key` | TEXT | 专辑级封面（取该专辑第一首有封面的） |

**唯一约束**：`UNIQUE(title COLLATE NOCASE, album_artist_id)`。

### 2.3 `tracks`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | |
| `kind` | TEXT | `local` / `remote`（v1 只有 local） |
| `path` | TEXT | 绝对路径；远程为空串 |
| `source` | TEXT | `local` / `netease` / `bilibili` / `yt` |
| `source_id` | TEXT | 远程 ID；本地空串 |
| `title` | TEXT | 缺失时用文件名兜底 |
| `album_id` | INTEGER | 外键 → albums.id，可为 NULL |
| `album` | TEXT | **冗余**：展示与 `LIKE` 检索用 |
| `artist` | TEXT | **冗余**：多艺人 `,` 连接，用于检索 |
| `album_artist` | TEXT | **冗余** |
| `track_no` / `disc_no` / `year` | INTEGER | 0 表示未知 |
| `duration_ms` / `sample_rate` / `channels` / `bitrate` | INTEGER | |
| `codec` | TEXT | `flac` / `mp3` / `aac` … |
| `cover_key` | TEXT | 曲目级封面（内嵌图优先） |
| `size_bytes` | INTEGER | 增量扫描 |
| `mtime_ms` | INTEGER | 增量扫描 |
| `added_at` | INTEGER | 首次入库 |
| `last_seen_at` | INTEGER | 最近一次扫描见到（缺失判定） |

**唯一约束**：`UNIQUE(kind, path)`；`UNIQUE(source, source_id)`（`source_id` 非空时）。

### 2.4 `track_artists`

| 列 | 类型 | 说明 |
|---|---|---|
| `track_id` | INTEGER | → tracks.id |
| `artist_id` | INTEGER | → artists.id |
| `position` | INTEGER | 0 起，保持标签里的顺序 |

主键：`(track_id, artist_id)`；索引 `idx_ta_artist (artist_id)`。

### 2.5 `scan_roots`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | |
| `path` | TEXT | UNIQUE |
| `added_at` | INTEGER | |
| `last_scan_at` | INTEGER | 0 = 从未扫描 |

### 2.6 `play_history`

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | INTEGER PK | |
| `track_id` | INTEGER | → tracks.id |
| `played_at` | INTEGER | |
| `completed` | INTEGER | 0/1 |

索引：`idx_history_played (played_at DESC)`。

### 2.7 `settings`

`key TEXT PK` / `value TEXT`（JSON）。只存运行时状态；用户可编辑配置走 TOML。

### 2.8 索引汇总

| 表 | 索引 |
|---|---|
| tracks | `(kind,path)` 唯一、`(source,source_id)` 唯一、`title COLLATE NOCASE`、`artist COLLATE NOCASE`、`album_id`、`last_seen_at` |
| albums | `(title COLLATE NOCASE, album_artist_id)` 唯一、`album_artist_id` |
| artists | `name` 唯一 |
| track_artists | `(track_id,artist_id)` 主键、`artist_id` |
| play_history | `played_at DESC` |

### 2.9 队列（**不入库**）

T-0015 的队列是内存结构。持久化留 M4（届时新增 `queue_items(position, track_id)`）。

## 3. 封面缓存

| 项 | 约定 |
|---|---|
| 位置 | `<appdata>/covers/` |
| 命名 | `cover_key` = 内容哈希前 16 位 hex |
| 格式 | 512px 长边 WebP（quality 80） |
| 来源优先级 | 内嵌图 > 同目录 `cover.jpg` / `folder.jpg` / `front.jpg` |
| 专辑级 | 取该专辑中**第一首**成功提取的封面 |
| 清理 | 扫描结束时删除无引用的封面文件 |

---

## 4. 扫描语义

| 规则 | 说明 |
|---|---|
| 遍历 | 递归；跳过隐藏目录、`node_modules`、`.git` |
| 扩展名白名单 | `flac mp3 m4a aac ogg opus wav aiff aif` |
| 增量 | `(size_bytes, mtime_ms)` 未变 → 跳过解析，只更新 `last_seen_at` |
| 消失 | 未见到的旧记录只更新 `last_seen_at`，**不删** |
| 失败 | 单文件失败记录错误、继续；不中断整轮 |
| 取消 | 可取消，已入库部分保留 |
| 并发 | 解析 `rayon` 并行；**写库单线程** |
| 归一化 | 每首曲目 upsert `artists`（按 name 去重）→ `albums`（按 title+album_artist）→ `tracks` → `track_artists` |

---

## 5. 查询契约（给命令层用）

| 用途 | 语义 |
|---|---|
| `search(keyword, limit)` | 在 `tracks.title/artist/album` 上 `LIKE %kw%`（不区分大小写），按 title 排序 |
| `list_recent(limit)` | `added_at DESC` |
| `list_albums(limit)` | 按 albums.title 排序，带曲目数与封面 |
| `list_artists(limit)` | 按 artists.name 排序，带曲目数 |
| `tracks_by_album(album_id)` | 按 `disc_no, track_no` 排序 |
| `tracks_by_artist(artist_id)` | 经 `track_artists` 连接 |
| `stats()` | 曲目数 / 专辑数 / 艺人数 / 总时长 / 最近扫描 |

---

## 6. 边界（明确不做）

- 不做多用户/权限、不做网络库、不做标签写回。
- 不做播放列表持久化（M4）。
- 不做 FTS5（一万首以内 `LIKE` 够用；M4 加虚表，`search` 语义不变）。
