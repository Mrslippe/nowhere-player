# 测试规范

> 目标：**便宜的证据优先**。能用文本断言就不用截图，能用截图就不用等人。
> 本项目不追求覆盖率数字，追求“关键行为有回归测试、失败可定位”。

---

## 1. 分层

| 层 | 工具 | 覆盖 | 成本 |
|---|---|---|---|
| 单元 | `#[test]` | 解析、队列、状态机、迁移、过滤、纯函数 | 极低 |
| 渲染 | `TestBackend` + 金标 | 布局、块、补全、状态栏、播放器条 | 低 |
| 集成 | `tests/` + 假 `Transport` | 扫描/查询/音源 DTO/下载缓存 | 中 |
| 无头端到端 | `NP_TUI_SELFTEST` | 命令 → 状态 → 文本输出 | 低 |
| 真机 | 人看/人听 | 声音、托盘、媒体键、字体/颜色 | 高 |

**规则**：能在第 1/2 层证明的，不要拖到第 4/5 层；标 `[数字]` 的验收不许用截图交差。

---

## 2. 必须测什么

- 命令解析：形状、别名、默认子命令、错误码、拼写建议。
- 播放状态机：play/pause/seek/ended/next/prev/repeat/shuffle。
- 队列与歌单：1 基序号、上下文切换、删除/重排。
- 数据库：空库迁移、v2→v3 旧库迁移、备份、查询契约。
- 音源：DTO 解析、签名/取流、下载原子写、缓存 LRU、错误映射。
- 删除/重构：残留入口为零、旧命令被拒绝、迁移可回退到备份。
- 渲染：关键块金标；布局在 100×30 / 140×40 两档不重叠。

---

## 3. 夹具与隔离

- 网络测试**不得访问真实平台**；用 `fixtures/` + 假 `Transport`。
- 不提交 cookie/token/真实账号；夹具 URL 用 `example.invalid`，token 用 `synthetic`。
- 文件/数据库测试用系统临时目录；命令层测试用 `NP_TUI_DATA_DIR` 隔离。
- 每张卡至少一条可复现命令；报告只贴结论行，完整输出写 `tmp/`。

---

## 4. 金标与视觉

- 金标文件在 `crates/np-tui/tests/golden/`，更新必须说明差异（`UPDATE_GOLDEN=1`）。
- 版本号进入标题时，bump 版本会改金标；这是预期，不要用通配符绕过。
- 截图只用于字体/颜色/抗锯齿；布局错位先 dump 字符网格或 `TestBackend`。
- 像素比较用 `scripts/tools/png-hash.mjs`；跨机器才用 `pixel-diff.py`。

---

## 5. 覆盖率与豁免

- 不设硬覆盖率门槛；新增逻辑必须有测试，或卡里写豁免理由。
- 删除卡：测试数下降是预期；报告“删了哪些子系统”，不是“≥N”。
- 无法自动化的项（声音、托盘、媒体键、真实输入法）进“人工验收清单”，写清谁在什么设备上验。

---

## 6. 失败处理

| 现象 | 处理 |
|---|---|
| 单测失败 | 先复现，再改代码；不许 `#[ignore]` 了事 |
| flaky | 找出时序/共享状态；加隔离或重试上限，并在卡里记录 |
| CI 与本地不一致 | 以 CI 为准；检查工具链/平台/环境变量 |
| 金标差异 | 确认是预期变化，再更新；不得盲刷 |

---

## 7. 最低验收命令

```bash
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
python scripts/check-docs.py
python scripts/check-contracts.py
python scripts/check-hygiene.py
```
