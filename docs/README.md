## 五、维护规则（摘要）

1. **同 PR 更新**：改了行为就必须改文档，否则 PR 不算完成。
2. **`updated` 与 `verified` 分开**：前者是编辑时间，后者是"与代码核对过"的时间，超过 60 天标黄。
3. **单篇 ≤ 200 行**：超了就拆，拆了就在本文件重新登记。
4. **改动登记**：新增/重命名/废弃文档，必须同步改本文件的清单。
5. **不写"将来可能"**：只写"当前是什么"和"为什么这样决定"（决策记录进 ADR）。
