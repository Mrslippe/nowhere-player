## 六、维护规则（摘要）

1. **两类文档**：规范类（`10/20/40/50` + 计划中的规范）必须有 front-matter、进本索引、≤200 行；过程类（任务卡/报告/归档）不强制，但要有目录入口。
2. **同卡更新**：改了行为就必须改对应文档与 CHANGELOG；CI 的 `check-docs` 会检查链接、front-matter、长度与索引。
3. **`updated` 与 `verified` 分开**：前者是编辑时间，后者是“与代码核对过”的时间；超过 60 天标黄。
4. **单篇 ≤ 200 行**：超了拆；历史文档进 `90-归档/`，不要留在主目录误导人。
5. **规范类表是生成的**：改 front-matter 后运行 `python scripts/gen-docs-index.py`，不要手改生成块；CI 会检查是否过期。
6. **不写“将来可能”**：只写“当前是什么”和“为什么这样决定”（决策记录进 ADR）。
